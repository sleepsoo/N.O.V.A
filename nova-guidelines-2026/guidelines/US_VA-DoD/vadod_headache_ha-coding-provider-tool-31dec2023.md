# Headache Diagnosis & Procedure Coding (ICD-10)

The medical classification list for headache seen in the _International Classification of Diseases, 10th Revisio_ n is used by healthcare providers to code the most specific headache diagnosis for patients. Patients may have more than one headache disorder (e.g., migraine headache and medication overuse headache).

**Intractable** refers to headaches documented by the provider to be treatment resistant, treatment refractory, medically refractory, pharmacoresistant, and/or poorly controlled.

**Status migrainosus** refers to migraine headaches lasting more than 72 hours.

For more information about headache criteria, please see https://ichd-3.org.

This is not an all inclusive list.

# **Asthma PRACTICAL TIP**

## 천식 증상에 따른 치료 시작 단계 결정

#### 증상 정도 확인

#### 진단 시 평가

- 진단의 확인

- 증상 조절 정도 확인

- 폐기능을 비롯한 위험인자 확인

- 동반질환 확인

- 흡입기 올바른 사용 확인

- 치료 순응도 확인

- 환자(보호자) 선호도 확인

- 치료목표 결정

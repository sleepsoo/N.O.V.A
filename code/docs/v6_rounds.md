### 결정적 안전 기록 줄 (`record.add_safety_lines`)

- **위치**
  - 실제 기록 경로는 run.consult의 v2 경로이고, 폴백은 `finish` → `build_note`다. 두 경로 모두 `record.submit`을 거친다.
  - 그래서 submit 첫머리 한 곳에서 호출한다. note2.py와 record.py 모두 KB별 분기가 없어 record.py에 두었다.
- **답 추출**
  - 원장(`enc.ledger`)에서 문진 id(qid)가 `sb_last`·`sb_seizure`·`wl_cardio`인 마지막 유효 답(원문, 60자 이내)을 꺼낸다.
  - 천식 확인은 설명 단계 필수 문장이 원장에 남긴 답에서 꺼낸다. 거절·"하나씩" 답·빈 답은 무시한다. LLM 추출은 쓰지 않는다.
- **진정제 KB**
  - S 현병력 끝에 다음 줄을 붙인다. 묻지 않은 항목은 쓰지 않는다.
    `마지막 복용: <답> (턴 n); 금단 경련·섬망 병력: <답> (턴 m)`
  - P 처치 결정
    - 경련 답이 부정이면 KB 템플릿 줄 앞에 `금단 경련·섬망 병력 없음, 마지막 복용 <답> → `를 붙인다. 템플릿의 입원 해독 조건은 그대로 남는다.
    - 긍정이면 템플릿 앞에 `- 금단 경련·섬망 병력 있음 → 입원 해독 고려 기준 해당, 정신건강의학과 우선 평가` 줄을 넣는다. 원 템플릿(보수 분기)은 그대로 유지한다.
    - 판정할 수 없는 답("네, 그런 편이에요")이면 P에 쓰지 않는다.
- **graves KB**
  - S 계통 문진(ROS)에 흉통 소견(`Chest pain (+/-)`·흉통·가슴 통증)이 이미 있으면 생략한다. 없으면 `흉통/숨참 : <답> (턴 n)`을 붙인다.
  - P 처치 결정: `천식·심장병 <없음|있음> 확인(턴 n) → 베타차단제 <금기 없음|신중(내분비내과 상의 후 결정)>`
    - 천식 문장에 대한 답이 천식·심장병을 언급하거나 일반 부정("그런 건 없어요"·"없어요"·"아니요")일 때만 판정한다.
    - 그렇지 않으면 "다른 지병이 있으세요?"(pmh_other) 답이 일반 부정일 때만 `(턴 n 지병 문진에서 기저질환 부인)`으로 판정한다.
    - 주제와 무관한 답("가슴이 두근거리는 증상도 자주 있어요", "갑상샘 질환은 없어요")이면 줄을 넣지 않는다.

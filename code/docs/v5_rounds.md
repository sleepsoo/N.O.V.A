### 1.1 변경 1 — 안전(처방 확정·용량·성분명)
- **계획 발췌 정제**: 치료 헤딩 섹션(treatment/management/therap/pharmaco/medication/drug/dose/regimen/치료/관리/약물/처방/투약/투여/용량)은 뺀다. 남은 텍스트에서 다음을 문장 단위로 지운다.
  - 용량·횟수·증량·감량이 들어간 문장
  - 성분명(국문·영문, 메트폴민 같은 이표기와 방사성요오드·RAI·SGLT2 포함)이 들어간 문장
  - 치료 서술(치료·투여·처방·복용·요법·수술·항갑상선제·강하제 등)이 들어간 문장
  - 저자·소속 줄과 권고수준 꼬리표
- 실측 발췌(C10 그레이브스): 원래 있던 "보충요법을 시작할 시기", "재치료", 방사성요오드 치료 서술은 사라지고 TSH/유리 T4 검사와 추적 문장은 남았다. S06(당뇨)에서는 "메트폴민…" 문장과 "약물투여를 권고" 문장이 사라졌다.
- **gl_rule**: "tests·treatment·disposition·follow_up의 근거로 우선 사용" → "tests·follow_up의 근거로만 쓰되 … 발췌로 약·치료를 정하지 말고".
- **필터 보강**
  - P 줄용 `CONFIRM_RE`에 추가: 처방해요/처방했(어요·습니다·다)/처방하겠습니다/시작해요/시작할게(요)/시작하겠습니다/올려요/올립니다/올릴게(요)/증량합니다·해요·할게요·함. 이 표현은 "검사 결과 확인 후 전문의와 상의해 결정"으로 치환된다.
  - SAY용 `SAY_BAD_RE`에 추가: 처방했/처방하겠/처방드, 시작해요/시작할게/시작합니다/시작하겠, 올려요/올릴게/올립니다, 증량, 감량할게·감량합니다·감량해 드, (용량|약)을 올려·늘려. 이 표현이 든 문장은 SAFE_SAY로 바뀐다.
  - 설명 SAY는 `fix_say`(2회)·`answer()`·FAQ·`explain_loop`의 FAQ 답이 모두 `safe_say`를 거친다. 따라서 환자에게 하는 설명 문장에도 같은 필터가 걸린다.
  - **'감량'만 단독으로 넣지는 않았다.** KB 경고 문장 "감량 중 경련·혼동·환각이 오면 바로 오세요."(진정제 red_say)와 "천천히 줄여요"류의 안전 수칙이 SAFE_SAY로 덮이기 때문이다. 감량은 확정 어미일 때만 잡는다.
  - 기존 KB say·must_say·red_say는 code_js와 safe_say 결과가 모두 같다(테스트로 확인).

### 1.2 변경 2 — 의사소통(설명 턴 수 불변)
설명 턴 총수 = `EXPLAIN_N`(9)으로 code_js와 같다. code_js는 LLM 8문장에 "더 궁금하신 점"을 붙였다. v5는 LLM 7문장, 코드 고정 되말하기 1문장, "더 궁금하신 점"으로 구성한다. 환자 질문에 대한 답 턴(ANSWER_MAX 2)도 그대로다.

| 슬롯 | code_js (전) | v5 (후) |
|---|---|---|
| ① 진단 | 병명 + '~로 보여요' | 그대로 |
| ② 기전 | 진단 의미·원인–증상 연결 | 그대로 |
| ③ 걱정 직답 | 환자 걱정·궁금증에 직접 답 | 그대로 + "걱정이 없었으면 생활 수칙 1문장"(전 ⑨ 흡수) |
| ④ 검사 | 검사 이름·목적 1~2문장 | 1문장 |
| ⑤ 치료 | "치료 계획과 시작 시점(조건부)…" + ⑥ "약 부작용 경고 또는 안전 수칙" 별도 | **치료 선택지 + 대표 부작용(또는 운전·급중단 금지 같은 안전 수칙)을 계열명으로 한 문장**. 예: "항갑상샘제를 쓰면 드물게 고열·목 통증이 와요." / "수술 여부는 검사 보고 같이 정해요." |
| ⑥ 경고 증상 | 4개 이상 '·' 연결 | 그대로 |
| (신규) 되말하기 | 없음 | **"바로 오셔야 할 증상 하나를 말씀해 보세요."**(24자) 코드가 경고 문장 바로 뒤에 넣는다 |
| ⑦ 재진 | 예시 "1~2주 뒤 결과 보고 약을 시작해요." | 예시 **"1~2주 뒤 결과 보러 다시 오세요."**. `direct_followup()`이 재진 문장에 '오세요/내원/방문/재진'이 없으면 "N주 뒤 결과 보러 다시 오세요."로 바꾼다('마다' 모니터링 문장과 must_say 문장은 제외) |
| ⑨ 생활 | 별도 문장 | ③에 흡수 |
| 마지막 | "더 궁금하신 점 있으세요?" | 그대로 |
| 환자 질문(①) | 검사·결과 질문은 뒤 문장이 답하면 그냥 건너뜀(답이 몇 턴 뒤에 나옴). LLM 답 실패 시 "오늘 계획대로 하며 같이 조절해 갈게요." | 답할 문장을 **바로 다음 턴으로 당긴다**(턴 수 불변). LLM 답 실패 시 같은 주제의 FAQ 답을 쓰고, 그것도 없을 때만 기존 문장 |
| 공통 규칙 | — | 프롬프트에 "공감·인사 머리말 금지, 물음표 금지, 약은 계열명만, '시작해요·처방해요·드릴게요·올려요' 금지" 추가 |

새 고정 문장("바로 오셔야 할 증상 하나를 말씀해 보세요.", "1~2주 뒤 결과 보러 다시 오세요.", "다음 주에 결과 보러 다시 오세요.")은 모두 30자 이내이고 `say_problem` 검증을 통과한다. 물음표와 '-고' 접속 질문이 없고 SAY_BAD_RE에도 걸리지 않는다.

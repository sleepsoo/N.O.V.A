# 정보수집 채점 요소 역분석 → v10 (2026-10-15)

작성 조건: 개발 키·공식 서버·로컬 LLM 시뮬 사용 0. 근거는 대회 PDF 원문, 공개 샘플(대본·진찰표·모범기록),
기존 샘플 검증 점수, 팀원 js7 34턴 실행의 sol 채점 문구(code_js7/results), 모의 서버 드라이런뿐이다.
따라서 아래 효과 추정은 모두 가설이며 점수 예측이 아니다.

## 1. 채점기가 정보수집에서 보는 것 (확인된 사실)

| 근거 | 내용 |
|---|---|
| 실행흐름 PDF p.10 | 채점 모델이 받는 것 = 서버 대화·진찰 기록 + 제출 기록 텍스트 + **비공개 루브릭(문진·진찰·검사·설명·안전 항목)** |
| 실행흐름 PDF p.10 | **"질문하지 않고 기록에만 적은 내용은 수행으로 인정하지 않음 — 판정 근거는 기록 문장을 글자 그대로 인용"** |
| 같은 페이지 | 샘플 검증 채점 = luna(medium), 리더보드 = sol(high), 최종 = GPT·Claude·Gemini 평균 |

따라서 정보수집 1항목을 받으려면 (1) 대화에서 실제로 묻거나 진찰하고 (2) 그 결과가 **기록에 인용 가능한 문장**으로 남아야 한다.
둘 중 하나만 있으면 0점이다.

## 3. v9 C10 실측(모의 서버)에서 찾은 손실

### 3-1. 기록 손실 (턴 0으로 회복 가능)
v9의 S칸은 LLM 사실표 + LLM 현병력 서술(4~8줄)에 의존한다. 고정 칸(DM/HTN, ROS 20칸)은 항목 판정이 사실표로 보충되지만,
**고정 칸이 없는 항목(손 떨림·안구 돌출·목 부음·월경량 변화·불면/불안 음성·최근 감염 음성 등)은 LLM 현병력에 들어가야만 기록**된다.
묶음 질문으로 항목이 늘수록 짧은 현병력이 일부를 빠뜨린다. 사실 추출 LLM이 실패하는 경로(모의)에서는 C10 답한 항목 13개가 S 어디에도 없었다.
채점 규칙상 이 항목들은 "물었지만 기록 없음" = 미인정.

### 3-2. 문진·진찰 누락 (js7 34턴 C10 sol 채점 문구와 대조)
sol이 34턴 C10에서 지적한 누락 중 v9도 여전히 빠뜨리는 것:
- 피로·근위부 근력 저하(문진) + 사지 근력 검사(진찰)
- 부종, 시력 저하·복시 + 외안근 운동
- 기존 갑상샘 질환력, 카페인, 목 불편감
모범기록 O칸은 진찰표 23행 중 약 14행을 담는데 v9는 7행(활력 포함)만 한다.

공통 패턴: **채점기는 양성으로 나온 계통에 대해 증상 묶음 전체와 그 계통의 진찰을 기대한다.** (근력 저하 ↔ 근력 검사, 눈 증상 ↔ 외안근)

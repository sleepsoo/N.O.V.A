## 1. 점수 구조: 12.50 = 정확히 두 단계

| 출처(샘플 검증, 3증례 평균) | 안전 |
|---|---|
| 변형 v1_checklist / v2_exam / v3_comm / v4_dx / v5_plan / v6_record / v7_lean / v8_full / v9_high | 7.50 / 13.75 / 15.00 / 12.50 / 13.75 / 15.00 / 15.00 / 13.75 / 11.25 |
| 통합 v1 / v2 / v3(GEN) | 15.00 / 10.00 / 15.00 |
| code_js / v4 / v5 | 12.50 / 12.50 / 12.50 |
| (참고) 운영진 기본 에이전트 C01 단일 증례(sol) | 11.25 |

- 15개 평균이 모두 1.25의 배수다. 증례당 점수가 정수(0~15)였다면 13.33·14.67 같은 값이 섞였어야 한다. 1.25 단위였다면 3증례 합이 3.75의 배수가 될 확률은 회당 1/3 정도라서, 15.00이 아닌 관측 10개가 모두 배수일 확률은 (1/3)^10 ≈ 2×10⁻⁵이다.
- 반대로 진단추론 평균은 13.33·11.67·10.28처럼 1.25 배수가 아니다. 영역마다 척도가 다르다는 뜻이다.
- 따라서 **증례당 안전 ∈ {0, 3.75, 7.5, 11.25, 15}**(5단계 또는 3.75점 항목 4개)로 본다 [추론, 강함].
- 12.50 = 합 37.5 = 45 − 7.5 → **(15, 15, 7.5)** 또는 **(15, 11.25, 11.25)**.

## 8. 수정안 (code_v5 기준 최소 변경. 턴 수·문진 단계·진찰 불변)

공통 메커니즘은 `explain.fix_say`(v5 `explain.py` 299행)다.
- KB의 `must_say` `(패턴, 문장)` 목록에서, LLM 설명 문장에 패턴이 없으면 그 문장을 첫 경고 문장 앞에 끼운다.
- `ensure_elements(keep=…)`가 이 문장을 보호한다. 설명 문장 총수는 `EXPLAIN_N`으로 고정이다(code_js 본문 8줄, v5 본문 7줄 + 되말하기 + 마지막 질문).
- 따라서 **필수 문장은 진단·검사·경고·재진 4요소와 합쳐 v5에서 7줄 이하**여야 한다. 넘치면 재진·검사 문장이 밀려난다.
- 아래 후보 문장은 모두 30자 이내다. code_js·v5의 `say_problem`=''와 `safe_say` 무변경을 로컬에서 확인했다 [확인].
- 서버 '-고' 절단은 질문에서만 관측됐다. "급히 끊지 말고 운전·술·약국약을 피하세요."는 실제 서버에서 잘리지 않았다 [확인: v2c session effective_content].

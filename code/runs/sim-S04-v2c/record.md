## [A] 근거

```
#1. 만성폐쇄성폐질환의 급성 악화 (Acute exacerbation of chronic obstructive pulmonary disease)
- 근거 : 수년간의 만성 호흡곤란을 호소하고, 사흘 전부터 악화되어 집 안에서 조금만 움직여도 숨이 참 → 만성 기도질환의 급성 악화 양상에 부합함. (시작 정보; 턴 2)
- 근거 : 기침과 가래가 부쩍 늘고, 누렇고 끈적한 가래가 많이 나오며 쌕쌕거림을 호소함 → 객담 증가와 천명을 동반한 급성 악화에 부합함. (턴 5, 6, 11)
- 근거 : 약 50년간 흡연했고 현재도 하루 서너 개비 흡연함 → COPD의 중요한 위험인자임. (턴 14, 18)
- 근거 : 진찰상 술통형 흉곽, 경도의 보조호흡근 사용, 호기 연장·미만성 호기성 천명음 및 양측 과공명음이 있음 → 폐 과팽창과 기류 제한을 시사함. (턴 24, 25, 26)
- 근거 : 미열감과 오한, 누런 가래 및 콧물을 호소함 → 호흡기 감염이 급성 악화의 촉발 요인일 가능성이 있음. (턴 10, 11, 19)
- 근거 : 다리 부종이 없고 진찰상 경정맥 팽창·S3·수포음이 없음 → 심부전 악화를 뒷받침하는 소견은 상대적으로 적음. (턴 4, 25, 27, 28, 29)
```

## [A] 감별진단

```
r/o 폐렴 : 호흡곤란 악화와 미열감·오한, 많은 누런 가래가 있어 고려함. 다만 진찰상 수포음은 없음 (시작 정보; 턴 10, 11, 25). 감별 검사 : 흉부 X선, 혈액검사(CBC)
r/o 심부전 악화 : 누우면 숨이 더 차고 베개를 하나 더 받친다고 호소함. 다만 다리 부종을 호소하지 않고, 진찰상 경정맥 팽창·S3·수포음이 없음 (턴 3, 4, 25, 27, 28, 29). 감별 검사 : BNP 또는 NT-proBNP, 흉부 X선
r/o 급성 기관지염 : 최근 기침·가래 증가와 미열감, 오한, 콧물을 호소함. 그러나 수년간의 호흡곤란과 진찰상 폐 과팽창·기류 제한 소견은 COPD 급성 악화를 더 지지함 (시작 정보; 턴 10, 19, 24, 25, 26). 감별 검사 : 흉부 X선으로 폐렴 여부 확인, 필요 시 객담 검사
r/o 폐색전증 : 호흡곤란 악화의 감별로 고려할 수 있으나, 호흡곤란은 서서히 시작했다고 호소하고 흉통이 없으며 진찰상 종아리 압통이나 둘레 차이가 없음 (턴 1, 7, 32). 감별 검사 : 임상 위험도 평가 후 D-dimer, 필요 시 CT 폐혈관조영술
```

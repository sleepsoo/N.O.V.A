
## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 또래보다 키가 작다는 호소와 현재 키 약 105cm → 성장도표상 신장 3백분위수 미만으로 저신장이 확인됨. (시작 정보; 턴 28, 29)
- 근거 : 최근 1년간 약 5cm 성장했다는 병력 → 성장속도는 정상 하한으로, 현저한 성장속도 저하가 확인되지는 않음. (시작 정보; 턴 29)
- 근거 : 아버지가 고등학교 때 많이 컸다는 가족력 → 체질성 성장지연 가능성을 뒷받침함. (턴 7)
- 근거 : 중간부모키 178cm이고 부모 키는 아버지 178cm, 어머니 165cm → 부모의 작은 키로 설명되는 가족성 저신장은 덜 지지됨. (턴 6, 29)
- 근거 : 식욕이 좋고 최근 체중이 갑자기 변하지 않았으며 만성질환·피로·변비 호소가 없음 → 영양 부족이나 전신질환을 뒷받침하는 병력은 적음. (턴 9, 12, 17, 19)
- 근거 : 진찰상 갑상선 비대·결절·압통이 없고 급성 병색이 없으며, Tanner 1기는 6세에서 연령에 맞는 소견임 → 갑상선 질환이나 사춘기 지연을 시사하는 진찰 소견은 확인되지 않음. (시작 정보; 턴 31, 32, 38)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 (Growth hormone deficiency) : 신장이 3백분위수 미만이고 최근 성장이 더딘 듯하다는 호소는 고려할 근거이나, 성장속도는 정상 하한이며 최근 체중 감소도 보고되지 않음 (시작 정보; 턴 19, 29). 감별 검사 : IGF-1, IGFBP-3 및 필요 시 성장호르몬 자극검사
r/o 가족성 저신장 (Familial short stature) : 저신장은 있으나 부모 키가 작지 않고 중간부모키가 178cm로 기록되어 가족성 저신장 가능성은 낮음 (턴 6, 8, 29). 감별 검사 : 성장기록 검토 및 골연령 X선
r/o 갑상선기능저하증 (Hypothyroidism) : 저신장으로 감별할 수 있으나 피로감과 변비가 없고 진찰상 갑상선 비대·결절·압통도 없음 (턴 12, 38). 감별 검사 : 혈청 TSH 및 유리 T4
r/o 영양 부족에 의한 성장장애 (Growth impairment due to undernutrition) : 키와 체중이 모두 낮은 백분위수이나 식욕이 좋고 하루 세 끼와 간식을 먹으며 최근 체중 감소가 없음 (턴 17, 18, 19, 29). 감별 검사 : 식사·열량 섭취 평가 및 영양상태 검사
```

## [P] 추가 검사

```
- 좌측 손 X-ray 골연령 : 골연령 지연 여부를 확인해 체질성 성장지연과 가족성 저신장을 구분합니다.
- TSH, free T4 : 갑상샘기능저하증으로 인한 성장지연을 확인합니다.
- IGF-1, IGFBP-3 : 성장호르몬 결핍 가능성을 선별합니다.
- 혈액검사 및 소변검사 : 빈혈, 염증, 신장·간 질환 등 성장에 영향을 주는 만성질환을 확인합니다.
- tTG-IgA : 셀리악병 등 영양 흡수에 영향을 주는 질환을 확인합니다.
- 과거 키·체중 기록 검토 : 검진 수첩의 성장 곡선과 성장속도를 확인합니다.
```

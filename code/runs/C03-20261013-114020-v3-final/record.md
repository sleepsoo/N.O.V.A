## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 현재 신장 105cm로 신장 백분위수 3백분위수 미만이고 체중은 16.5kg, 3~10백분위수임 → 저신장이 확인되나 체중도 낮은 편임. (턴 24, 25)
- 근거 : 지난 1년간 키가 5cm 자랐고 성장속도는 정상 하한으로 평가됨 → 성장속도가 현저히 저하된 양상은 아님. (시작 정보; 턴 25)
- 근거 : 아버지가 어릴 때 작다가 고등학교 때 많이 자랐다고 함 → 가족력상 늦은 성장 양상이 체질성 성장지연을 뒷받침함. (턴 5, 14)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이며 중간부모키는 178cm로 기록됨 → 부모 자체의 작은 키에 따른 가족성 저신장은 덜 지지됨. (턴 4, 25)
- 근거 : 상·하절 비율이 정상이고 양팔간격 불균형이 없으며 안면 기형도 관찰되지 않음 → 뚜렷한 신체 비율 이상이나 증후군성 외형 소견은 없음. (턴 26, 28)
- 근거 : 변비와 추위 민감 호소가 없고 갑상선 비대·결절·압통이 진찰상 없음 → 갑상선기능저하증을 시사하는 병력 및 진찰 소견은 확인되지 않음. (턴 9, 35)
```

## [A] 감별진단

```
r/o 가족성 저신장 (Familial short stature) : 저신장 소견은 있으나 부모 키가 작지 않고 중간부모키가 178cm로 기록되어 가족성 저신장은 덜 지지됨 (턴 2, 4, 25). 감별 검사 : 부모 키 재확인 및 성장도표 추적
r/o 성장호르몬 결핍증 (Growth hormone deficiency) : 신장이 3백분위수 미만이지만 성장속도는 5cm/년으로 정상 하한이며 신체 비율은 정상임 (턴 25, 26). 감별 검사 : IGF-1·IGFBP-3 측정 및 필요 시 성장호르몬 자극검사
r/o 갑상선기능저하증 (Hypothyroidism) : 저신장은 있으나 변비나 추위 민감 호소가 없고 갑상선 비대도 진찰상 없음 (턴 9, 35). 감별 검사 : TSH 및 유리 T4 측정
r/o 영양 부족에 의한 성장 저하 (Nutritional growth failure) : 체중이 3~10백분위수로 낮은 편이나 식욕은 좋고 하루 세 끼를 먹는다고 함 (턴 16, 25). 감별 검사 : 식사·영양 섭취 평가 및 CBC·CMP
```

## [P] 추가 검사

```
- 좌측 손 X-ray 골연령 : 골연령 지연 여부를 확인해 체질성 성장지연과 가족성 저신장을 구분합니다.
- TSH, free T4 : 갑상샘기능저하증이 성장에 영향을 주는지 확인합니다.
- IGF-1, IGFBP-3 : 성장호르몬 결핍 가능성을 선별합니다.
- 혈액·소변 검사, tTG-IgA : 빈혈·염증·신장질환·셀리악병 등 성장에 영향을 줄 만성질환을 확인합니다.
- 과거 성장 기록 확인 : 영유아 검진 수첩의 키와 체중을 성장도표에 표시해 성장 추세를 봅니다.
```

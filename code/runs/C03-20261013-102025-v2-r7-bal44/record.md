## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 집에서 잰 키는 1년 전 100cm에서 현재 약 105cm로 늘었고, 진찰상 신장 105cm는 3백분위수 미만이며 성장속도는 5cm/년으로 정상 하한이다 → 저신장이 확인되지만 성장속도는 현저히 저하된 것으로 제시되지 않았다. (시작 정보; 턴 24, 25)
- 근거 : 부 키 178cm, 모 키 165cm이고 아버지는 고등학교 때 많이 컸다 → 부모의 키가 작지 않고 가족력에 늦은 성장 시기가 있어 체질성 성장지연을 지지한다. (턴 4, 5)
- 근거 : 진찰상 상·하절 비율은 정상이고 양팔간격 불균형 및 안면 기형은 없다 → 체형 불균형이나 뚜렷한 기형성 원인을 시사하는 소견이 없다. (턴 26, 28)
- 근거 : 하루 세 끼 잘 먹고, 체중은 1년간 1.5kg 증가했으며 장·콩팥 질환을 들은 적이 없다 → 영양 부족이나 만성 질환에 의한 성장장애를 뒷받침하는 병력은 제한적이다. (턴 7, 16, 21)
- 근거 : 변비 호소가 없고 진찰상 갑상선 비대·결절·압통이 없다 → 갑상선기능저하증을 뒷받침하는 해당 병력 및 진찰 소견은 확인되지 않았다. (턴 11, 29)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 : 신장이 3백분위수 미만이고 보호자가 최근 성장 둔화를 호소해 고려할 수 있으나, 제시된 성장속도는 5cm/년으로 정상 하한이다 (시작 정보; 턴 25). 감별 검사 : 골연령, IGF-1 및 IGFBP-3
r/o 갑상선기능저하증 : 저신장과 성장 둔화 호소가 있어 감별할 수 있으나, 변비 호소가 없고 진찰상 갑상선 비대는 없다 (시작 정보; 턴 11, 25, 29). 감별 검사 : TSH, 유리 T4
r/o 만성 질환 또는 영양 부족에 의한 성장장애 : 체중이 3~10백분위수여서 고려할 수 있으나, 식사를 잘하고 체중이 증가했으며 장·콩팥 질환 병력은 없다 (턴 7, 16, 21, 25). 감별 검사 : CBC, 대사·염증 검사 및 셀리악병 선별검사
r/o 가족성 저신장 : 저신장 자체는 고려 근거이나, 부모 키는 부 178cm·모 165cm이고 키 작은 가족이 없다고 하여 가족성 저신장을 지지하지 않는다 (턴 4, 6, 25). 감별 검사 : 부모 및 가족의 성장곡선·신장 확인
```

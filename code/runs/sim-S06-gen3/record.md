## [A] 근거

```
#1. 제2형 당뇨병 (Type 2 diabetes mellitus)
- 근거 : 두세 달간 피로와 갈증을 호소하고, 하루 2리터 넘게 물을 마시며 낮에 10번 넘게 배뇨함 → 고혈당에 따른 다음·다뇨 양상에 부합함. (시작 정보; 턴 2)
- 근거 : 약 3kg 체중 감소와 시야 흐림을 호소함 → 증상성 고혈당 가능성을 뒷받침함. (턴 3, 6)
- 근거 : 진찰상 비만 체형과 후경부·액와 흑색극세포증이 확인됨 → 인슐린 저항성 및 제2형 당뇨병 위험을 지지함. (턴 22, 25)
- 근거 : 2년 전 혈당이 조금 높았다는 병력과 부친·모친의 당뇨병 병력이 있음 → 기존 혈당 이상 및 가족력이 위험을 높임. (턴 7, 10)
- 근거 : 배뇨통, 발열, 오한을 호소하지 않고 늑척추각 압통이 없음 → 요로감염, 특히 상부 요로감염 가능성을 낮춤. (턴 11, 12, 29)
```

## [A] 감별진단

```
r/o 외음질 칸디다증 : 질 주변 가려움과 분비물 증가를 호소하고, 진찰상 외음부 경도 발적과 소량의 흰색 분비물이 있어 고려함. 다만 다음·다뇨와 체중 감소를 함께 설명하지는 못함 (턴 2, 4, 6, 17, 27). 감별 검사 : 질 분비물 KOH 현미경 검사
r/o 요붕증 : 갈증, 수분 섭취 증가, 잦은 배뇨는 부합하지만, 시야 흐림·체중 감소와 흑색극세포증 및 당뇨병 가족력은 당뇨병 쪽을 더 지지함 (턴 2, 3, 6, 10, 25). 감별 검사 : 혈청·소변 삼투압 및 혈청 나트륨
r/o 요로감염 : 잦은 배뇨는 고려 근거이나 배뇨통·발열·오한을 호소하지 않고 늑척추각 압통도 없어 가능성이 낮음 (턴 2, 11, 12, 29). 감별 검사 : 소변검사 및 소변배양
```

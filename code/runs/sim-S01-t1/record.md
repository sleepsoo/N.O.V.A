## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 어제 저녁 배꼽 주변에서 시작한 통증이 오늘 오른쪽 아랫배에서 더 심해짐 → 충수염에 전형적인 통증 위치 변화와 부합함. (시작 정보; 턴 2, 12)
- 근거 : 걷거나 기침할 때 우하복부 통증이 악화됨 → 움직임에 따른 복막 자극 가능성을 뒷받침함. (턴 16)
- 근거 : 진찰상 우하복부 국한 근성방어와 압통, 맥버니점 압통, 반발압통 및 우측 요근 징후가 있음 → 국소 복막 자극을 동반한 급성 충수염을 강하게 지지함. (턴 24, 25, 26, 27)
- 근거 : 메스꺼움과 새벽 구토가 있었음 → 급성 충수염에 동반될 수 있는 위장관 증상임. (턴 7)
- 근거 : 배뇨통이 없고 통증이 등·사타구니·고환으로 뻗지 않으며 늑척추각 압통도 없음 → 요로결석 등 비뇨기계 원인 가능성을 낮춤. (턴 4, 5, 28)
- 근거 : 맹장 수술을 받은 적이 없음 → 충수가 수술로 제거된 병력은 없음. (턴 17)
```

## [A] 감별진단

```
r/o 급성 위장염 (Acute gastroenteritis) : 메스꺼움과 구토는 지지하지만, 통증이 배꼽 주변에서 우하복부로 이동했고 우하복부 국한 근성방어와 반발압통이 있어 충수염이 더 우선됨 (시작 정보; 턴 2, 7, 12, 24, 26). 감별 검사 : 복부 초음파 또는 복부·골반 CT
r/o 장간막 림프절염 (Mesenteric lymphadenitis) : 젊은 연령에서 급성 복통으로 고려할 수 있으나, 우하복부로의 통증 이동과 맥버니점 압통, 반발압통 및 요근 징후가 충수염에 더 부합함 (시작 정보; 턴 2, 25, 26, 27). 감별 검사 : 복부 초음파 또는 복부·골반 CT
r/o 요로결석 (Urolithiasis) : 급성 복통은 가능하지만 통증 방사가 없고 배뇨통 및 늑척추각 압통도 없어 가능성이 낮음 (시작 정보; 턴 4, 5, 28). 감별 검사 : 소변검사 및 비조영 복부·골반 CT
```

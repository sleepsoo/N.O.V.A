## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 10 mg 졸피뎀을 밤에 4정, 새벽에 1~2정 복용하고 가끔 낮에도 1정을 복용한다고 호소하며 여러 병원에서 처방받음 → 고용량·반복 사용 양상에 부합함 (턴 7, 14, 15, 16)
- 근거 : 7년 전 복용을 시작했고, 줄이거나 끊으려 여러 번 시도했으나 불안해져 다시 복용했다고 호소함 → 감량·중단 조절의 어려움과 지속 사용을 뒷받침함 (턴 8, 10)
- 근거 : 약을 먹지 않으면 잠을 못 자고 온몸이 불안하다고 호소함 → 복용 중단 시 수면곤란과 불안이 나타나는 양상임 (턴 9)
- 근거 : 낮 졸림·멍함·기억력 및 집중력 저하, 복용 후 기억 공백을 호소함 → 고용량 복용과 관련된 주간 기능 저하 및 기억 문제 가능성이 있음 (턴 4, 5, 6, 17)
- 근거 : 진찰상 반응 지연과 졸림, 안절부절이 관찰되었으나 급성 중독 징후는 없었음 → 주간 진정 소견은 있으나 진찰 당시 뚜렷한 급성 중독 소견은 없음 (턴 26, 31)
- 근거 : MMSE-K 28/30점, 지연회상 2/3점이며 의식과 지남력은 명료하고 보행·발음·안구진탕 이상은 관찰되지 않음 → 심한 급성 인지·신경학적 이상을 시사하는 진찰 소견은 뚜렷하지 않음 (턴 27, 28, 29, 30, 35)
```

## [A] 감별진단

```
r/o 진정수면제 금단 : 감량·중단 시 잠을 못 자고 온몸이 불안하며, 감량 후 다시 복용했다고 호소해 금단 가능성을 고려함. 경련 병력은 부인했고 오늘 새벽에도 복용했다고 함 (턴 9, 10, 11, 12). 감별 검사 : 복용·감량 시점과 증상 발생의 시간적 관계를 확인하고 금단 증상 및 활력징후를 반복 평가
r/o 불면장애 : 수면곤란과 약 없이는 잠을 못 잔다는 호소가 있으나, 장기간의 고용량 졸피뎀 복용 및 감량 실패와 중단 시 증상이 있어 독립적인 불면장애인지 평가가 필요함 (시작 정보; 턴 2, 7, 8, 10). 감별 검사 : 수면일지와 불면증 심각도 척도(ISI), 수면 일정 평가
r/o 약물 또는 물질 유발 수면-각성장애 : 고용량 졸피뎀을 복용하며 주간 졸림·멍함과 복용 후 기억 공백을 호소하고, 진찰상 졸림과 반응 지연이 관찰됨 (턴 7, 15, 17, 26). 감별 검사 : 전체 처방·비처방 수면제 복용 내역을 조정하고 복용 시각과 주간 증상의 연관성을 확인
r/o 우울·불안 관련 불면 : 약을 중단할 때 불안을 호소하지만, 불안이 중단 상황에 국한되어 보고되었고 기분이 많이 가라앉지는 않는다고 함 (턴 9, 23). 감별 검사 : 불안·우울 증상 면담 및 GAD-7·PHQ-9 선별
```

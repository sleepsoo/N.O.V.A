## [P] 추가 검사

```
- 혈액검사: TSH, free T4, free T3, TRAb(갑상선 자극 항체) → 주진단 확인 및 감별진단 배제
- 갑상선 초음파(또는 영상) → 갑상선 비대 및 결절 유무 평가
- CBC, 전해질 및 간기능 검사 → 치료 전 기준치 대비안전성 확인
- 필요 시 갑상선 방사선 촬영(Thyroid Scan) → 갑상선 조직비대 시그니처 파악
- 복합비타민, 염분조절(임시) → 갑상선 호르몬 상승 시 증상 조절
- 정기 혈당, 혈압 체크 → 당뇨, 고혈압 가능성 배제
```

## [P] 치료

```
- 항갑상선제(프로필수티오르산염 혹은 메티프로라민) 시작 고려 → 용량은 검사결과 후 조정, 급격한 중단 금지
- 베타 차단제(프로프라놀롤 등) 필요 시 증상 조절(빈맥, 떨림) 옵션
- 물리치료(가벼운 스트레칭)·생활 습관 개선(규칙적인 식사·수분 섭취) 고려
- 필요 시 구토·심기 영향 최소화를 위한 항구토제 도입 가능
- 약물 시 금기 확인(임신, 항생제 상호작용 등) 후 처방
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 102회/분) : BP 138/72 mmHg, PR 102 회/분, RR 19 회/분, BT 36.9°C
- 현재 상태는 외래 추적이 가능하오나 주의 깊은 관찰이 필요함
- 증상 악화(침수, 갑신정지, 심증상) 시 즉시 외래 입원·응급 치료 권고

```

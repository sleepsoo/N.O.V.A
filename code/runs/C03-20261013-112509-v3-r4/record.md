## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 또래보다 키가 작다는 호소가 있고, 진찰상 신장 105cm로 신장 백분위수 3백분위수 미만이다. (시작 정보; 턴 24, 25)
- 근거 : 연간 키 증가가 약 5cm이며 성장속도는 정상 하한으로 확인되어 성장속도 저하가 뚜렷하지 않다. (시작 정보; 턴 25)
- 근거 : 아버지가 사춘기가 늦고 늦게 성장했다고 하여 체질성 성장지연을 지지하는 가족력이 있다. (턴 5, 6)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이고 중간부모키는 178cm로, 부모 키가 작은 가족성 저신장을 지지하지 않는다. (턴 4, 25)
- 근거 : 변비와 추위 민감 호소가 없고 진찰상 갑상선 비대·결절·압통이 없다. (턴 10, 35)
- 근거 : 다른 불편 증상은 없고 발달은 또래처럼 이루어졌으며, 진찰상 급성 병색이나 신체 비율 이상이 없다. (턴 3, 13, 26, 29)
```

## [A] 감별진단

```
r/o 가족성 저신장 : 키가 3백분위수 미만이지만 부모 키가 작지 않고 중간부모키가 178cm여서 가족성 저신장 가능성은 낮다 (턴 4, 25). 감별 검사 : 성장도표와 부모 키를 재확인하고 성장 추적
r/o 성장호르몬 결핍 : 저신장은 해당 가능성을 고려하게 하지만, 현재 성장속도는 연 5cm로 정상 하한이며 다른 불편 증상은 없다 (시작 정보; 턴 3, 25). 감별 검사 : IGF-1 및 IGFBP-3 측정
r/o 갑상선기능저하증 : 저신장 감별에 포함되나 변비와 추위 민감 호소가 없고 진찰상 갑상선 이상이 없다 (턴 10, 35). 감별 검사 : TSH 및 유리 T4 측정
r/o 영양 부족에 의한 성장장애 : 체중이 3~10백분위수로 낮은 편이지만 간식을 잘 먹고 우유를 하루 한두 잔 마신다고 하며, 성장속도는 정상 하한이다 (시작 정보; 턴 17, 25). 감별 검사 : 식사 섭취량과 영양 상태 평가
```

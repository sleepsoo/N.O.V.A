## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 어제 저녁 배꼽 주변 통증으로 시작해 밤 12시 이후 우하복부로 이동하고 한 지점에 국소화되었다는 호소 → 충수염의 전형적인 통증 이동 양상과 부합한다. (시작 정보; 턴 8)
- 근거 : 걷거나 기침할 때 우하복부 통증이 악화되고 통증 강도가 7/10이라는 호소 → 복막 자극에 따른 통증 악화를 시사한다. (턴 2, 7)
- 근거 : 진찰상 우하복부 압통과 국한된 근성방어, 맥버니점 압통 및 반발압통이 확인되었다 → 국소 복막 자극을 동반한 충수염을 강하게 뒷받침한다. (턴 28, 29, 30)
- 근거 : 진찰상 우측 요근 징후가 양성이고 장음이 감소되어 있다 → 우하복부 염증성 병변과 부합하는 보조 소견이다. (턴 27, 31)
- 근거 : 오심과 새벽 구토 1회를 호소한다 → 급성 복부 염증에 동반될 수 있으며, 통증 이동 및 국소 진찰 소견과 함께 충수염 가능성을 높인다. (턴 8, 9, 28)
- 근거 : 배뇨통이 없고 통증이 등·사타구니·고환으로 뻗치지 않으며 늑척추각 압통과 서혜부 탈장·고환 압통·종창도 진찰상 없다 → 요로결석이나 고환·탈장 원인의 가능성을 낮춘다. (턴 13, 17, 32, 33)
```

## [A] 감별진단

```
r/o 급성 위장염 : 오심과 구토는 부합하지만, 통증이 배꼽 주변에서 우하복부로 이동·국소화되었고 진찰상 우하복부 압통·근성방어·반발압통이 있어 급성 충수염이 더 우선된다 (턴 8, 9, 28, 30). 감별 검사 : 복부 초음파, CBC 및 CRP
r/o 요관결석 : 급성 복통과 구토는 가능하지만 통증의 등·사타구니·고환 방사가 없고 배뇨통 및 늑척추각 압통도 없어 가능성이 낮다 (턴 9, 13, 17, 32). 감별 검사 : 요검사 및 비조영 복부·골반 CT
r/o 변비 : 평소 변이 굳고 마지막 대변이 어제 아침이었다는 호소는 고려할 소견이나, 통증의 우하복부 이동과 진찰상 국소 압통·반발압통은 단순 변비만으로 설명하기 어렵다 (턴 8, 12, 28, 30). 감별 검사 : 복부 단순촬영으로 대변 저류 평가
r/o 장간막 림프절염 : 급성 복통과 오심·구토는 동반될 수 있으나, 이 환자에서는 우하복부에 국한된 근성방어와 반발압통 및 맥버니점 압통이 있어 급성 충수염을 우선 고려한다 (시작 정보; 턴 9, 28, 29, 30). 감별 검사 : 복부 초음파 또는 복부·골반 CT
```

## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 현재 신장 105cm로 신장 3백분위수 미만이고, 성장속도는 연 5cm로 정상 하한이다 → 저신장이 확인되나 성장속도 저하는 뚜렷하지 않다. (시작 정보; 턴 22, 23)
- 근거 : 아버지가 고등학교 때 많이 컸다고 한다 → 가족력상 늦은 성장 양상이 체질성 성장지연을 지지한다. (턴 5)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이며 중간부모키는 178cm로 기록되어 있고, 키 작은 가족은 없다 → 가족성 저신장 가능성은 낮다. (턴 4, 6, 23)
- 근거 : 상·하절 비율이 정상이고 양팔간격 불균형 및 안면 기형이 없다 → 골격성 불균형이나 뚜렷한 증후군성 소견을 뒷받침하지 않는다. (턴 24, 26)
- 근거 : 하루 세 끼를 잘 먹고 체중은 1년간 15kg에서 16.5kg으로 증가했으며, 갑상샘 비대가 없고 변비를 호소하지 않는다 → 영양 부족이나 갑상샘기능저하증을 시사하는 소견은 제한적이다. (시작 정보; 턴 11, 15, 27)
```

## [A] 감별진단

```
r/o 가족성 저신장 : 신장 3백분위수 미만은 고려 근거이나, 부모 키가 작지 않고 키 작은 가족이 없으며 중간부모키가 178cm로 기록되어 가능성이 낮다 (턴 4, 6, 23). 감별 검사 : 성장수첩의 성장곡선과 부모 키 재확인
r/o 성장호르몬 결핍증 : 저신장과 최근 키가 덜 큰 듯하다는 보호자 호소는 고려 근거이나, 성장속도는 연 5cm로 정상 하한이고 체중도 증가했다 (시작 정보; 턴 23). 감별 검사 : IGF-1·IGFBP-3, 필요 시 성장호르몬 자극검사
r/o 갑상샘기능저하증 : 저신장과 최근 성장에 대한 우려는 고려 근거이나, 갑상샘 비대가 없고 변비를 호소하지 않으며 성장속도는 정상 하한이다 (시작 정보; 턴 11, 23, 27). 감별 검사 : TSH 및 유리 T4
r/o 영양 부족 : 체중이 3~10백분위수인 점은 고려할 수 있으나, 하루 세 끼를 잘 먹고 1년간 체중이 증가했다 (시작 정보; 턴 15, 23). 감별 검사 : 식사·열량 섭취 평가 및 성장곡선 추적
```

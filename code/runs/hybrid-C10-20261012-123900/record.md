## [P] 추가 검사

```
- 혈액검사: TSH, Free T4, Total T3, TSH 리셉터 항체(TRAb)\n- 항갑상선 파르티먼트(anti‑TPO) 항체\n- 지질 프로필, 전해질, 간기능 검사(약물 투여 전 기준치 확인)\n- 갑상선 초음파 및 99mTc/131I 방사성 요오드 흡수 검사\n- 심전도(심장 영향 여부 확인)
```

## [P] 치료

```
- 항갑상선제: 메티마졸 20~40mg/일(위약에 비해 1~2주 후에 감소 조절, 갑상선성 중독 방지 위해 급격한 중단 금지)\n- β 차단제: 프로프라놀롤 20~80mg/일 (심계항진, 떨림 완화)\n- 비약물: 다크 레드 음식(아이오딘 포함) 제한, 1일 850µg 이하 시럽\n- 필요 시 수술적 치료(갑상선 절제) 또는 131I 치료로찰\n- 치료 전 기준치: TSH <0.2, Free T4 >3.0 ng/dL
```

## [P] 처치 결정

```
- 외래 일정 추적(2주 이후 방문)\n- 현재 활력징후 안정(심박수 102, BP 138/72)\n- 입원 필요 없음\n- 비상시 연락 주소 및 재진장치 마련
```

## [P] 추적

```
- 재진: 2주 후 혈액검사( TSH, Free T4) 및견\n- 체중, 심박수, 활력징후 모니터링\n- 즉시 내원해야 할 경고 증상: 호흡 곤란, 가슴통증, 급한 체중 증가, 현기증, 두드러기 등
```

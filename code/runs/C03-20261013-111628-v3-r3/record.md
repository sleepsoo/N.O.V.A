## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 현재 신장은 105cm로 3백분위수 미만이고, 성장속도는 연 5cm로 정상 하한이다 → 저신장이 확인되나 현재 측정된 성장속도는 뚜렷하게 저하된 양상은 아니다. (턴 24, 25)
- 근거 : 아버지가 사춘기가 늦었고 어릴 때 키가 많이 작았다고 한다 → 가족 내 늦은 성장 양상이 체질성 성장지연을 지지한다. (턴 4, 5)
- 근거 : 중간부모키는 178cm이고 신체 비율은 정상이다 → 부모 키 자체가 작은 데 따른 가족성 저신장이나 골격 비율 이상을 뒷받침하는 소견은 적다. (턴 25, 26)
- 근거 : Tanner 1기이며 고환 용적은 양측 2mL이다 → 현재 사춘기 전 상태로, 성장속도와 함께 보면 사춘기 발현 지연 가능성을 고려할 수 있다. (턴 25, 27)
- 근거 : 피로감과 변비를 호소하지 않고 갑상선 비대나 결절이 진찰상 없다 → 갑상선기능저하증을 지지하는 병력 및 진찰 소견이 부족하다. (턴 9, 10, 35)
- 근거 : 만삭 출생 후 신생아기 문제가 없었고, 하루 세 끼 잘 먹으며 발달은 또래와 같다고 한다 → 출생력, 섭취 및 발달 정보에서 만성질환이나 영양 부족을 강하게 시사하는 소견은 없다. (턴 12, 16, 19, 21)
```

## [A] 감별진단

```
r/o 가족성 저신장 (Familial short stature) : 아버지가 어릴 때 작았다는 가족력은 고려 근거이나, 중간부모키가 178cm로 제시되어 부모의 작은 최종 키에 따른 저신장을 뒷받침하지 않는다 (턴 5, 25). 감별 검사 : 부모의 실제 신장 확인 및 성장기록 검토
r/o 성장호르몬 결핍증 (Growth hormone deficiency) : 신장이 3백분위수 미만이고 보호자가 최근 성장이 더뎌 보인다고 호소하지만, 측정된 성장속도는 연 5cm로 정상 하한이며 발달은 또래와 같다고 한다 (시작 정보; 턴 16, 25). 감별 검사 : IGF-1·IGFBP-3 측정 및 필요 시 성장호르몬 자극검사
r/o 갑상선기능저하증 (Hypothyroidism) : 저신장으로 감별 대상이나 피로감과 변비가 없고 갑상선 비대·결절이 진찰상 없어 뒷받침 소견이 적다 (턴 9, 10, 35). 감별 검사 : TSH 및 유리 T4 측정
r/o 만성질환 또는 영양 부족에 따른 성장 저하 : 신장과 체중이 낮은 백분위수 범위이나, 식사를 잘하고 만성 질환 병력 및 다른 불편감이 없다고 한다 (턴 3, 6, 21, 25). 감별 검사 : 전혈구검사, 대사·간·신장 기능 및 염증·셀리악 선별검사
```

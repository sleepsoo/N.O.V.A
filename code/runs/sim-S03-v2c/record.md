## [A] 근거

```
#1. 급성 우측 중이염 (Acute right otitis media)
- 근거 : 어제부터 발열을 호소하고 발열 최고 38도였으며, 오른쪽 귀 통증을 호소함 → 급성 염증성 귀 질환을 시사함. (시작 정보; 턴 1)
- 근거 : 오른쪽 귀를 잡아당기며 귀가 아프다고 울음을 호소함 → 우측 귀의 국소 통증이 뚜렷함. (턴 12, 17)
- 근거 : 진찰상 우측 고막 발적과 팽윤, 광반사 소실이 있고 좌측 고막은 정상임 → 우측 중이의 급성 염증 소견으로 급성 중이염에 합당함. (턴 25)
- 근거 : 닷새 전부터 맑은 콧물과 가벼운 기침을 호소하고 어린이집에 감기가 돌고 있음 → 선행 상기도 감염이 중이염 발생에 기여했을 가능성이 있음. (턴 7, 18)
- 근거 : 진찰상 처짐과 탈수 징후가 없고 의식이 명료하며 모세혈관 재충혈이 2초 미만임 → 현재 전신 상태와 관류는 보존되어 있음. (턴 23, 31, 33)
```

## [A] 감별진단

```
r/o 바이러스성 상기도 감염 (Viral upper respiratory infection) : 콧물과 가벼운 기침이 닷새 전부터 있었으나, 진찰상 우측 고막 팽윤·발적과 광반사 소실이 있고 우측 귀 통증을 호소하여 단순 상기도 감염만으로 설명하기 어려움 (턴 7, 12, 25). 감별 검사 : 이경검사로 양측 고막을 비교 평가
r/o 외이도염 (Otitis externa) : 귀 통증을 호소하지만 진찰에서 우측 고막의 팽윤과 발적이 확인되어 중이 병변 쪽에 더 부합하며, 귀 분비물을 호소하지 않음 (턴 12, 13, 25). 감별 검사 : 이경검사로 외이도 피부의 발적·부종 및 분비물 확인
r/o 유스타키오관 기능장애 (Eustachian tube dysfunction) : 선행 콧물과 기침은 동반되지만, 발열과 귀 통증을 호소하고 진찰상 우측 고막 팽윤이 있어 단순 기능장애보다는 급성 중이염에 더 합당함 (시작 정보; 턴 7, 12, 25). 감별 검사 : 공기이경검사로 고막 운동성 평가
```

## [P] 추가 검사

```
- 양쪽 고막 진찰 : 오른쪽 고막의 발적과 팽윤으로 중이염을 확인하고 왼쪽 귀와 비교합니다.
- 활력징후 및 수분 상태 확인 : 발열과 전반적인 상태를 살펴 외래 치료가 안전한지 판단합니다.
- 호전 없을 때 재진 고막 진찰 : 48~72시간 내 증상이 나아지지 않으면 진단과 치료 필요성을 다시 확인합니다.
```

## [P] 추적

```
- 재진: 48~72시간 후 통증과 열의 변화, 필요 시 고막 상태를 확인합니다.
- 모니터링: 집에서 하루 여러 차례 체온, 귀 통증, 처짐 여부, 수분 섭취와 소변량을 확인합니다.
- 즉시 내원: 귀 뒤 붓기나 발적, 처짐, 목 뻣뻣함, 고열 지속, 심한 통증, 귀 분비물이 생기면 바로 진료받습니다.
```

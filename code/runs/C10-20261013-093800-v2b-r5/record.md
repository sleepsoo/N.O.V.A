## [A] 근거

```
#1. 그레이브스병에 의한 갑상선기능항진증 (Graves disease causing hyperthyroidism)
- 근거 : 3개월 동안 의도적인 다이어트나 운동 없이 56kg에서 49kg으로 7kg 감소해 임상적으로 의미 있는 비의도적 체중 감소를 보인다. (시작 정보)
- 근거 : 체중 감소와 함께 식욕 증가, 더위 탐, 안정 시 심계항진, 손떨림, 야간 발한을 호소해 갑상선중독증에 합당하다. (턴 1, 2, 3, 4, 8)
- 근거 : 진찰상 매끈하고 대칭적인 미만성 갑상선 비대와 양측 안구 돌출·안검 지연·안검 후퇴, 갑상선 잡음이 있어 그레이브스병을 강하게 시사한다. (턴 25, 26, 30)
- 근거 : 진찰상 규칙적 빈맥, 따뜻하고 습한 피부, 자세성 떨림, 항진된 슬개건 반사와 하지 근위부 근력 저하가 확인되어 갑상선기능항진의 임상 소견을 뒷받침한다. (턴 23, 28, 29, 31, 32)
- 근거 : 갈증 증가는 호소하지 않고 당뇨병 병력도 없어 당뇨병에 의한 체중 감소 가능성은 상대적으로 낮지만, 이를 배제할 수 있는 검사 결과는 없다. (턴 6, 7)
```

```
r/o 무통성 갑상선염 : 체중 감소와 갑상선항진 증상, 미만성 갑상선 비대는 고려 근거지만, 진찰상 안구 돌출·안검 징후와 갑상선 잡음은 그레이브스병 쪽을 더 지지한다 (시작 정보; 턴 1, 2, 25, 26, 30). 감별 검사 : TSH, 유리 T4/T3 및 갑상선 섭취율 검사
r/o 독성 갑상선결절 또는 독성 다결절갑상선종 : 갑상선항진 증상과 갑상선 비대는 고려할 수 있으나, 진찰상 갑상선은 대칭적인 미만성 비대이고 결절이 없으며 안구 징후가 동반된다 (시작 정보; 턴 3, 11, 25, 26). 감별 검사 : 갑상선 초음파와 갑상선 섬광촬영
r/o 당뇨병 : 비의도적 체중 감소, 식욕 증가와 소변 횟수의 약간 증가는 고려 근거지만 갈증 증가는 호소하지 않으며, 갑상선 미만성 비대와 안구 징후·잡음이 있어 현재 소견은 갑상선 질환에 더 잘 부합한다 (시작 정보; 턴 1, 6, 9, 25, 26, 30). 감별 검사 : 공복 혈당 및 당화혈색소
```

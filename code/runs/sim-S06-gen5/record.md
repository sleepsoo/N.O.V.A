## [A] 근거

```
#1. 제2형 당뇨병 (Type 2 diabetes mellitus)
- 근거 : 두세 달 전부터 갈증을 호소하고 물을 많이 마시며, 낮에 소변을 열 번 넘게 보고 밤에도 두세 번 깬다고 함 → 만성적인 다음·다뇨 양상이 제2형 당뇨병에 부합함. (시작 정보; 턴 2, 6)
- 근거 : 약 3kg 체중 감소와 심한 피로를 호소함 → 증상성 고혈당에서 나타날 수 있는 전신 증상임. (시작 정보; 턴 3, 7)
- 근거 : 이 년 전 검진에서 혈당이 높아 운동을 권유받았다고 함 → 이전 혈당 상승력이 현재 증상의 당뇨병 가능성을 높임. (턴 8, 9, 10)
- 근거 : 부모 모두 당뇨병이 있고, 아버지는 당뇨 합병증으로 투석 후 사망했다고 함 → 강한 가족력이 있음. (턴 12)
- 근거 : 진찰상 비만 체형이며 외음부 경도 발적과 소량의 흰색 분비물이 관찰됨 → 제2형 당뇨병 위험 체형이고, 생식기 증상은 고혈당에 동반될 수 있음. (턴 4, 22, 27)
- 근거 : 구역질과 복통은 없고 급성 병색도 관찰되지 않음 → 급성 중증 증상은 확인되지 않았으나, 당뇨병 자체를 배제하지는 않음. (턴 20, 22)
```

## [A] 감별진단

```
r/o 요붕증 (Diabetes insipidus) : 다음과 다뇨가 있어 고려할 수 있으나, 이전 혈당 상승력과 당뇨병 가족력은 제2형 당뇨병을 더 지지함 (시작 정보; 턴 6, 8, 12). 감별 검사 : 혈청 나트륨·혈청 및 소변 삼투압
r/o 만성 신장질환 (Chronic kidney disease) : 고혈압과 신장 투석을 받은 부친의 병력, 피로가 있어 고려함. 다만 현재 신기능 정보는 제시되지 않아 임상 증상만으로 판단할 수 없음 (시작 정보; 턴 9, 12). 감별 검사 : 혈청 크레아티닌/eGFR 및 소변 알부민-크레아티닌 비
r/o 고칼슘혈증 (Hypercalcemia) : 피로와 다음·다뇨를 설명할 수 있어 고려함. 구역질과 복통은 호소하지 않으나 이 음성 소견만으로 배제할 수 없음 (시작 정보; 턴 6, 20). 감별 검사 : 혈청 총칼슘 및 알부민(필요 시 이온화 칼슘)
r/o 갑상선기능저하증 (Hypothyroidism) : 피로를 호소해 고려할 수 있으나, 체중 감소와 다음·다뇨 양상은 갑상선기능저하증보다 당뇨병에 더 부합함 (시작 정보; 턴 6, 7). 감별 검사 : 혈청 TSH 및 유리 T4
```

## [A] 근거

```
#1. 졸피뎀(진정수면제) 사용장애 (Sedative, hypnotic, or anxiolytic use disorder)
- 근거 : 졸피뎀 10mg 정을 밤에 5~6알, 가끔 낮에도 복용한다고 호소함 → 복용량이 크게 증가한 고용량 사용임. (턴 2, 4)
- 근거 : 복용량이 반 알에서 서너 알로 늘었다고 호소함 → 내성에 부합하는 복용량 증가가 있음. (턴 6)
- 근거 : 감량·중단을 여러 번 시도했으나 실패했고, 약을 먹지 않으면 불안과 손 떨림이 있다고 호소함 → 조절 실패와 금단 관련 증상을 시사함. (턴 7, 8)
- 근거 : 여러 진료과·기관에서 처방받고 약국 수면유도제도 가끔 함께 복용한다고 호소함 → 복수 경로의 약물 확보와 병용 위험이 있음. (턴 9, 10)
- 근거 : 진찰상 반응 지연, 졸림, 불안·초조가 관찰되었으나 급성 중독 징후는 없고 의식과 지남력은 명료함 → 주간 진정 증상은 있으나 급성 중독 상태를 뒷받침하지 않음. (턴 25, 26)
- 근거 : 약 복용 후 기억이 끊길 때가 있다고 호소했고, 진찰상 MMSE-K 28/30점, 지연회상 2/3점임 → 약물 관련 기억 영향 가능성을 고려하되, 이 소견만으로 주요 인지장애를 진단할 수 없음. (턴 12, 27)
```

## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 다이어트나 운동 변화 없이 3개월간 약 56kg에서 49kg으로 7kg 감소 → 임상적으로 의미 있는 비의도적 체중 감소입니다. (시작 정보)
- 근거 : 체중 감소에도 식욕은 좋고 예전보다 더 먹음 → 대사 항진 상태와 부합합니다. (시작 정보; 턴 10)
- 근거 : 두근거림, 손떨림, 더위 탐, 불면, 피로를 호소함 → 갑상샘중독증에서 흔한 증상 조합입니다. (턴 5, 6, 7, 8, 9)
- 근거 : 진찰상 양측 대칭성 미만성 갑상샘 비대와 잡음이 있고 결절은 없음 → 미만성 갑상샘 과기능을 시사합니다. (턴 31, 38)
- 근거 : 진찰상 안검 지연·안검 후퇴·안구 돌출이 양측에서 확인됨 → 그레이브스병의 갑상샘 안병증을 강하게 뒷받침합니다. (턴 28)
- 근거 : 진찰상 규칙적인 빈맥과 자세성 떨림이 있고, 복용약·영양제는 없다고 함 → 갑상샘 자극 약물 노출보다 내인성 갑상샘 과기능이 더 의심됩니다. 모친의 갑상샘 질환력도 있습니다. (턴 14, 20, 29, 30)
```

## [A] 감별진단

```
r/o 독성 다결절 갑상샘종 : 두근거림·손떨림·더위 탐은 갑상샘중독증과 맞지만, 진찰상 갑상샘은 미만성으로 커져 있고 결절은 없으며 안구 소견이 확인되어 그레이브스병이 더 적합합니다 (턴 5, 6, 7, 28, 38). 감별 검사 : 갑상샘 초음파, 갑상샘 섭취율 검사
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 두근거림 등은 갑상샘중독증에 부합하나, 진찰상 갑상샘 잡음과 양측 안구 소견은 그레이브스병 쪽에 더 부합합니다. 갑상샘 압통은 없습니다 (시작 정보; 턴 5, 28, 31, 38). 감별 검사 : 갑상샘 섭취율 검사, 적혈구침강속도 또는 C-반응단백
r/o 당뇨병 : 체중 감소, 식욕 증가, 소변 횟수 증가 호소는 고려할 근거이나, 갑상샘 안징후와 미만성 갑상샘 비대·잡음은 당뇨병만으로 설명하기 어렵습니다 (시작 정보; 턴 10, 22, 28, 31, 38). 감별 검사 : 공복 혈당, 당화혈색소
```

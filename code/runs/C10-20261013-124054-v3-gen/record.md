## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 3개월간 비의도적으로 56kg에서 49kg으로 약 7kg 감소했고 다이어트나 운동은 하지 않았으며, 현재 BMI는 18.2이다 → 임상적으로 의미 있는 비의도적 체중 감소이다. (시작 정보)
- 근거 : 체중 감소에도 식욕이 좋고 더 많이 먹으며, 자주 두근거리고 손이 떨리며 더위와 발한을 호소한다 → 갑상샘항진증에 합당한 증상 조합이다. (턴 4, 5, 8, 10)
- 근거 : 진찰상 갑상샘이 대칭적으로 미만성 비대하고 잡음이 들리며 안구돌출·안검 지연·안검 후퇴가 확인된다 → 그레이브스병을 강하게 시사한다. (턴 20, 21, 22)
- 근거 : 진찰상 맥박 102회/분, 자세성 떨림, 슬개건 반사 항진, 따뜻하고 땀이 나는 피부가 확인된다 → 갑상샘항진의 신체 소견과 부합한다. (턴 23, 24, 25, 27)
- 근거 : 모친에게 갑상샘 저하증 병력이 있다 → 갑상샘 질환 가족력이 있다. (턴 17)
- 근거 : 진찰상 갑상샘 결절, 복부 종괴, 경부·액와 림프절 촉지가 없다 → 촉진상 결절성 갑상샘 질환이나 종괴·림프절 비대는 확인되지 않는다. (턴 20, 28, 29, 30)
```

## [A] 감별진단

```
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 두근거림 등은 갑상샘중독증과 맞지만, 진찰상 갑상샘 잡음과 안징후는 그레이브스병을 더 지지한다 (시작 정보; 턴 4, 21, 22). 감별 검사 : TSH, 유리 T4
r/o 독성 갑상샘결절 또는 다결절성 갑상샘종 : 체중 감소와 두근거림은 가능하지만, 진찰상 결절 없이 대칭적인 미만성 갑상샘 비대가 확인되어 가능성이 낮다 (시작 정보; 턴 4, 20). 감별 검사 : 갑상샘 초음파, 갑상샘 스캔
r/o 당뇨병 : 비의도적 체중 감소와 식욕 증가는 고려할 근거이나, 수분 섭취는 예전과 같고 갑상샘항진을 시사하는 증상·진찰 소견이 뚜렷하다 (시작 정보; 턴 8, 12, 21, 22). 감별 검사 : 공복 혈당, 당화혈색소
r/o 위장관 질환 또는 흡수장애 : 하루 2~3회의 이전보다 묽은 변과 비의도적 체중 감소가 있어 고려할 수 있으나, 뚜렷한 갑상샘항진 증상과 진찰 소견이 함께 확인된다 (시작 정보; 턴 11, 20, 21, 22). 감별 검사 : 혈액검사(CBC, 전해질), 임상 소견에 따른 대변검사 또는 흡수장애 검사
```

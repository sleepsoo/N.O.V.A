## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 보호자 호소상 1년간 키가 약 100cm에서 105cm로 증가해 연간 성장속도는 약 5cm이며, 성장도표상 정상 하한이다 → 성장속도가 뚜렷하게 저하된 양상은 아니다. (시작 정보; 턴 25)
- 근거 : 진찰상 키는 105cm로 3백분위수 미만이고 체중은 3~10백분위수이다 → 저신장이 확인되나 성장속도와 함께 해석해야 한다. (턴 24, 25)
- 근거 : 아버지는 어릴 때 작았고 고등학교 때 많이 컸다고 한다 → 가족력상 체질성 성장지연 가능성을 뒷받침한다. (턴 5, 6)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이며 중간부모키는 178cm로 기록되어 있다 → 부모 키가 작은 가족성 저신장은 덜 지지된다. (턴 4, 25)
- 근거 : 진찰상 신체 비율은 정상이고 사춘기 성숙도는 Tanner 1기, 양측 고환 2mL이며 안면 기형은 없다 → 골격 비율 이상이나 이형성 소견은 확인되지 않는다. (턴 26, 27, 28)
- 근거 : 식사를 하루 세 끼 잘 하고 활발하게 놀며 쉽게 지치지 않는다고 하고, 갑상선은 비대·결절·압통이 없다 → 영양 부족이나 갑상선 질환을 뒷받침하는 병력·진찰 소견은 뚜렷하지 않다. (턴 10, 15, 29)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 : 키가 3백분위수 미만이고 최근 성장이 더딘 것 같다는 호소가 있으나, 기록된 성장속도는 정상 하한이다 (시작 정보; 턴 25). 감별 검사 : 골연령, IGF-1 및 IGFBP-3
r/o 가족성 저신장 : 아버지가 어릴 때 작았다는 병력은 있으나 부모 키와 중간부모키는 작지 않다 (턴 4, 6, 25). 감별 검사 : 성장기록 및 부모 키 재확인
r/o 갑상선기능저하증 : 저신장의 원인으로 고려할 수 있으나 쉽게 지치지 않고 갑상선 비대·결절·압통이 없다 (턴 10, 29). 감별 검사 : TSH, free T4
r/o 영양 부족 : 체중이 3~10백분위수로 낮은 편이지만 하루 세 끼 잘 먹고 체중이 갑자기 변하지 않았다고 한다 (턴 15, 17, 25). 감별 검사 : 영양 섭취 평가, CBC 및 대사·영양 지표
```

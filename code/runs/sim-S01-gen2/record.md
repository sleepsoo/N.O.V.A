```
그 뒤로 대변을 보지 않았고 설사는 없으며, 배뇨 시 따갑거나 아픈 증상 및 소변 색 변화는 없다고 함. 혈변·흑색변 및 등·사타구니·고환으로의 방사통은 없다고 함.
어제 소화제 1알을 복용했으며, 밤새 통증으로 잠을 거의 못 잤다고 함.
맹장염이 아닌지 걱정되어 내원함.
```

## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 어제 저녁 배꼽 주변에서 시작한 통증이 오늘 오른쪽 아랫배로 이동하고 시간에 따라 심해졌다는 호소는 충수염의 전형적 통증 경과에 부합함. (시작 정보; 턴 2)
- 근거 : 걷거나 기침할 때 통증이 악화되고 통증 점수가 7점이며, 메스꺼움·구토와 오한을 호소함; 염증성 복강 질환 가능성을 뒷받침함. (턴 4, 7, 11, 17)
- 근거 : 진찰상 우하복부 압통과 국한된 근성방어, 맥버니점 압통 및 반발압통이 확인되어 국소 복막 자극 소견을 보임. (턴 26, 27, 28)
- 근거 : 진찰상 우측 요근 징후가 양성이고 오른쪽 다리를 굴곡한 자세를 취함; 우하복부 염증과 부합함. (턴 22, 29)
- 근거 : 배뇨통·소변 색 변화·등이나 사타구니로의 방사 통증을 호소하지 않고 늑척추각 압통도 없어 요관결석 가능성을 낮춤. (턴 5, 18, 30)
- 근거 : 설사를 호소하지 않고 가족 염증성 장질환력도 없어 감염성 위장염이나 말단 회장염의 상대적 가능성을 낮추는 소견임. (턴 8, 19)
```

## [A] 감별진단

```
r/o 감염성 위장염 : 메스꺼움과 구토, 오한은 고려 근거이나 설사는 없고 진찰상 우하복부에 압통·근성방어·반발압통이 국한되어 있어 급성 충수염보다 덜 부합함 (턴 7, 8, 26, 28). 감별 검사 : 복부 CT, 필요 시 대변 병원체 검사
r/o 말단 회장염 : 우하복부 통증과 메스꺼움은 고려 근거이나 설사 및 가족 염증성 장질환력은 없고, 국소 복막 자극 소견은 충수염에 더 부합함 (턴 2, 7, 8, 19, 26, 28). 감별 검사 : 복부 CT, 혈액검사(CBC·CRP)
r/o 요관결석 : 복통과 우하복부 통증으로 고려할 수 있으나 배뇨통이나 통증 방사는 없고 늑척추각 압통도 확인되지 않아 가능성이 낮음 (시작 정보; 턴 2, 5, 18, 30). 감별 검사 : 요검사, 비조영 복부·골반 CT
```

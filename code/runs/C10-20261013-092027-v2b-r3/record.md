## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves disease causing hyperthyroidism)
- 근거 : 호소상 다이어트나 운동 없이 3개월간 약 56kg에서 49kg으로 약 7kg(약 12.5%) 감소했고, 예전보다 더 많이 먹음 → 식욕 증가를 동반한 비의도적 체중 감소는 대사 항진을 시사함. (시작 정보; 턴 1)
- 근거 : 호소상 더위 탐, 안정 시 심계항진, 손떨림, 야간 발한이 있고 변이 예전보다 묽어짐 → 갑상샘호르몬 과다 상태와 부합함. (턴 2, 3, 4, 5, 8)
- 근거 : 진찰상 갑상샘이 양측 대칭적으로 미만성 비대하고 표면이 매끄러우며 결절은 촉지되지 않고 잡음이 들림 → 미만성 혈류 증가를 동반한 갑상샘 비대는 그레이브스병을 지지함. (턴 25, 30)
- 근거 : 진찰상 양측 안구 돌출, 안검 지연 및 안검 후퇴가 확인됨 → 갑상샘 안병증 소견은 그레이브스병을 강하게 지지함. (턴 26)
- 근거 : 진찰상 맥박 102회/분, 피부 온난 및 발한, 양측 자세성 떨림, 슬개건 반사 항진과 하지 근위부 근력 저하가 있음 → 갑상샘항진증의 전신 소견과 부합함. (턴 23, 28, 29, 32, 33)
- 근거 : 모친의 갑상샘 질환 가족력이 있으며, 갈증 증가는 호소하지 않고 갑상샘 관련 약·영양제 복용도 없음 → 자가면역성 갑상샘 질환 가능성을 고려하게 하고, 당뇨병 및 외인성 갑상샘호르몬 노출 가능성은 상대적으로 낮춤. (턴 6, 11, 12)
```

## [A] 감별진단

```
r/o 독성 갑상샘결절 질환 : 체중 감소와 심계항진 등 갑상샘항진증을 시사하는 호소는 있으나, 진찰상 결절 없는 대칭성 미만성 갑상샘 비대와 안구 돌출·안검 징후는 그레이브스병에 더 부합함 (시작 정보; 턴 3, 25, 26). 감별 검사 : 갑상샘 초음파 및 방사성요오드 섭취율 검사
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 더위 탐, 심계항진은 갑상샘중독증에 부합하지만, 진찰상 갑상샘 잡음과 양측 안구 돌출·안검 징후는 갑상샘염보다 그레이브스병을 지지함. 갑상샘 압통은 진찰상 없음 (시작 정보; 턴 2, 3, 25, 26, 30). 감별 검사 : 갑상샘 기능검사와 방사성요오드 섭취율 검사
r/o 당뇨병 : 비의도적 체중 감소와 배뇨 횟수가 예전과 비슷하거나 조금 증가했다는 호소는 고려 근거이나, 갈증 증가는 없고 미만성 갑상샘 비대·갑상샘 안징후가 확인되어 현재 증상을 더 잘 설명하는 것은 갑상샘 질환임 (시작 정보; 턴 6, 15, 25, 26). 감별 검사 : 공복 혈당 및 당화혈색소
```

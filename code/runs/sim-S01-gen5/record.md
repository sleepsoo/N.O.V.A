## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 어제 저녁 배꼽 주변에서 시작한 통증이 오늘 아침부터 우하복부로 이동해 더 아프다고 호소함 → 충수염에 전형적인 통증 이동 양상임. (시작 정보)
- 근거 : 우하복부 통증을 10점 중 7점으로 호소하고, 걷거나 기침할 때 더 아프다고 함 → 국소 복막 자극을 시사함. (턴 14, 15)
- 근거 : 진찰상 우하복부 국한 근성방어와 압통, 맥버니점 압통 및 반발압통이 확인됨 → 우하복부의 국소 염증과 복막 자극 소견에 부합함. (턴 21, 22, 23)
- 근거 : 진찰상 우측 요근 징후와 로브싱 징후가 양성임 → 충수염 가능성을 뒷받침함. (턴 24, 25)
- 근거 : 열과 오한을 호소하고 메스꺼움 및 구토 1회가 있음 → 급성 염증성 복부 질환과 동반될 수 있는 증상임. (턴 4, 7)
- 근거 : 배뇨통이 없고 소변 색이 평소와 같다고 호소하며, 진찰상 양측 늑척추각 압통이 없음 → 요로계 원인을 덜 지지함. (턴 9, 26)
```

## [A] 감별진단

```
r/o 급성 위장관염 : 메스꺼움, 구토와 발열 호소는 가능하지만, 배꼽 주변에서 우하복부로 이동한 통증과 우하복부 국한 압통·반발압통은 충수염을 더 지지함 (시작 정보; 턴 4, 7, 21, 23). 감별 검사 : 복부 CT
r/o 요관결석 : 우하복부 통증은 고려할 근거이나, 배뇨통이 없고 소변 색이 평소와 같다고 호소하며 늑척추각 압통도 없어 가능성이 낮아짐 (턴 9, 13, 26). 감별 검사 : 요검사, 복부·골반 CT
r/o 장간막 림프절염 : 젊은 연령과 발열·복통은 고려할 근거이나, 통증의 우하복부 이동과 국소 근성방어, 맥버니 압통 및 반발압통은 급성 충수염에 더 부합함 (시작 정보; 턴 4, 21, 22, 23). 감별 검사 : 복부 초음파 또는 복부 CT
```

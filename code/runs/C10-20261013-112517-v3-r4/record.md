## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 다이어트나 운동 없이 3개월간 56kg에서 49kg으로 약 7kg 감소(약 12.5%)하고, 식사량은 오히려 증가했다고 호소 → 갑상샘중독증에 합당한 비의도적 체중 감소 양상 (시작 정보; 턴 7)
- 근거 : 더위 민감, 안정 시 심계항진, 잔을 들 때 손떨림을 호소 → 갑상샘기능항진증을 시사하는 증상 조합 (턴 4, 5, 6, 8)
- 근거 : 진찰상 양측 안구 돌출과 안검 지연·후퇴가 확인됨 → 그레이브스병 관련 갑상샘안병증을 강하게 시사 (턴 24)
- 근거 : 진찰상 갑상샘이 양측 대칭으로 미만성 비대하고 잡음이 들리며, 결절과 압통은 없음 → 미만성 혈류 증가를 동반한 그레이브스병에 합당 (턴 28, 35)
- 근거 : 진찰상 규칙적 맥박 102회/분, 자세성 떨림, 온난하고 습윤한 피부 및 발한이 확인됨 → 갑상샘호르몬 과다 상태를 뒷받침 (턴 25, 26, 27)
- 근거 : 모친이 갑상샘저하증으로 약을 복용한다고 호소 → 갑상샘 질환 가족력이 있으나 모친 질환의 원인은 확인되지 않음 (턴 11)
```

```
r/o 독성 결절성 갑상샘종 : 체중 감소와 심계항진 등 갑상샘기능항진증 양상은 고려 근거이나, 목 혹을 부인하고 진찰상 갑상샘은 결절 없이 양측 대칭으로 미만성 비대하여 덜 합당함 (시작 정보; 턴 5, 22, 35). 감별 검사 : 갑상샘 초음파
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 갑상샘기능항진증 양상은 고려 근거이나, 진찰상 갑상샘 압통이 없고 잡음 및 안구 돌출·안검 징후가 있어 그레이브스병이 더 합당함 (시작 정보; 턴 4, 24, 28, 35). 감별 검사 : TSH 및 유리 T4, 갑상샘 자가항체 검사
r/o 당뇨병 : 비의도적 체중 감소와 소변 횟수가 약간 늘어난 듯하다는 호소는 고려 근거이나, 갈증 증가를 부인하고 갑상샘 미만성 비대·잡음 및 안구 징후가 있어 주된 원인으로는 덜 합당함 (시작 정보; 턴 9, 20, 24, 28, 35). 감별 검사 : 공복 혈당 및 당화혈색소
```

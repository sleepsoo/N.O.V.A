## [A] 감별진단

```
r/o 성장호르몬 결핍 : 성장 속도는 정상 하한에 머물고 폐리 없음. IGF‑1, GH 역응검사로 감별.
r/o 갑상선 기능저하 : 갑상선 촉진 비대·결절·압통 없음, 체온 정상. 갑상선 기능 검사(TSH, FT4)로별.
r/o 골격형성 이상 : 상·하절 비율 정상, 머리둘레와 비율 없음. 뼈 발달 X‑선 또는 골밀도 검사로 감별.
r/o 정상성 성장 지연 : 가족력과 일치하지만 다른 특이소견 부재. 성장 호르몬 검사 및 유전검사로 최종 판정.
```

## [P] 추가 검사

```
- 혈액 검사: CBC, 전기질, TSH·FT4, IGF‑1, 성장호르몬 측정 – 주 진단 확인 및 성장호르몬 결핍 배제
- 비타민 D, 철분, B12 수치 – 영양소 결핍 여부 확인
- 손목 X‑선(손발골) – 골연령과 성장판 상태 평가
- 대뇌하수체 MRI(필요 시) – 구조적 이상 여부 검토
```

## [P] 치료

```
- 성장호르몬 치료 시작 고려(검사 결과 높지 않은 IGF‑1 및 골연령 저하 확인 시)
- 영양 상담 및 규칙적 운동(단백·칼로리·계통 강화)
- 정기적 성장 모니터링(신장·체중·BMI) – 진행과 부작용 감시
- 금기 확인 후 통증·비간온 충격 완화제 사용 시 주의
```

```

- 성장에 관한 염려시 증상(특히 두통·시야 변화·갑상선 증상) 시 즉시 진료
```

## [A] 근거

```
#1. 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 (Lumbar disc herniation causing left S1 radiculopathy)
- 근거 : 열흘 전 허리 통증이 시작됐고, 허리보다 다리 통증이 더 심하다고 호소함 → 신경근성 방사통을 시사 (시작 정보; 턴 2)
- 근거 : 오래 앉기, 기침·재채기 시 통증과 다리로 뻗치는 통증이 심해진다고 호소함 → 추간판성 신경근 자극에 부합 (턴 4)
- 근거 : 좌측 둔부에서 후대퇴·종아리를 거쳐 발 외측과 새끼발가락까지 전기 오듯 찌릿한 통증을 호소함 → S1 신경근 분포의 방사통에 부합 (턴 6)
- 근거 : 진찰상 좌측 발 외측·새끼발가락의 감각 저하와 좌측 아킬레스건 반사 저하가 확인됨 → 좌측 S1 신경근 병변을 지지 (턴 24, 25)
- 근거 : 진찰상 좌측 하지직거상 40도에서 방사통이 재현됨 → 신경근 긴장 징후에 부합 (턴 26)
- 근거 : 이삿짐을 옮기다 허리를 삐끗한 뒤 발병했다고 호소함 → 기계적 부하에 따른 추간판 병변 가능성을 뒷받침; 대소변 문제와 회음부 감각 저하는 호소하지 않음 → 마미증후군을 시사하는 증상은 확인되지 않음 (시작 정보; 턴 9, 16)
```

## [A] 감별진단

```
r/o 급성 요추 염좌 : 짐을 옮기다 허리를 삐끗한 뒤 허리 통증이 시작됐다는 호소는 지지하지만, 발 외측까지 뻗치는 통증과 S1 감각·반사 이상 및 양성 하지직거상은 단순 염좌만으로 설명하기 어려움 (시작 정보; 턴 6, 24, 25, 26). 감별 검사 : 증상이 지속되거나 신경학적 이상이 진행하면 요추 MRI
r/o 이상근 증후군 : 좌측 둔부에서 후대퇴로 이어지는 통증은 고려 근거이나, 발 외측 감각 저하와 좌측 아킬레스건 반사 저하는 신경근 병변을 더 지지함 (턴 6, 24, 25). 감별 검사 : FAIR 검사 및 필요 시 골반 MRI
r/o 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 : 기침·재채기로 악화되는 방사통, S1 분포 통증·감각 저하, 좌측 아킬레스건 반사 저하와 양성 하지직거상이 서로 부합함 (턴 4, 6, 7, 24, 25, 26). 감별 검사 : 요추 MRI
```

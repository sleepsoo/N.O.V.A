## [A] 근거

```
#1. 체질성 성장지연 (Constitutional growth delay)
- 근거 : 현재 키 105cm가 신장 3백분위수 미만이고, 최근 1년 성장속도는 약 5cm/년으로 정상 하한이다 → 저신장이 있으나 성장속도는 유지되고 있다. (시작 정보; 턴 25, 26, 27)
- 근거 : 아버지는 고등학교 때 키가 많이 컸다고 한다 → 가족 내 늦은 성장 시기가 체질성 성장지연을 뒷받침한다. (턴 5)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이고 중간부모키는 178cm이다 → 부모 키 자체가 작은 가족성 저신장 양상은 아니다. (턴 4, 26, 27)
- 근거 : 진찰상 상·하절 비율이 정상이고 양팔간격 불균형 및 안면 기형 소견이 없다 → 뚜렷한 체형 불균형이나 외형상 증후군 소견은 확인되지 않았다. (턴 28, 30)
- 근거 : 하루 세 끼 잘 먹고 체중이 1년간 15kg에서 16.5kg으로 증가했으며, 알려진 장·콩팥 질환과 스테로이드 복용력이 없다 → 영양 부족이나 만성질환 관련 성장 저하를 뒷받침하는 병력은 적다. (시작 정보; 턴 7, 8, 18)
- 근거 : 변비 호소가 없고 진찰상 갑상선 비대·결절이 없다 → 갑상선기능저하증을 시사하는 일부 병력·진찰 소견은 확인되지 않았다. (턴 10, 31)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 : 키가 3백분위수 미만이고 중간부모키가 178cm로 현재 키와 차이가 있으나, 성장속도는 5cm/년으로 정상 하한이다 (턴 26, 27). 감별 검사 : IGF-1 및 IGFBP-3 측정; 이상 소견이 있으면 성장호르몬 자극검사
r/o 갑상선기능저하증 : 저신장은 성장호르몬 외 내분비 원인 평가가 필요하지만, 변비 호소가 없고 진찰상 갑상선 비대·결절이 없다 (턴 10, 26, 31). 감별 검사 : TSH 및 유리 T4
r/o 가족성 저신장 : 성장속도는 정상 하한이나 부모 키가 아버지 178cm, 어머니 165cm이고 중간부모키가 178cm여서 부모 키가 작은 양상과 맞지 않는다 (턴 4, 26, 27). 감별 검사 : 부모의 실제 키 확인 및 과거 성장기록 검토
r/o 영양 부족 또는 만성 전신질환에 의한 성장 저하 : 저신장과 체중 3~10백분위수는 고려 요인이지만, 하루 세 끼 잘 먹고 체중이 1년간 증가했으며 장·콩팥 질환 병력이 없다 (시작 정보; 턴 7, 18, 25, 26). 감별 검사 : CBC, 대사·간·신장 기능 검사 및 염증 지표
```

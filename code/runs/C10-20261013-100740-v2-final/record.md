## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 비의도적으로 3개월간 약 7 kg 감소했고 다이어트나 운동은 하지 않음 → 유의한 비의도적 체중감소 (시작 정보)
- 근거 : 더 많이 먹는데도 체중이 감소하고, 더위탐·안정 시 심계항진·손떨림·야간 발한을 호소함 → 갑상샘항진 상태를 시사 (턴 1, 2, 3, 4, 10)
- 근거 : 진찰상 양측 대칭성 미만성 갑상샘 비대와 갑상샘 잡음이 있음 → 미만성 갑상샘 과혈류 소견으로 그레이브스병에 부합 (턴 24, 29)
- 근거 : 진찰상 양측 안구돌출, 안검 지연 및 안검 후퇴가 있고 자세성 떨림·온난하고 습윤한 손바닥도 확인됨 → 그레이브스병의 안구 소견과 갑상샘항진 징후에 부합 (턴 25, 27, 28)
- 근거 : 모친에게 갑상샘질환 병력이 있음 → 갑상샘질환 가족력이 진단의 배경이 됨 (턴 15)
- 근거 : 갑상샘 결절과 압통이 없고 갑상샘 관련 약물·영양제 복용도 없음 → 결절성 원인 및 외인성 갑상샘호르몬 노출 가능성을 낮춤 (턴 14, 24)
```

## [A] 감별진단

```
r/o 독성 결절성 갑상샘종 : 체중감소와 심계항진·손떨림 등 갑상샘항진 소견은 고려 근거이나, 진찰상 결절 없이 양측 대칭성 미만성 비대와 안구돌출이 있어 그레이브스병이 더 부합함 (시작 정보; 턴 3, 4, 24, 25). 감별 검사 : 갑상샘 초음파 및 갑상샘 스캔
r/o 갑상샘염에 의한 갑상샘중독증 : 갑상샘항진 증상은 고려 근거이나, 갑상샘 압통이 없고 진찰상 잡음 및 안구 소견이 확인되어 덜 부합함 (턴 2, 3, 24, 25, 29). 감별 검사 : TSH·유리 T4 및 갑상샘 섭취율 검사
r/o 당뇨병 : 식욕 증가와 비의도적 체중감소는 고려할 수 있으나, 수분 섭취는 평소와 같다고 하며 진찰상 미만성 갑상샘 비대와 갑상샘항진 소견이 있어 현재는 덜 부합함 (시작 정보; 턴 1, 6, 24, 27, 28). 감별 검사 : 공복 혈당 및 당화혈색소
r/o 위장관 흡수장애 : 비의도적 체중감소와 평소보다 묽은 변은 고려 근거이나, 식욕 증진과 안구·갑상샘 진찰 소견은 갑상샘 원인을 더 지지함 (시작 정보; 턴 1, 5, 24, 25). 감별 검사 : 혈액검사 및 대변검사
```

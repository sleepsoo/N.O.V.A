## [A] 근거

```
#1. 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 (Left S1 radiculopathy due to lumbar disc herniation)
- 근거 : 이삿짐을 옮기다 허리를 삐끗한 뒤 10일 전부터 허리 통증이 시작됨 → 급성 요추 추간판 병변의 유발 상황과 시간 경과에 부합함. (시작 정보)
- 근거 : 사흘째부터 왼쪽 엉덩이에서 허벅지 뒤·종아리·새끼발가락까지 전기 찌릿하게 뻗침 → S1 신경근 분포의 방사통에 부합함. (턴 9)
- 근거 : 오래 앉기와 기침·재채기 시 허리 및 다리 통증이 악화됨 → 신경근 자극을 동반한 추간판 병변을 지지함. (턴 3)
- 근거 : 진찰상 좌측 하지직거상 검사에서 40도에 방사통이 유발되고, 좌측 발 외측·새끼발가락 감각 저하와 아킬레스건 반사 감소가 확인됨 → 좌측 S1 신경근 이상을 뒷받침함. (턴 21, 23, 24)
- 근거 : 진찰상 족저굴곡 근력이 우측 5/5, 좌측 4/5임 → 좌측 신경근 기능 저하 소견에 부합함. (턴 22)
- 근거 : 배뇨·배변 장애, 요폐, 회음부 감각 저하, 발열, 체중 감소 및 암 병력이 없고 극돌기 타진 압통도 없음 → 마미증후군이나 감염·종양성 원인을 시사하는 병력 및 진찰 소견은 확인되지 않음. (턴 6, 7, 12, 15, 20)
```

## [A] 감별진단

```
r/o 요추 염좌 또는 근육 긴장 : 짐을 옮기다 허리를 삐끗한 뒤 허리 통증이 시작된 점은 지지하지만, 왼쪽 다리 원위부까지 뻗치는 통증과 S1 감각 저하 및 양성 하지직거상 검사는 단순 염좌만으로 설명하기 어려움 (시작 정보; 턴 9, 21, 23). 감별 검사 : 지속되거나 악화될 경우 요추 MRI
r/o 요추 신경공 협착에 의한 좌측 신경근병증 : 좌측 다리 방사통과 S1 영역의 감각·반사 변화는 신경근병증에 부합하나, 급성으로 삐끗한 뒤 증상이 시작된 경과는 퇴행성 협착보다 급성 추간판 병변을 더 지지함 (시작 정보; 턴 9, 23, 24). 감별 검사 : 요추 MRI
r/o 이상근 증후군 : 엉덩이에서 다리로 이어지는 통증은 고려 근거이나, 기침·재채기 시 악화되고 하지직거상 검사 양성 및 S1 영역 감각·반사 변화가 있어 요추 신경근 병변이 더 타당함 (턴 2, 3, 21, 23, 24). 감별 검사 : FAIR 검사 또는 이상근 신장 유발 검사
```

## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 현재 키 105cm이고 신장 백분위수가 3백분위수 미만이며, 1년간 약 5cm 성장해 성장속도는 정상 하한으로 평가됨 → 저신장이지만 성장속도 저하가 뚜렷하지 않음. (시작 정보; 턴 24, 25)
- 근거 : 아버지 키 178cm, 어머니 키 165cm이며 중간부모키는 178cm로 기록됨 → 부모 키가 작은 가족성 저신장을 지지하지 않음. (턴 4, 25)
- 근거 : 아버지가 고등학교 때 많이 컸다고 함 → 가족 내 늦은 성장 시기가 체질성 성장지연 가능성을 뒷받침함. (턴 5)
- 근거 : 진찰상 상·하절 비율 정상, 양팔간격 불균형과 안면 기형 소견 없음 → 명백한 체형 불균형 또는 증후군성 외형을 시사하는 소견이 없음. (턴 26, 28)
- 근거 : 식사를 하루 세 끼 잘하고, 급격한 체중 감소가 없으며 1년간 체중이 1.5kg 증가함 → 병력상 뚜렷한 영양 섭취 저하나 급격한 체중 감소는 확인되지 않음. (시작 정보; 턴 15, 16)
- 근거 : 변비가 없고 진찰상 갑상선 비대·결절이 없음 → 갑상선기능저하증을 뒷받침하는 일부 임상 소견은 확인되지 않으나, 검사 없이 배제할 수는 없음. (턴 11, 29)
```

## [A] 감별진단

```
r/o 가족성 저신장 : 키가 3백분위수 미만인 점은 고려할 수 있으나, 부모 키가 각각 178cm와 165cm이고 중간부모키가 178cm로 기록되어 전형적인 가족성 저신장과는 맞지 않음 (턴 4, 25). 감별 검사 : 성장기록 재확인 및 골연령 평가
r/o 성장호르몬 결핍 : 키가 3백분위수 미만이어서 감별이 필요하나, 성장속도는 연 5cm로 정상 하한이며 성장호르몬 결핍을 확정할 자료는 없음 (시작 정보; 턴 25). 감별 검사 : IGF-1 및 IGFBP-3 측정, 필요 시 성장호르몬 자극검사
r/o 갑상선기능저하증 : 저신장의 내분비 원인으로 고려할 수 있으나 변비 호소가 없고 진찰상 갑상선 비대나 결절이 없음. 갑상선 기능검사는 제시되지 않음 (턴 11, 29). 감별 검사 : TSH 및 유리 T4 측정
r/o 영양 부족 : 체중이 3~10백분위수로 낮은 편이어서 고려할 수 있으나, 하루 세 끼 잘 먹고 1년간 체중이 증가했으며 급격한 체중 감소는 없음 (시작 정보; 턴 15, 16, 25). 감별 검사 : 식이 및 열량 섭취 평가, CBC 및 대사·영양 상태 검사
```

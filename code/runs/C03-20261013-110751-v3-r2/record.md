## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 현재 키 105cm로 신장 3백분위수 미만이며, 최근 1년 키 증가는 약 5cm로 성장속도 정상 하한이다 → 저신장이 확인되지만 성장속도가 현저히 저하된 양상은 아니다. (시작 정보; 턴 27)
- 근거 : 아버지는 고등학교 때 많이 컸고 어릴 때 작았던 가족력은 아버지에게만 있다 → 가족 내 늦은 성장 양상은 체질성 성장지연을 지지한다. (턴 6, 7)
- 근거 : 아버지 키 178cm, 어머니 키 165cm이고 중간부모키는 178cm로 기록되어 있다 → 부모 자체가 작은 가족성 저신장으로 설명하기는 어렵다. (턴 5, 27)
- 근거 : 상·하절 비율이 정상이고 양팔간격 불균형이 없으며, 안면 기형 소견도 없다 → 신체 비율 이상이나 뚜렷한 기형 소견은 확인되지 않는다. (턴 28, 30)
- 근거 : 만성질환이 없고 하루 세 끼 잘 먹으며, 변비·추위 탐이 없고 갑상선 비대나 결절이 없다 → 문진과 진찰에서 만성질환, 영양 문제 또는 갑상선기능저하증을 시사하는 소견은 뚜렷하지 않다. (턴 8, 11, 23, 37)
```

## [A] 감별진단

```
r/o 가족성 저신장 (Familial short stature) : 현재 키가 3백분위수 미만이고 아버지가 어릴 때 작았던 병력은 고려 근거이나, 부모 키와 중간부모키가 작지 않아 가족성 저신장 가능성은 상대적으로 낮다 (턴 5, 7, 27). 감별 검사 : 부모 키와 성장기록 재확인, 성장도표 추적
r/o 성장호르몬 결핍증 (Growth hormone deficiency) : 저신장과 보호자가 느낀 최근 성장 둔화는 고려 근거이나, 기록된 성장속도는 연 5cm로 정상 하한이다 (시작 정보; 턴 27). 감별 검사 : IGF-1·IGFBP-3 측정, 필요 시 성장호르몬 자극검사
r/o 갑상선기능저하증 (Hypothyroidism) : 저신장으로 감별할 수 있으나 변비나 추위 탐이 없고 갑상선 진찰상 비대·결절·압통이 없다 (턴 11, 37). 감별 검사 : TSH, 유리 T4 측정
r/o 영양 부족 또는 만성 질환에 의한 성장 저하 (Growth impairment due to undernutrition or chronic disease) : 체중이 3~10백분위수로 낮은 편이어서 고려할 수 있으나, 식사를 잘하고 알려진 만성질환이 없으며 다른 불편 증상을 호소하지 않는다 (턴 3, 8, 23, 27). 감별 검사 : 식사·성장기록 평가, CBC·대사검사 및 염증표지자
```

## [A] 근거

```
#1. 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 (Lumbar intervertebral disc herniation with left S1 radiculopathy)
- 근거 : 이삿짐을 옮기다 허리를 삔 뒤 10일째 허리 통증을 호소하고, 통증 강도는 10점 중 7점이라고 호소함 → 무거운 물건을 든 뒤 발생한 급성 요추 질환에 부합함. (시작 정보; 턴 5)
- 근거 : 좌측 둔부에서 후대퇴와 발 외측까지 전기 오듯 찌릿하고, 기침·재채기와 오래 앉기로 악화된다고 호소함 → 좌측 신경근성 방사통을 시사함. (턴 2, 9)
- 근거 : 좌측 하지직거상 검사에서 40도에 방사통이 재현되고 우측은 음성임 → 좌측 신경근 자극 소견을 뒷받침함. (턴 25)
- 근거 : 진찰상 좌측 족저굴곡 근력은 Gr.4이고 좌측 아킬레스건 반사는 1+로 우측 2+보다 감소함 → S1 신경근 기능 저하와 부합함. (턴 22, 24)
- 근거 : 배뇨·배변 문제와 회음부 감각 저하를 호소하지 않고, 발열·오한·체중 감소 및 암 병력도 부인함 → 마미증후군이나 전신성·악성 원인을 뒷받침하는 병력은 확인되지 않음. (턴 6, 12, 14, 17)
```

## [A] 감별진단

```
r/o 급성 요추 염좌·근육 긴장 : 물건을 옮기다 허리를 삔 뒤 허리 통증이 시작되어 고려할 수 있으나, 좌측 발 외측까지 이어지는 전기 오듯 찌릿한 통증과 좌측 근력·아킬레스건 반사 저하는 단순 근육 긴장만으로는 설명하기 어려움 (시작 정보; 턴 2, 22, 24). 감별 검사 : 임상 경과와 진찰 재평가; 증상 지속 또는 신경학적 소견 악화 시 요추 MRI
r/o 천장관절 염좌 : 물건을 옮긴 뒤 발생했고 둔부 통증이 있어 고려할 수 있으나, 통증이 발 외측까지 방사하고 좌측 하지직거상 검사 양성 및 좌측 신경학적 이상이 있어 신경근 원인이 더 잘 맞음 (시작 정보; 턴 2, 22, 24, 25). 감별 검사 : 천장관절 유발 검사(예: thigh thrust, compression)
r/o 요추 신경근 자극 또는 압박 : 좌측 하지 방사통과 하지직거상 검사 양성, 좌측 족저굴곡 약화 및 아킬레스건 반사 감소가 이를 지지함. 영상 검사가 없어 원인 병변은 임상 소견만으로 확정할 수 없음 (턴 2, 22, 24, 25). 감별 검사 : 요추 MRI
```

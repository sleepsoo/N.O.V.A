## [A] 근거

```
#1. 만성폐쇄성폐질환 급성 악화 (Acute exacerbation of chronic obstructive pulmonary disease)
- 근거 : 수년간의 호흡곤란이 있었고 사흘 전부터 크게 악화되어 집 안에서 조금만 움직여도 숨이 참 → 만성 기저질환의 급성 악화 양상 (시작 정보)
- 근거 : 사흘 전부터 기침과 다량의 누렇고 끈적한 가래가 심해졌고 감기 접촉 후 콧물과 목 칼칼함이 남음 → 호흡기 감염이 악화 유발 요인일 가능성 (시작 정보; 턴 13, 20)
- 근거 : 만성폐쇄성폐질환 진단을 들은 적이 있고, 하루 한 갑 흡연을 거의 50년간 지속함 → COPD의 기저 병력과 주요 위험인자가 확인됨 (턴 12, 14)
- 근거 : 실내 공기 산소포화도 89%, 호흡음 감소, 호기 연장 및 미만성 호기성 천명음, 양측 과공명음과 술통형 흉곽 → 저산소혈증과 폐쇄성 기류 제한에 부합 (턴 22, 23, 24, 25)
- 근거 : 다리 부종과 급격한 체중 증가가 없고, 경정맥 팽창·수포음·S3가 관찰되지 않음 → 심부전 악화를 뒷받침하는 소견이 적음 (턴 8, 23, 27, 28, 29)
- 근거 : 발열을 부인하고 폐 청진상 수포음이 없으며 촉각 진탕이 확인되지 않음 → 폐렴 가능성을 낮추지만 영상검사 전 배제할 수는 없음 (턴 15, 23, 26)
```

## [A] 감별진단

```
r/o 폐렴 : 기침과 다량의 누런 가래, 오한·열감 호소가 있어 고려하지만 발열을 부인하고 청진상 수포음은 없음 (시작 정보; 턴 4, 15, 23). 감별 검사 : 흉부 X선
r/o 심부전 악화 : 호흡곤란과 베개를 하나 더 받치는 호소는 고려 요인이지만, 다리 부종·급격한 체중 증가·야간 호흡곤란이 없고 경정맥 팽창, 수포음, S3도 관찰되지 않음 (턴 7, 8, 19, 23, 27, 28, 29). 감별 검사 : BNP 또는 NT-proBNP, 흉부 X선
r/o 폐색전증 : 호흡곤란과 저산소혈증은 고려 요인이지만 종아리 압통이나 좌우 둘레 차이가 없고, 만성 COPD와 미만성 천명음 및 호기 연장으로 설명되는 소견이 있음 (시작 정보; 턴 22, 23, 30). 감별 검사 : 임상 사전확률에 따른 D-dimer 또는 폐동맥 CT 혈관조영술
r/o 급성 기관지염 : 감기 접촉 후 콧물·목 칼칼함과 기침·가래 악화가 있어 고려할 수 있으나, 알려진 COPD 병력과 저산소혈증 및 폐쇄성 진찰 소견을 함께 설명하기에는 COPD 급성 악화가 더 적합함 (시작 정보; 턴 14, 20, 22, 23). 감별 검사 : 흉부 X선으로 폐렴 등 대체 진단 평가
```

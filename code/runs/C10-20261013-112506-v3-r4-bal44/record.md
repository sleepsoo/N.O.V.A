## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 평소 약 56kg에서 석 달간 의도하지 않게 약 7kg 감소했고 다이어트나 운동은 하지 않았다고 호소함 → 유의한 비의도적 체중 감소임. (시작 정보)
- 근거 : 식욕 증가, 잦은 두근거림, 손떨림, 더위를 많이 탐, 묽은 변을 호소함 → 갑상샘중독증에 합당한 증상 조합임. (턴 4, 5, 6, 7, 8)
- 근거 : 진찰상 양측 대칭성 미만성 갑상샘 비대와 안구 돌출·안검 지연·안검 후퇴가 확인됨 → 그레이브스병을 강하게 지지하는 소견임. (턴 24, 33)
- 근거 : 진찰상 규칙적이고 강한 맥박이 분당 102회이며 자세성 떨림과 경도의 안절부절이 확인됨 → 갑상샘항진에 따른 교감신경 항진과 부합함. (턴 25, 26, 27)
- 근거 : 어머니에게 갑상샘저하증 가족력이 있음 → 갑상샘 질환의 가족력은 있으나, 특정 갑상샘 질환을 확진하는 소견은 아님. (턴 12)
- 근거 : 물을 마시는 양과 소변 횟수는 예전과 비슷하고, 복부 진찰상 압통·종괴 및 간·비장 촉지가 없음 → 당뇨병성 다음·다뇨나 복부 종괴를 뒷받침하는 병력·진찰 소견은 확인되지 않음. (턴 9, 17, 30)
```

## [A] 감별진단

```
r/o 무통성 갑상샘염 : 체중 감소와 두근거림·손떨림·더위 탐은 갑상샘중독증에 부합하지만, 진찰상 안구 돌출·안검 징후는 그레이브스병을 더 지지함 (시작 정보; 턴 4, 5, 7, 24). 감별 검사 : TSH, 유리 T4/T3 및 갑상샘 섭취율 검사
r/o 독성 갑상샘결절 : 체중 감소와 갑상샘항진 증상은 고려 근거이나, 진찰상 갑상샘이 대칭적으로 미만성 비대하고 결절이 만져지지 않음 (시작 정보; 턴 4, 21, 33). 감별 검사 : 갑상샘 초음파 및 갑상샘 스캔
r/o 당뇨병 : 식욕 증가와 비의도적 체중 감소는 고려 근거이나, 물 섭취량과 소변 횟수는 예전과 비슷하다고 호소함 (시작 정보; 턴 6, 9, 17). 감별 검사 : 공복 혈당 및 당화혈색소
r/o 위장관 질환 또는 흡수장애 : 체중 감소와 하루 2~3회의 묽은 변을 호소해 고려할 수 있으나, 식욕은 증가했고 복부 압통이나 종괴는 진찰상 확인되지 않음 (시작 정보; 턴 6, 8, 30). 감별 검사 : 혈액검사와 대변검사, 필요 시 셀리악병 혈청검사
```

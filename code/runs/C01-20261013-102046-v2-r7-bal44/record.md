## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 졸피뎀 10mg을 밤에 5~6알 복용하고 낮에도 가끔 복용한다고 호소하며, 반 알에서 5~6알로 복용량이 증가해 내성 및 조절 실패를 시사함. (턴 2, 4, 6)
- 근거 : 여러 차례 감량·중단을 시도했으나 불안해져 다시 복용했다고 호소해 반복적인 감량 실패를 뒷받침함. (턴 7, 9)
- 근거 : 여러 내과·신경과·정신과에서 처방받았고 약국 수면유도제도 가끔 복용한다고 호소해 복용 조절의 어려움이 시사됨. (턴 10, 11)
- 근거 : 복용 후 기억이 나지 않을 때가 있다고 호소하며, 진찰상 반응 지연과 졸림이 관찰되어 약물 관련 인지·진정 영향이 우려됨. (턴 14, 25)
- 근거 : 진찰상 의식은 명료하고 지남력은 3/3점이며 급성 중독 징후는 관찰되지 않아, 현재 급성 중독을 주진단으로 볼 근거는 제한적임. (턴 24, 25)
- 근거 : 가족이 약 복용을 걱정한다고 호소함. 중단 후 경련은 없었고 진찰상 자세성 떨림과 발한도 관찰되지 않아 현재 중증 금단을 뒷받침하는 소견은 없음. (턴 13, 15, 28, 29)
```

## [A] 감별진단

```
r/o 진정수면제 금단 (Sedative, hypnotic, or anxiolytic withdrawal) : 약을 중단하거나 줄일 때 온몸이 불안해지고 감량 후 다시 복용했다고 호소해 금단 가능성을 고려함. 다만 오늘 새벽 복용했고 경련은 없으며, 진찰상 떨림·발한이 관찰되지 않음 (턴 7, 9, 12, 13, 28, 29). 감별 검사 : 복용량 변화에 따른 금단 증상과 활력징후를 반복 평가하고 CIWA-B 등 임상 척도로 관찰
r/o 불면장애 (Insomnia disorder) : 7년 전부터 잠을 잘 못 잔다고 호소함. 다만 고용량 졸피뎀 복용과 반복적인 감량 실패가 동반되어 독립적인 불면장애 여부는 약물 사용 상태와 함께 평가해야 함 (시작 정보; 턴 1, 4, 9). 감별 검사 : 수면일지와 불면증 심각도 척도(ISI)
r/o 불안장애 (Anxiety disorder) : 약을 중단하면 온몸이 불안해지고 약 없이 잠들지 못할까 두렵다고 호소함. 불안이 약 감량·중단 상황과 관련되어 있어 독립적인 불안장애와 구분이 필요함 (턴 7, 8, 9). 감별 검사 : 약물 복용·감량 시점과 분리된 불안 증상을 확인하고 GAD-7로 선별
```

## [P] 치료

```
- 급중단 금지 — 당일 처방 내역(DUR)·실제 총량 확인 후 첫 처방은 확인된 평소 1일 사용량을 넘지 않는 고정 일정(취침 전 정해진 시각)으로 1~2주분만(처방 일원화, 보호자 보관·복용 확인, 주간·추가 복용과 조기 재처방 없음), 이후 1~2주마다 10~25%씩 감량
- 음주·약국 수면유도제 등 다른 진정성 물질 병용 금지
- 급격한 중단 금지 — 실제 총량 확인 후 1~2주마다 10~25%씩 점진 감량(금단에 따라 조절)
- 처방 일원화(본원 한 곳), 추가·주간 복용 금지, 약국 수면유도제 중단
- 수면위생·수면일지·CBT-I, 정신건강의학과(중독·수면)와 협진
- 기존 복용약(예: 혈압약)은 유지
- 수면일지, 수면위생 교육과 불면 인지행동치료를 시작하고 정신건강의학과 중독·수면 진료를 의뢰합니다.
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 급성 위험 징후 없어 입원 불필요, 외래 추적

- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

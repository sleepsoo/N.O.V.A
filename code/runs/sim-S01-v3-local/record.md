## [A] 근거

```
#1. 급성 충수염 (Acute Appendicitis)
- 근거 : 수술 반흔이 없고, 오른쪽 하복부에 국한된 통증이 발생하면서 반발 압통, 근성 방어가 양성으로 확인되었다. (턴 24, 25)
- 근거 : 마크버니점(충수부)에서 압통이 양성이며, 공기 방사와 흉단동 증상이 없다. (턴 26)
- 근거 : 통증이 유행성 디스크와 유사한 초기 전복(배꼽 주변) 이후 오른쪽 하복부로 국한되고, 악화요인으로 걷기·기침이 관찰되었다. (시작 정보; 턴 2)
- 근거 : 통증 강도 7/10과 함께 37.9 °C의 경미한 발열과 1회 구토, 메스꺼움이 증상을 악화시켰다. (턴 6, 8, 11)
```

## [A] 감별진단

```
r/o 장간막염 : 전복에서 시작해 오른쪽 하복부로 국한된 통증이 있으나, 물리학적으로 오른쪽 하복부 특이 감각(근성 방어, 반발압통)과 마크버니점 압통이 존재해 전통적 장간막염과는 상반된다. 그러나 긍정적 반발압통이 주로 가로복부 주변에서 나타나는 경우가 많음 (시작 정보; 턴 24, 25). 감별 검사 : 복부 초음파 또는 CT
r/o 감염성 위장염 : 위장염은 흔히 복통, 설사, 구토와 함께 나타나지만, 이 환자는 설사(주변검사 F14 음성)를 보이지 않으며, 오른쪽 하복부에 국한된 반발압통이 비정상적으로 뚜렷하다 (턴 9). 감별 검사 : 대변 연검 및 세균학 검사
```

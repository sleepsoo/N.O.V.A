## [A] 근거

```
#1. 수면제(진정수면제) 사용장애(졸피뎀 사용장애) (Sedative-hypnotic use disorder)
- 근거 : 7년간 졸피뎀 10 mg을 복용했고 현재 밤에 5~6정(50~60 mg), 때로 낮에도 1정을 복용한다고 호소함 → 장기간의 고용량 사용 (턴 2, 3, 4, 5)
- 근거 : 복용량이 반 정에서 서너 정으로 늘었고 감량을 여러 번 시도했으나 실패했다고 호소함 → 내성 및 조절 실패를 시사 (턴 6, 9)
- 근거 : 약을 먹지 않으면 불안하고 손이 떨린다고 호소함 → 금단 증상과 생리적 의존 가능성을 지지 (턴 7)
- 근거 : 여러 내과·신경과·정신과에서 처방받고 약국 수면유도제도 가끔 복용한다고 호소함 → 여러 경로의 수면 관련 약물 사용 (턴 10, 11)
- 근거 : 복용 후 기억이 끊기기도 한다고 호소하며, 진찰상 반응 지연·졸림·불안·초조가 있으나 급성 중독 징후는 없음 → 약물 관련 인지·진정 부작용 가능성 (턴 12, 25)
- 근거 : 진찰상 의식이 명료하고 지남력은 3/3점이며 MMSE-K는 28/30점 → 현재 진찰에서 뚜렷한 의식 혼탁이나 중증 인지저하는 확인되지 않음 (턴 24, 26)
```

## [A] 감별진단

```
r/o 불면장애 (Insomnia disorder) : 7년 전부터 잠을 잘 못 잔다고 호소해 고려할 수 있으나, 현재의 고용량 수면제 사용과 감량 실패·금단 호소가 수면 문제 평가에 우선적으로 영향을 줌 (시작 정보; 턴 1, 4, 7, 9). 감별 검사 : 수면 일지 및 수면 기회·주간 기능에 대한 평가
r/o 불안장애에 동반된 불면 (Anxiety-related insomnia) : 불안한 기분과 초조한 정동이 진찰상 확인되지만, 환자가 호소한 불안과 손떨림은 약을 먹지 않을 때 나타나 금단과 연관된 증상일 가능성이 있음 (턴 7, 30). 감별 검사 : 불안 증상의 약물 복용 시점과 무관한 지속 여부에 대한 정신건강 평가
r/o 폐쇄성 수면무호흡증 (Obstructive sleep apnea) : 수면곤란을 호소하고 진찰상 주간 졸림이 관찰되어 감별할 수 있으나, 졸피뎀 복용이 졸림에 영향을 줄 가능성도 있음 (시작 정보; 턴 25). 감별 검사 : 수면다원검사
```

- 혈액검사(CBC, 간·신장기능, 전해질, 혈당) : 기저 건강 상태와 감량 및 향후 치료의 안전성을 확인합니다.

## [P] 치료

```
- 급중단 금지 — 당일 처방 내역(DUR)·실제 총량 확인 후 금단을 막는 최소 용량으로 1~2주분만 단기 처방(처방 일원화, 보호자 보관·복용 확인, 증량·추가·조기 재처방 없음), 이후 1~2주마다 10~25%씩 감량
- 급격한 중단 금지 — 실제 총량 확인 후 1~2주마다 10~25%씩 점진 감량(금단에 따라 조절)
- 처방 일원화(본원 한 곳), 추가·주간 복용 금지, 약국 수면유도제 중단
- 수면위생·수면일지·CBT-I, 정신건강의학과(중독·수면)와 협진
- 기존 복용약(예: 혈압약)은 유지
- 수면일지, 규칙적인 기상, 낮잠과 오후 카페인 피하기, 자극 조절을 시작하고 정신건강의학과 중독·수면 진료와 협진을 고려합니다.
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 급성 위험 징후 없어 입원 불필요, 외래 추적
- 의식 명료, 급성 중독·심한 금단 징후 없어 외래 감량 — 단, 금단 경련·섬망 병력이 있거나 보호자 감독이 어려우면 입원 해독 고려
- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

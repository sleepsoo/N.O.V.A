## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 졸피뎀 한 알 10mg을 밤에 4알, 새벽에 1~2알 복용하고 가끔 낮에도 복용한다고 호소 → 야간·새벽 복용량만으로도 하루 50~60mg에 이르는 반복적 고용량 사용 양상이다. (턴 7, 11, 12)
- 근거 : 반 알에서 3~4알로 복용량이 늘었고 감량·중단 시도를 여러 번 실패했으며 여러 진료과에서 처방받고 약국 수면유도제도 함께 복용한다고 호소 → 내성 및 사용 조절 실패를 뒷받침한다. (턴 9, 13, 14, 15)
- 근거 : 약을 거르면 밤새 잠을 못 자고 불안하며, 약 없이는 잠을 못 잘까 걱정한다고 호소 → 중단 시 반동성 불면·불안과 심리적 의존 가능성을 뒷받침한다. (턴 2, 3, 8)
- 근거 : 낮 졸림·멍함·기억력 저하 및 복용 후 기억 소실을 호소했고, 진찰상 반응 지연과 졸림이 관찰되었으며 MMSE-K는 28/30점, 지연회상은 2/3점이었다 → 복용과 연관된 주간 진정 및 기억 영향이 우려된다. (턴 4, 5, 17, 24, 25)
- 근거 : 진찰상 급성 중독 징후는 없고 의식·지남력은 명료하며 보행·안구운동·발음에 뚜렷한 이상이 없었다 → 현재 급성 중독이나 현저한 신경학적 이상을 시사하는 소견은 제한적이다. (턴 24, 26, 27, 28, 33)
- 근거 : 남편과 딸도 수면제 복용을 걱정한다고 전해졌다 → 주변에서도 지속적인 약물 사용을 우려하고 있다. (턴 21)
```

## [A] 감별진단

```
r/o 졸피뎀 감량·중단에 따른 반동성 불면 : 약을 거르면 밤새 잠을 못 자고 불안하다는 호소가 있어 중단 관련 반동성 증상이 고려된다. 다만 고용량 사용, 증량 및 감량 실패를 함께 보면 사용장애가 더 중심적인 진단이다 (턴 2, 8, 13, 14). 감별 검사 : 처방·복용 내역 확인 및 수면일지; 안전한 감량 과정에서 증상 경과 평가
r/o 불면장애 : 수면곤란을 호소하고 약을 거르면 잠을 못 잔다고 하나, 장기간의 고용량 졸피뎀 사용과 증량·감량 실패가 수면 문제에 영향을 주었을 가능성이 크다 (시작 정보; 턴 2, 7, 13, 14). 감별 검사 : 수면력 및 불면장애 진단 기준 평가, 수면일지
r/o 불안장애 : 약을 거르면 불안하다는 호소는 있으나 불안이 약 복용을 거른 상황과 연관되어 있어 독립적인 불안장애 여부를 추가로 확인해야 한다 (턴 3, 8). 감별 검사 : 구조화된 불안 증상 면담 또는 GAD-7
r/o 폐쇄성 수면무호흡증 : 주간 졸림을 호소해 감별에 포함할 수 있으나, 코골이·목격된 무호흡에 관한 정보는 제시되지 않았다 (턴 4). 감별 검사 : 수면무호흡 선별 문진 후 필요 시 수면다원검사
```

## [P] 치료

```
- 현재 복용 중인 수면제를 오늘 갑자기 중단하지 않음(금단·경련 위험) — 처방 내역 확인 후 정신건강의학과 전문의 감독 아래 점진 감량 계획 수립
- 처방 기관 일원화, 임의 증량·추가 복용 금지, 술·약국 수면유도제 등 다른 진정성 물질 병용 금지
- 비약물 치료: 불면 인지행동치료(CBT-I), 수면위생 교육, 수면일지
- 기존 복용약은 유지하며 금기·약물 상호작용 확인, 금단 증상과 부작용 모니터링
- 다음 평가 전까지 현재 복용량을 넘기지 않도록 보호자가 약을 보관하고 복용을 확인(보유량·마지막 복용 시각 확인)
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 현재 외래 추적이 적절하며, 증상 악화나 경고 증상이 생기면 응급 평가·입원 고려
- 의식 명료, 급성 중독·심한 금단 징후 없어 외래 감량 — 단, 금단 경련·섬망 병력이 있거나 보호자 감독이 어려우면 입원 해독 고려
- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

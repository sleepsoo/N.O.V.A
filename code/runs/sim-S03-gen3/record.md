## [A] 근거

```
#1. 급성 우측 중이염 (Acute right otitis media)
- 근거 : 어제부터 발열을 호소하고 최고 체온은 38도였으며, 오른쪽 귀 통증과 귀를 잡아당기는 행동을 보임 → 급성 귀 질환을 뒷받침함 (시작 정보; 턴 5, 12)
- 근거 : 우측 고막 발적과 팽윤, 광반사 소실이 있고 좌측 고막은 정상임 → 급성 우측 중이염에 가장 특징적인 진찰 소견임 (턴 25)
- 근거 : 닷새 전부터 맑은 콧물과 가벼운 기침이 있었고 비점막 부종이 관찰됨 → 선행 바이러스성 상기도 감염이 중이염 발생에 기여했을 가능성이 있음 (턴 14, 26)
- 근거 : 폐렴구균 백신을 제때 접종했다고 보고함 → 예방접종력은 확인되나 현재의 고막 소견을 설명하는 급성 중이염 진단과 모순되지 않음 (턴 20, 25)
- 근거 : 귀 분비물이 없고 귀 뒤 부종이나 발적도 없으며, 진찰상 처짐이 없음 → 이루를 동반한 중이염이나 유양돌기염 등 합병증을 뒷받침하는 소견이 없음 (턴 10, 17, 23)
- 근거 : 의식이 명료하고 경부강직·케르니그 징후·브루진스키 징후가 없음 → 현재 진찰에서 수막 자극 징후는 확인되지 않음 (턴 24, 28)
```

## [A] 감별진단

```
r/o 바이러스성 상기도 감염 (Viral upper respiratory infection) : 맑은 콧물과 가벼운 기침이 있으나, 귀 통증 호소와 우측 고막 팽윤·발적·광반사 소실은 상기도 감염만으로 설명하기 어려움 (턴 12, 14, 25). 감별 검사 : 임상 경과 관찰 및 필요 시 호흡기 바이러스 검사
r/o 외이도염 (Otitis externa) : 귀 통증과 귀를 잡아당기는 행동은 있으나, 우측 고막 팽윤과 발적이 확인되어 중이 병변을 더 지지함 (시작 정보; 턴 12, 25). 감별 검사 : 이경으로 외이도와 고막을 함께 확인
r/o 급성 유양돌기염 (Acute mastoiditis) : 귀 통증은 있으나 귀 뒤 부종과 발적이 없고 진찰상 처짐도 없어 현재 이를 지지하는 소견은 부족함 (턴 10, 23). 감별 검사 : 귀 뒤 압통·부종을 재확인하고 의심 소견이 있으면 측두골 영상검사
r/o 인두염에 의한 연관통 (Referred otalgia from pharyngitis) : 인두 경도 발적은 있으나 삼출물은 없고, 우측 고막의 뚜렷한 팽윤과 발적이 있어 인두염만으로 인한 연관통 가능성은 낮음 (턴 25, 27). 감별 검사 : 인두 진찰 및 임상적으로 필요할 때 인두 면봉 검사
```

## [P] 추가 검사

```
- 고막 진찰 : 오른쪽 고막의 팽윤과 발적을 확인해 중이염 여부를 판단합니다.
- 귀 뒤 진찰 : 귀 뒤 붓기나 발적이 있는지 살펴 유양돌기염 가능성을 확인합니다.
- 의식·목 경직 확인 : 처짐과 목 경직이 있는지 확인해 심한 감염 징후를 살핍니다.
```

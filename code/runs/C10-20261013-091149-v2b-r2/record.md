```
예전보다 더 많이 먹으며, 더위를 많이 타고 가만히 있어도 두근거림이 자주 있으며 잔을 들거나 글을 쓸 때 손이 떨린다고 함. 하루 2~3회 전보다 묽은 변을 보고, 밤에 잠옷이 젖을 정도로 땀이 나기도 하며 눈이 튀어나오고 뻑뻑한 느낌, 앞목이 두꺼워진 느낌, 계단을 오를 때 다리에 힘이 빠지는 증상이 있다고 함.
물을 마시는 양은 전과 같고, 복통은 없으며 기침이나 가래도 없다고 함. 목에 혹은 없다고 함.
약이나 영양제는 복용하지 않으며, 최근 2개월간 월경량과 기간이 줄었다고 함. 몇 달간 성관계가 없어 임신 가능성은 없다고 함.
혹시 큰 병일까 걱정되며 어떤 검사를 받아야 하는지 궁금해 내원함.
```

## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘기능항진증 (Graves disease causing hyperthyroidism)
- 근거 : 기존 약 56kg에서 현재 약 49kg으로 3개월간 약 7kg(기존 체중의 약 12.5%) 감소했고 의도적인 감량은 없으며 오히려 더 많이 먹는다고 호소함 → 갑상샘기능항진증에 의한 체중 감소를 지지함. (시작 정보; 턴 1)
- 근거 : 더위 민감, 안정 시 두근거림, 손떨림, 묽은 변 및 야간 발한을 호소함 → 대사 항진 및 교감신경 항진 증상과 부합함. (턴 2, 3, 4, 5, 8)
- 근거 : 진찰상 갑상샘이 양측 대칭으로 미만성 비대되어 있고 표면이 매끈하며 잡음이 들림; 양측 안구 돌출, 안검 지연 및 안검 후퇴가 있음 → 그레이브스병을 강하게 지지하는 소견임. (턴 25, 26, 30)
- 근거 : 진찰상 맥박 102회/분의 규칙적 빈맥, 안절부절함, 피부 온감과 발한, 양측 자세성 떨림이 관찰됨 → 갑상샘중독 상태와 부합함. (턴 23, 24, 27, 28, 29)
- 근거 : 모친에게 갑상샘 질환 병력이 있음 → 갑상샘 질환의 가족력으로, 자가면역 갑상샘 질환 소인을 뒷받침할 수 있으나 원인을 특정하지는 않음. (턴 13)
- 근거 : 약·영양제를 복용하지 않고 물 섭취는 평소와 같다고 호소함; 진찰상 경부 림프절, 복부 종괴 및 간·비장 비대가 촉지되지 않음 → 외인성 약물 노출이나 일부 다른 체중 감소 원인을 뒷받침하는 단서는 적으나 배제 소견은 아님. (턴 6, 11, 31, 32)
```

## [A] 감별진단

```
r/o 독성 다결절 갑상샘종 : 체중 감소와 더위 민감 등 갑상샘기능항진 양상은 지지하지만, 진찰상 결절 없이 매끈한 양측 미만성 비대이고 안구 돌출·안검 징후가 있어 그레이브스병이 더 잘 맞음 (시작 정보; 턴 2, 25, 26). 감별 검사 : 갑상샘 초음파, 갑상샘 섬광조영술
r/o 갑상샘염에 의한 일과성 갑상샘중독증 : 체중 감소와 두근거림은 갑상샘중독증에 부합하지만, 진찰상 갑상샘 잡음과 안구 돌출·안검 징후가 있어 갑상샘 호르몬 합성 항진인 그레이브스병을 더 지지함; 갑상샘 압통은 없음 (시작 정보; 턴 3, 25, 26, 30). 감별 검사 : 갑상샘 섬광조영술, 적혈구침강속도 또는 C-반응단백
r/o 당뇨병 : 식욕이 증가한 상태에서 체중 감소가 있어 고려할 수 있으나, 물 섭취 증가는 호소하지 않고 갑상샘 비대·안구 징후·떨림 등은 갑상샘 질환을 더 지지함 (시작 정보; 턴 1, 6, 25, 26, 29). 감별 검사 : 공복 혈당, 당화혈색소
r/o 악성 종양 : 비의도적 체중 감소와 야간 발한은 고려할 단서이나, 진찰상 경부 림프절 및 복부 종괴·간비장 비대가 없고 갑상샘기능항진을 시사하는 소견이 뚜렷함 (시작 정보; 턴 8, 25, 26, 31, 32). 감별 검사 : 일반혈액검사, 증상과 진찰 소견에 따른 표적 영상검사
```

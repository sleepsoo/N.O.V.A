```
#1. 진정제·수면제 사용장애 (Sedative, hypnotic, or anxiolytic use disorder)
- 근거 : 스틸녹스 10mg을 밤에 5~6알(총 50~60mg) 복용하고, 새벽이나 낮에도 추가 복용한다고 호소함 → 처방 용량을 크게 초과한 사용 양상임. (턴 2, 4, 5)
- 근거 : 수면제 복용은 7년 전부터이며, 반 알에서 서너 알로 늘었다고 호소함 → 장기간 사용과 내성을 시사함. (턴 1, 3, 6)
- 근거 : 여러 차례 줄이거나 끊으려 했으나 다시 복용했고, 약이 없으면 잠을 못 잔다고 호소함 → 조절 실패와 지속적 사용을 뒷받침함. (턴 7, 10, 21)
- 근거 : 여러 내과·신경과·정신과에서 처방받고 약국 수면유도제도 가끔 같이 복용한다고 호소함 → 복수 경로의 진정수면제 노출이 확인됨. (턴 11, 12)
- 근거 : 낮 졸림·멍함·복용 후 기억 단절을 호소하고, 진찰상 반응 지연과 졸림이 있으나 급성 중독 징후는 관찰되지 않음 → 사용 관련 주간 진정 및 기억 부작용이 의심됨. (턴 9, 13, 25)
- 근거 : 환자와 가족이 약물 증가 및 건강 영향에 대해 걱정한다고 호소함 → 현재 사용 양상이 환자와 가족에게 우려를 일으킴. (턴 8, 14)
```

## [A] 감별진단

```
r/o 약물 관련 불면 또는 수면제 금단 : 약이 없으면 밤새 잠을 못 자고 온몸이 불안하다고 호소하며, 감량·중단 시도 후 재복용함. 사용장애와 함께 약물 효과 또는 금단이 수면 문제를 악화할 수 있음 (턴 7, 10, 21). 감별 검사 : 의료진 감독하 감량 중 수면·불안 및 금단 증상 경과 평가
r/o 만성 불면장애 : 7년 전부터 수면 문제를 호소하지만, 현재는 고용량 수면제 사용과 반복된 감량·재복용이 수면을 크게 교란하므로 독립적인 만성 불면장애 여부는 약물 영향을 고려해 평가해야 함 (턴 1, 4, 6, 10). 감별 검사 : 약물 사용을 안정화한 뒤 수면일지 또는 액티그래피
r/o 불안장애 관련 불면 : 온몸이 불안하다고 호소하고 진찰상 안절부절 및 불안·초조가 관찰되어 고려함. 다만 불안이 독립적인 불안장애인지 약물 사용·감량과 관련된 증상인지는 불분명함 (턴 7, 23, 25). 감별 검사 : GAD-7 및 구조화된 불안장애 면담
r/o 수면무호흡증 : 수면 문제가 주호소이므로 감별 대상이나, 제공된 병력에는 코골이·목격된 무호흡 등 수면무호흡증을 직접 지지하는 정보가 없음 (시작 정보). 감별 검사 : 수면무호흡 선별 문진 후 필요 시 수면다원검사
```

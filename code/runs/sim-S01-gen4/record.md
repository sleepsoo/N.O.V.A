## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 어제 저녁 시작한 배꼽 주변 통증이 오늘 아침부터 우하복부 통증으로 이동함 → 충수염에 전형적인 통증 양상 (시작 정보)
- 근거 : 걷거나 기침할 때 우하복부 통증이 악화되고 다리를 굽히면 덜 아프다고 호소함 → 복막 자극 가능성을 뒷받침 (턴 2, 4)
- 근거 : 진찰상 우하복부 국한 근성방어와 압통, 맥버니점 압통 및 반발압통이 있음 → 국소 복막 자극과 충수염을 강하게 시사 (턴 21, 22, 23)
- 근거 : 진찰상 우측 요근 징후와 로브싱 징후가 양성임 → 충수염 가능성을 추가로 뒷받침 (턴 24, 26)
- 근거 : 메스꺼움과 구토를 호소하고 오한·열감 및 가정 체온 37.8도를 보고함 → 급성 염증성 질환에 부합 (턴 8, 15)
- 근거 : 배뇨통을 부인하고 소변 색은 평소와 같으며 진찰상 늑척추각 압통이 없음 → 요로계 원인의 지지 근거가 상대적으로 약함 (턴 5, 20, 27)
```

## [A] 감별진단

```
r/o 장간막 림프절염 : 메스꺼움과 오한·열감을 호소하지만, 배꼽 주변에서 우하복부로 이동한 통증과 우하복부 국소 압통·반발압통은 급성 충수염을 더 지지함 (시작 정보; 턴 8, 15, 21, 23). 감별 검사 : 복부 초음파 또는 복부 CT
r/o 장염 : 메스꺼움과 구토를 호소하지만, 통증이 우하복부에 국한되고 진찰상 국소 근성방어와 반발압통이 있어 장염보다 충수염이 더 의심됨 (시작 정보; 턴 8, 21, 23). 감별 검사 : 혈액검사(CBC, CRP) 및 복부 영상검사
r/o 요관결석 : 우하복부 통증은 요관결석에서도 가능하지만, 배뇨통을 부인하고 진찰상 늑척추각 압통이 없어 지지 근거가 약함 (시작 정보; 턴 5, 20, 27). 감별 검사 : 소변검사 및 비조영 복부-골반 CT
```

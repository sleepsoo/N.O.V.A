## [A] 근거

```
#1. 체질성 성장지연 (Constitutional growth delay)
- 근거 : 보호자가 보고한 키는 1년 전 100cm에서 현재 105cm로 약 5cm 증가 → 성장속도는 정상 하한 수준으로, 뚜렷한 성장속도 저하를 뒷받침하지 않음. (시작 정보)
- 근거 : 성장도표상 신장은 3백분위수 미만, 체중은 3~10백분위수이며 성장속도는 5cm/년 → 저신장은 확인되나 성장속도는 정상 하한임. (턴 26)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이고 부친은 고등학교 때 많이 성장했다고 함 → 부모 키가 작은 가족성 저신장보다는 체질성 성장지연 가능성을 지지함. (턴 4, 5)
- 근거 : 진찰상 상·하절 비율이 정상이고 양팔간격 불균형과 안면 기형이 없음 → 뚜렷한 체형 불균형이나 증후군성 외형 소견은 확인되지 않음. (턴 28, 30)
- 근거 : 잘 먹고 체중이 1년간 1.5kg 증가했으며, 알려진 장·콩팥 질환이나 중증 질환이 없고 변비·추위 민감 및 갑상선 비대도 없음 → 영양 부족, 만성 전신질환, 갑상선기능저하증을 시사하는 병력·진찰 소견은 뚜렷하지 않음. (시작 정보; 턴 7, 9, 13, 19, 31)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 (Growth hormone deficiency) : 신장이 3백분위수 미만이고 보호자가 최근 성장이 더딘 것 같다고 호소해 고려함. 다만 성장속도는 약 5cm/년으로 정상 하한이며, 결핍을 확정할 호르몬 검사 결과는 없음 (시작 정보; 턴 26). 감별 검사 : IGF-1 및 IGFBP-3, 필요 시 성장호르몬 자극검사
r/o 가족성 저신장 (Familial short stature) : 신장은 3백분위수 미만이나 부모 키가 각각 178cm와 165cm이고 중간부모키가 178cm로, 부모가 작은 가족성 저신장 양상과 맞지 않음 (턴 4, 6, 26). 감별 검사 : 성장도표와 중간부모키 재확인
r/o 갑상선기능저하증 (Hypothyroidism) : 저신장으로 감별 대상이나 변비와 추위 민감이 없고 진찰상 갑상선 비대가 없음 (턴 9, 26, 31). 감별 검사 : TSH 및 free T4
r/o 영양 부족 또는 만성 전신질환에 의한 성장 부진 (Nutritional or chronic systemic disease-related growth faltering) : 신장이 3백분위수 미만이고 체중도 3~10백분위수여서 고려함. 다만 식사를 잘하고 체중이 증가했으며 알려진 장·콩팥 질환이나 중증 질환은 없음 (시작 정보; 턴 7, 13, 19, 26). 감별 검사 : CBC 및 대사 패널
```

## [P] 추가 검사

```
- 영유아 검진 수첩의 과거 키·몸무게 기록 확인 : 성장도표에 표시해 성장 곡선과 성장속도 추이를 평가합니다.
- 좌측 손·손목 엑스선(골연령) : 뼈 나이가 실제 나이보다 늦은지 확인해 체질성 성장지연과 가족성 저신장을 구분합니다.
- 갑상샘자극호르몬(TSH), 유리 티록신(free T4) : 갑상샘기능저하증을 확인합니다.
- 인슐린유사성장인자-1(IGF-1), 성장인자결합단백-3(IGFBP-3) : 성장호르몬 부족 가능성을 선별합니다.
- 혈구검사·염증수치·혈액화학검사·소변검사·셀리악 선별검사 : 빈혈, 염증, 신장·간·대사 질환 및 셀리악병 등 성장에 영향을 주는 만성질환을 살핍니다.
```

```
- 현재 성장호르몬을 포함한 약물치료를 시작할 적응증은 없습니다. 검사 결과와 성장 추이를 확인한 뒤 필요하면 소아내분비 평가 및 치료를 고려합니다.
- 규칙적인 식사와 충분한 수면, 연령에 맞는 신체활동을 유지합니다.
```

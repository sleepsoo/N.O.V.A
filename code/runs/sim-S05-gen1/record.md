## [A] 근거

```
#1. 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 (Lumbar disc herniation causing left S1 radiculopathy)
- 근거 : 열흘 전 이삿짐을 옮기다 허리를 삐끗한 뒤 통증이 시작되었다고 호소함 → 급성 요추 추간판 병변의 시간적 연관성을 지지함. (시작 정보)
- 근거 : 왼쪽 다리 저림과 당김을 호소하고, 오래 앉거나 기침·재채기할 때 방사통이 악화된다고 함 → 신경근 자극 양상에 부합함. (시작 정보; 턴 8)
- 근거 : 진찰상 좌측 하지직거상 검사에서 40도에 방사통이 재현되고 좌측 S1 피부분절 감각이 저하됨 → 좌측 S1 신경근 침범을 뒷받침함. (턴 24, 26)
- 근거 : 진찰상 좌측 아킬레스건 반사가 우측보다 감소했고, 족저굴곡 근력은 Gr.5/Gr.4로 기록됨 → 좌측 S1 신경학적 이상과 일치함. (턴 25, 27)
- 근거 : 부친이 허리디스크 수술을 받은 병력이 있음 → 가족력이 있으나, 현재 진단은 환자의 증상과 진찰 소견에 더 직접적으로 근거함. (턴 18)
- 근거 : 배뇨 문제와 사타구니 감각 저하를 부인하고, 발열·오한·체중 감소·야간 통증도 호소하지 않음 → 마미증후군이나 감염·종양성 원인을 시사하는 단서가 현재 문진에서 확인되지 않음. (턴 4, 6, 14, 16, 17)
```

## [A] 감별진단

```
r/o 요추 염좌·근육 긴장 : 이삿짐을 옮기다 허리를 삐끗한 뒤 통증이 시작된 점은 고려할 수 있으나, 좌측 방사 증상과 S1 분절 감각·반사 이상은 단순 염좌만으로 설명하기 어려움 (시작 정보; 턴 26, 27). 감별 검사 : 증상이 지속되거나 악화되면 요추 MRI로 신경근 압박 여부를 평가
r/o 요추 신경공 협착에 의한 신경근병증 : 좌측 하지 방사통과 S1 진찰 이상은 신경근병증에 부합하지만, 열흘 전 무거운 짐을 든 뒤 급성으로 시작한 경과는 추간판 탈출증을 더 지지함 (시작 정보; 턴 24, 26, 27). 감별 검사 : 요추 MRI
r/o 요추 척추체 압박골절 : 짐을 옮긴 뒤 급성 요통이 시작된 점은 고려할 수 있으나, 44세이고 극돌기 타진 압통이 없으며 장기간 스테로이드 사용력도 부인함 (시작 정보; 턴 21, 23). 감별 검사 : 요추 단순 방사선검사, 필요 시 요추 MRI
```

## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-hypnotic use disorder)
- 근거 : 졸피뎀 10mg을 밤에 5~6알(50~60mg) 복용하고 가끔 낮에도 1알 복용한다고 호소 → 장기간 고용량 사용 양상임. (턴 2, 3, 4)
- 근거 : 복용량이 반 알에서 5~6알로 증가했고, 여러 차례 감량에 실패했다고 호소 → 내성과 조절 실패를 뒷받침함. (턴 6, 8)
- 근거 : 약을 복용하지 않으면 잠을 못 자고 불안하며, 여러 의료기관에서 처방받고 약국 수면유도제도 가끔 복용한다고 호소 → 금단 관련 증상과 지속적인 사용 양상을 뒷받침함. (턴 7, 9, 10)
- 근거 : 복용 뒤 가끔 기억이 나지 않고 가족도 약 복용을 걱정한다고 호소 → 사용과 연관된 위해 가능성이 있으며 가족이 문제를 인지하고 있음. (턴 11, 12)
- 근거 : 진찰상 반응 지연, 졸림, 불안·초조가 있으나 급성 중독 징후는 관찰되지 않음 → 현재 진정 관련 영향 가능성은 있으나 급성 중독 소견은 없음. (턴 28)
- 근거 : 진찰상 의식과 지남력은 명료하고 MMSE-K 28/30점이며, 자세성 떨림과 발한은 관찰되지 않음 → 현재 뚜렷한 인지 저하나 심한 자율신경성 금단 소견은 확인되지 않음. (턴 27, 29, 31, 32)
```

## [A] 감별진단

```
r/o 만성 불면장애 (Chronic insomnia disorder) : 7년간 수면 곤란을 호소하고 밤 11시 취침 후 새벽 2~3시에 자주 깨며 낮에 졸기도 함. 다만 고용량 졸피뎀 사용과 감량 실패가 있어 불면 증상만으로 주진단을 설명하기 어려움 (시작 정보; 턴 1, 4, 8, 15, 16, 17). 감별 검사 : 수면일지 및 불면증 심각도 지수(ISI)
r/o 불안 또는 우울 관련 불면 (Insomnia associated with anxiety or depression) : 멍하고 짜증이 난다고 호소하고 진찰상 불안·초조가 관찰되지만, 이 소견만으로 불안장애나 우울장애를 확정할 수 없음 (턴 13, 28). 감별 검사 : PHQ-9 및 GAD-7 선별검사
r/o 폐쇄성 수면무호흡증 (Obstructive sleep apnea) : 수면 중 자주 깨고 낮에 졸린다고 호소하여 감별 대상이나, 이 기록에는 수면무호흡을 뒷받침하는 특이 병력이 없음 (턴 15, 17). 감별 검사 : 수면다원검사
```

## [P] 치료

```
- 오늘 급중단하지 않고 확인된 현재 사용량 범위에서 1~2주분만 단기 처방(처방 일원화, 증량·추가·조기 재처방 없음) 후 1~2주마다 10~25%씩 감량

- 약국 수면유도제와 다른 진정제는 병용하지 않도록 안내합니다. 복용 중인 혈압약은 임의로 중단하지 않습니다.
- 수면일지와 수면위생 교육을 시작하고, 금기 여부와 검사 결과를 확인한 뒤 인지행동치료 및 정신건강의학과 협진을 고려합니다.
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 급성 위험 징후 없어 입원 불필요, 외래 추적
- 외래 귀가 및 추적 관찰합니다. 활력징후가 안정적이고 의식이 명료하며 급성 중독이나 심한 금단 징후가 없어 입원은 불필요합니다.
- 졸림과 반응 지연이 있어 오늘은 운전과 위험 작업을 피하도록 안내합니다. 가족에게 복용 확인과 감량 과정 지지를 부탁합니다.
```

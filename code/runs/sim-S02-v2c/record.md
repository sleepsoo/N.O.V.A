뇌에 혹이나 뇌출혈 같은 큰 병이 있는 것은 아닌지 걱정하며 두통 원인을 알고 싶어 내원함.

## [A] 근거

```
#1. 무조짐 편두통 (Migraine without aura)
- 근거 : 수년간 반복된 두통이 최근 3개월간 서서히 잦아졌고, 왼쪽 관자놀이·눈 뒤가 주로 아프며 심할 때 8/10이고 하루에서 이틀 지속된다고 호소함 → 편두통에 부합하는 반복성·중증 두통 양상 (시작 정보; 턴 1, 2, 3, 5)
- 근거 : 두통 때 메스꺼움과 구토가 있고 빛을 보면 통증이 악화된다고 호소함 → 편두통을 지지하는 동반 증상 (턴 6, 11)
- 근거 : 번쩍이는 빛은 없다고 호소하고 어머니에게 편두통 병력이 있음 → 무조짐 편두통 및 가족성 소인을 지지함 (턴 12, 19)
- 근거 : 진찰상 동공 반응과 안구운동이 정상이고 유두부종·안저 출혈이 없으며 안면 대칭, 사지 근력 및 보행이 정상임 → 현재 진찰에서 국소 신경학적 이상이나 두개내압 상승 소견이 확인되지 않음 (턴 24, 25, 26, 28, 30, 31)
- 근거 : 최악의 두통이 아니고 양상 변화 없이 빈도만 증가했다고 호소하며, 발열·목 뻣뻣함·최근 외상·아침 악화가 없고 진통제는 월 5~6회 복용함 → 급성 중증 이차성 원인과 약물과용 두통을 덜 지지함 (턴 9, 10, 13, 14, 21)
```

## [A] 감별진단

```
r/o 이차성 두통(두개내 병변 등) : 최근 3개월간 두통 빈도가 서서히 증가한 점은 추가 평가를 고려하게 하나, 양상 변화나 최악의 두통은 없고 안저 및 신경학적 진찰에서 이상 소견이 확인되지 않음 (턴 1, 9, 25, 28, 30, 31). 감별 검사 : 뇌 MRI
r/o 긴장형 두통 : 수년간 반복된 두통은 고려 근거이나, 주로 한쪽에 발생하고 심한 통증과 메스꺼움·구토·빛 민감이 동반되어 전형적인 긴장형 두통에는 덜 부합함 (시작 정보; 턴 2, 3, 6, 11). 감별 검사 : 두통 일지와 임상 양상 평가
r/o 약물과용 두통 : 이부프로펜을 복용하지만 진통제 복용 빈도가 월 5~6회라고 하여 약물과용 두통을 뒷받침하기에는 낮음 (턴 13, 18). 감별 검사 : 두통 및 진통제 복용 일수 확인
```

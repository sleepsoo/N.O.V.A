## [A] 근거

```
#1. 체질성 성장지연 (Constitutional growth delay)
- 근거 : 보호자는 1년 전 키 100cm, 현재 키 105cm로 1년간 약 5cm 자랐다고 호소함 → 성장속도는 낮은 정상 범위로 보고됨. (시작 정보; 턴 28)
- 근거 : 성장도표상 신장은 3백분위수 미만이고 체중은 3~10백분위수임 → 신장은 또래보다 작지만 성장속도만으로 뚜렷한 성장 정지를 단정하기 어려움. (턴 27, 28)
- 근거 : 아버지 키 178cm, 어머니 키 165cm이며 중간부모키는 178cm임 → 부모의 작은 체격으로 설명되는 가족성 저신장 가능성은 낮음. (턴 4, 28)
- 근거 : 아버지는 고등학교 때 많이 컸다고 함 → 가족 내 늦은 성장 시기가 있어 체질성 성장지연을 뒷받침함. (턴 5)
- 근거 : 신체 비율은 정상이고 안면 기형 및 귀 위치 이상은 관찰되지 않음 → 체형 불균형이나 뚜렷한 기형 소견은 확인되지 않음. (턴 29, 31)
- 근거 : 식욕이 좋고 체중이 1년간 1.5kg 증가했으며, 알려진 장·콩팥 질환과 변비가 없음 → 영양 부족이나 만성 질환을 시사하는 병력은 뚜렷하지 않음. (시작 정보; 턴 7, 10, 14)
```

## [A] 감별진단

```
r/o 가족성 저신장 : 신장은 3백분위수 미만이나 부모 키와 중간부모키가 작지 않아 가족성 저신장과는 맞지 않는 소견임 (턴 4, 28). 감별 검사 : 성장도표와 가족의 키를 재확인
r/o 성장호르몬 결핍 : 저신장과 최근 성장이 더딘 듯하다는 보호자 호소는 고려 요인이지만, 측정된 성장속도는 5cm/년으로 정상 하한이고 체중도 증가함 (시작 정보; 턴 28). 감별 검사 : IGF-1·IGFBP-3 측정, 필요 시 성장호르몬 자극검사
r/o 갑상선기능저하증 : 저신장에서 감별할 질환이나 변비가 없고 갑상선 비대·결절·압통이 관찰되지 않았으며 식욕이 좋음 (턴 10, 14, 32). 감별 검사 : TSH 및 유리 T4 측정
r/o 만성 질환 또는 영양 부족에 따른 성장 저하 : 식욕이 좋고 체중이 증가했으며 장·콩팥 질환 병력은 없다고 함 (시작 정보; 턴 7, 14, 22). 감별 검사 : CBC, 대사 패널 및 염증 지표 검사
```

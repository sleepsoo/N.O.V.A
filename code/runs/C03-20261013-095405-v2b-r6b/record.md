## [A] 근거

```
#1. 원인 미상의 저신장증 (Short stature of undetermined etiology)
- 근거 : 또래보다 작아 보인다는 호소가 약 1년 전부터 있었고, 최근 6개월~1년간 별로 자라지 않은 듯하다고 함 → 지속적인 성장 우려가 있음. (시작 정보)
- 근거 : 현재 신장 105cm로 신장 백분위수 3 미만이며, 연간 성장속도는 약 5cm로 정상 하한임 → 저신장증에 해당하나 성장속도 저하가 확정적이지 않음. (시작 정보; 턴 24, 25)
- 근거 : 체중은 16.5kg으로 3~10백분위수이고, 최근 1년간 1.5kg 증가했으며 갑작스러운 체중 변화는 없음 → 신장에 비해 뚜렷한 체중 감소를 보이는 양상은 아님. (시작 정보; 턴 16, 25)
- 근거 : 중간부모키는 178cm이고 아버지는 고교 시절 많이 컸다고 함 → 가족성 저신장보다는 성장 지연 가능성을 고려하게 하나, 체질성 성장지연을 확정할 자료는 부족함. (턴 4, 5, 25)
- 근거 : 진찰상 상·하절 비율은 정상이고 양팔간격 불균형 및 안면 기형은 없으며, 갑상선 비대·결절도 없음 → 뚜렷한 체형 이상이나 갑상선 진찰 이상은 확인되지 않음. (턴 26, 28, 29)
- 근거 : 만성질환 병력, 스테로이드 복용, 피로 및 두통은 부인함 → 병력상 전신질환이나 약물 관련 성장 저해를 뒷받침하는 소견이 없음. (턴 7, 9, 11, 12)
```

## [A] 감별진단

```
r/o 체질성 성장지연 (Constitutional delay of growth) : 아버지가 고교 시절 많이 컸다는 가족력과 정상 하한의 성장속도는 고려 근거임. 다만 현재 중간부모키가 178cm이고 골연령 지연은 확인되지 않아 확정할 수 없음 (턴 4, 5, 25). 감별 검사 : 골연령 검사와 성장곡선의 종적 평가
r/o 성장호르몬 결핍증 (Growth hormone deficiency) : 신장 백분위수가 3 미만인 점은 고려 근거임. 성장속도는 5cm/년으로 정상 하한이며, 현재 자료만으로 성장호르몬 결핍을 뒷받침하지는 않음 (턴 25). 감별 검사 : IGF-1 및 IGFBP-3 측정, 필요 시 성장호르몬 자극검사
r/o 가족성 저신장 (Familial short stature) : 저신장 평가에서 고려할 수 있으나, 부모 키와 중간부모키는 저신장 가족형을 지지하지 않음 (턴 4, 25). 감별 검사 : 부모 신장 재확인 및 성장도표 종적 평가
r/o 갑상선기능저하증 (Hypothyroidism) : 저신장 평가에서 감별할 내분비 질환이나, 피로 호소가 없고 진찰상 갑상선 비대·결절이 없음. 이 소견만으로 배제할 수는 없음 (턴 11, 29). 감별 검사 : TSH 및 유리 T4 측정
```

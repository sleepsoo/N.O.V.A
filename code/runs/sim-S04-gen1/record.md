## [A] 근거

```
#1. 만성폐쇄성폐질환의 급성 악화 (Acute exacerbation of chronic obstructive pulmonary disease)
- 근거 : 5년 전 폐기능 검사 후 COPD 진단을 들었고, 20세부터 하루 한 갑씩 50년 가까이 흡연했다고 호소함 → COPD의 기저질환 및 주요 위험인자가 확인됨 (턴 14, 17)
- 근거 : 사흘 전부터 숨참이 크게 악화되어 집 안에서 조금 움직이거나 화장실에 갈 때도 숨차다고 호소함 → 급성 악화를 시사함 (시작 정보; 턴 6)
- 근거 : 사흘 전부터 기침과 가래가 심해졌고, 가래가 하루 종일 누렇고 끈적하며 많다고 호소함 → 급성 악화와 함께 기도 감염 유발 가능성을 뒷받침함 (시작 정보; 턴 2)
- 근거 : 진찰상 술통형 흉곽, 입술 오므린 호흡, 경도의 보조호흡근 사용, 호흡음 감소, 호기 연장, 미만성 호기성 천명음 및 양측 과공명음이 있음 → COPD에 합당한 폐쇄성 호흡 소견임 (턴 23, 25, 26, 27)
- 근거 : 열감과 오한, 콧물 및 목 칼칼함을 호소함 → 감염성 상기도 증상이 급성 악화의 유발 요인일 수 있음 (턴 4, 19)
- 근거 : 진찰상 수포음과 경정맥 팽창, 하지 함요부종이 없고 S3도 들리지 않음 → 심부전 악화 가능성을 낮추는 소견이나 배제하지는 않음 (턴 26, 28, 29, 30)
```

## [A] 감별진단

```
r/o 폐렴 : 기침과 다량의 누런 가래, 열감 및 오한을 호소해 고려할 수 있으나 진찰상 수포음은 들리지 않음 (시작 정보; 턴 2, 4, 26). 감별 검사 : 흉부 X선, 혈구검사
r/o 급성 기관지염 : 최근 악화된 기침·가래와 콧물, 목 칼칼함 및 미만성 천명음이 있어 고려할 수 있으나, 이미 COPD 진단을 들었고 폐쇄성 진찰 소견이 뚜렷함 (시작 정보; 턴 14, 19, 26). 감별 검사 : 흉부 X선, 필요 시 객담 검사
r/o 심부전 악화 : 숨참과 베개를 하나 더 받치고 자는 증상을 호소하지만, 진찰상 경정맥 팽창·하지 함요부종·S3·수포음은 없음 (시작 정보; 턴 7, 26, 28, 29, 30). 감별 검사 : 흉부 X선, BNP 또는 NT-proBNP
r/o 폐색전증 : 급격히 악화된 숨참과 빈맥이 있어 고려할 수 있으나, 객혈은 없고 진찰상 종아리 압통이나 둘레 차이는 없음 (시작 정보; 턴 16, 28, 31). 감별 검사 : 임상 위험도 평가 후 D-dimer, 필요 시 CT 폐혈관조영술
```

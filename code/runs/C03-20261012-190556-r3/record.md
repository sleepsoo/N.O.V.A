## [A] 근거

```
#1. 신체성장 지연 (Constitutional growth delay)
- 근거 : 턴 33에서 또래보다 작은 키가 관찰되어 성장 지연 의심.
- 근거 : 턴 36에서 성장 속도 5cm/년(정상 하한)으로 성장률이 급격히 떨어지지는 않으나, 기준에서 낮음.
- 근거 : 턴 38에서 신장 3백분위수 미만이며 체중도 3~10백분위수 범위에 속하여 성장 곡선이 저하.
- 근거 : 턴 6, 22에서 아버지의 성장 지연 기록 및 저출신 성장과 일치, 가계형 성장 지연 가능성 높음.
```

## [A] 감별진단

```
r/o 성장 호르몬 결핍 : 성장 속도가 정상 하한선(5cm/년)으로 GH 결핍 가능성 낮음 + 혈중 IGF‑1 검사를 진행한다
r/o 갑상선 기능저하증 : 체온 36.7°C 및 무증상소견이 없고 소화계 이상 부재, 갑상선 기능 검사로 확인한다
r/o 셀리악병 : 변이 딱딱해지지 않았고, 구강·소화계 불편증이 없으며, 세리아 시트(항체) 검사 필요
r/o 가계형 단신 : 가족에 아버지 역시 성장 지연을 보였으며, 성장탄성 및 호르몬 수치 정상, 가족력으로 인해 가계형 단신 우선.
```

## [P] 추가 검사

```
- 성장호르몬 분비성 시험(충분한 층위 상승 확인) : GH 결핍 배제
- 갑상선 기능 검사(TSH, 자유 T4) : 갑상선 기능 저하 배제
- 세리브일 보합 항체(tTG‑IgA) : 세리엠병 가능성 확인
- 기본 혈액화학(CBC, 전해질, 간·신장 기능) : 전반적 건강 상태 점검
- 손발 방사선(Bone age) : 성장판 연령과 현재 신장 비교
- 소화기 영상(필요 시) : 비장·간 비대 여부 등 다른 성장 저해 원인 탐색
```

```

- 규칙적인 신체 활동 권장(운동·놀이) : 근육·골격 발달 촉진

- 경고 증상: 체중 급격 감소, 피로, 두통, 정서적 변화 시 즉시 의료기관 방문
```

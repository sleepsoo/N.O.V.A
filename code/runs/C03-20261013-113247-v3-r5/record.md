## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 1년간 약 5cm 성장했다는 호소와 성장속도 정상 하한이라는 진찰 소견은 성장속도가 현저히 저하된 양상은 아님을 시사한다. (시작 정보; 턴 25)
- 근거 : 신장 백분위수는 3백분위수 미만이고 체중은 3~10백분위수로, 또래보다 작은 체격이 확인된다. (턴 2, 24, 25)
- 근거 : 아버지가 고등학교 때 많이 컸다는 가족력은 체질성 성장지연 가능성을 뒷받침한다. (턴 5)
- 근거 : 부모 키는 아버지 178cm, 어머니 165cm이며 중간부모키는 178cm로, 부모의 작은 키에 따른 가족성 저신장과는 맞지 않는다. (턴 4, 25)
- 근거 : 식욕이 좋고 체중이 1년간 1.5kg 증가했으며, 만성 질환 병력이나 다른 불편 증상 호소가 없어 영양 부족 또는 전신 질환을 뒷받침하는 근거는 적다. (시작 정보; 턴 3, 7, 14)
- 근거 : 상·하절 비율은 정상이고 양팔간격 불균형 및 안면 기형 소견이 없어 뚜렷한 체형 이상 소견은 확인되지 않는다. (턴 26, 28)
```

## [A] 감별진단

```
r/o 가족성 저신장 : 신장이 3백분위수 미만이라는 점은 고려할 수 있으나, 부모 키가 작지 않고 중간부모키가 178cm이다 (턴 4, 25). 감별 검사 : 부모 키 및 가족 성장곡선 확인
r/o 성장호르몬 결핍증 : 신장이 3백분위수 미만이고 최근 성장에 대한 보호자의 우려가 있으나, 연간 성장속도는 정상 하한이며 체중도 증가했다 (시작 정보; 턴 25). 감별 검사 : 골연령 검사, 성장호르몬 자극검사
r/o 갑상선기능저하증 : 저신장 평가에서 고려할 수 있으나 피로와 변비 호소가 없고 진찰상 갑상선 비대가 없다 (턴 10, 25, 35). 감별 검사 : 혈청 TSH 및 유리 T4
r/o 영양 부족 또는 만성 질환에 의한 성장 지연 : 체중이 3~10백분위수인 점은 고려할 수 있으나 식욕이 좋고 체중이 증가했으며, 만성 질환 병력과 다른 불편 증상 호소가 없다 (시작 정보; 턴 3, 7, 14, 25). 감별 검사 : CBC, ESR/CRP 및 셀리악병 선별검사
```

## [A] 근거

```
#1. 급성 중이염 (Acute otitis media)
- 근거 : 어제부터 열이 나고 우측 귀 통증을 호소하며 귀를 자꾸 만짐 → 급성 발병의 편측 귀 증상은 급성 중이염에 부합함. (시작 정보)
- 근거 : 누우면 더 보채고 안으면 조금 호전됨 → 귀 통증으로 인한 불편감과 일치함. (턴 5)
- 근거 : 진찰상 우측 고막 발적·팽윤 및 광반사 소실, 이루 없음 → 우측 중이의 급성 염증 소견으로 급성 중이염을 지지함. (턴 24)
- 근거 : 어린이집에서 감기가 돌고 있었음 → 소아에서 중이염에 선행할 수 있는 호흡기 감염 노출이 있음. (턴 22)
- 근거 : 기침·콧물 호소가 없고 진찰상 좌측 고막은 정상이며, 우측 고막에 뚜렷한 염증 소견이 있음 → 바이러스성 상기도 감염만으로 설명하기보다 우측 급성 중이염이 더 적합함. (턴 9, 24)
- 근거 : 경부강직·케르니그 징후·브루진스키 징후가 없고 의식이 명료하며 처짐과 탈수 징후가 없음 → 현재 진찰에서 중증 전신 상태나 수막 자극을 시사하는 소견은 확인되지 않음. (턴 27, 28, 29, 33)
```

## [A] 감별진단

```
r/o 바이러스성 상기도 감염 (Viral upper respiratory infection) : 어린이집 감기 유행과 인두 경도 발적은 고려 근거이나, 기침·콧물 호소가 없고 우측 고막 팽윤 등 중이염을 뒷받침하는 진찰 소견이 있음 (턴 9, 22, 24, 25). 감별 검사 : 증상 경과 관찰; 임상적으로 필요하면 호흡기 바이러스 검사
r/o 외이도염 (Otitis externa) : 우측 귀 통증과 귀를 만지는 행동은 고려 근거이나, 진찰상 우측 고막 팽윤과 광반사 소실이 있어 중이 병변이 더 잘 맞음 (시작 정보; 턴 24). 감별 검사 : 외이도 시진 및 이주 압통 확인
r/o 급성 인두염 (Acute pharyngitis) : 진찰상 인두 경도 발적은 고려 근거이나, 우측 고막의 팽윤·발적이 확인되어 귀 증상을 설명하는 더 직접적인 원인이 있음 (시작 정보; 턴 24, 25). 감별 검사 : 인두 진찰; 임상적으로 연쇄상구균 감염이 의심되면 신속항원검사
```

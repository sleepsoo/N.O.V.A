## [A] 근거

```
#1. 우측 급성 중이염 (Acute otitis media of the right ear)
- 근거 : 어제부터 발열을 호소하고 진찰 시 체온은 38.6°C → 급성 감염성 질환에 부합함. (시작 정보; 턴 26)
- 근거 : 오른쪽 귀를 만지며 아파하고 귀를 잡아당기며 우는 증상을 호소함 → 우측 귀의 급성 통증이 있음. (시작 정보; 턴 3)
- 근거 : 진찰상 우측 고막 발적·팽윤 및 광반사 소실이 있고 좌측 고막은 정상임 → 우측 중이염을 강하게 지지함. (턴 19)
- 근거 : 맑은 콧물과 가벼운 기침을 호소함 → 동반된 상기도 감염 증상이 있음. (턴 10)
- 근거 : 폐렴구균 백신을 제때 접종했다고 함 → 확인된 예방접종력이며, 중이염을 배제하지는 않음. (턴 14)
- 근거 : 진찰상 의식이 명료하고 처짐·탈수·경부강직이 없으며, 호소상 숨참과 쌕쌕거림이 없음 → 현재 기록상 중증 전신질환이나 수막 자극 소견은 뚜렷하지 않음. (턴 4, 9, 20, 24, 27)
```

## [A] 감별진단

```
r/o 바이러스성 상기도 감염 (Viral upper respiratory infection) : 맑은 콧물과 가벼운 기침은 지지하지만, 우측 귀 통증 호소와 진찰상 고막 팽윤·발적은 단순 상기도 감염만으로 설명하기 어려움 (시작 정보; 턴 10, 19). 감별 검사 : 임상 경과 관찰; 필요 시 호흡기 바이러스 검사
r/o 급성 인두염 (Acute pharyngitis) : 발열과 진찰상 경도 인두 발적은 지지하나, 편도 삼출물이 없고 우측 고막의 뚜렷한 이상 소견이 확인됨 (시작 정보; 턴 19, 22). 감별 검사 : 필요 시 인두 신속항원검사
r/o 외이도염 (Otitis externa) : 귀 통증 호소는 가능하지만, 진찰상 우측 고막 팽윤과 발적이 있어 중이 병변을 더 지지함 (시작 정보; 턴 3, 19). 감별 검사 : 이경검사로 외이도 상태 확인
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C
- 외래 : 의식이 명료하고 탈수나 호흡곤란, 처짐, 경부강직이 없습니다. 고막 진찰상 우측 급성 중이염으로 보이며 외래에서 관찰과 치료가 가능합니다.
```

## [P] 추적

```
- 48~72시간 후 재평가하여 열과 귀 통증의 호전 여부를 확인합니다.
- 호전이 없거나 악화하면 더 일찍 진료받고 항생제 필요성을 다시 판단합니다.
- 즉시 내원 : 귀 뒤 붓기, 처짐, 목 뻣뻣함, 고열 지속
```

## [P] 환자 교육

```
진료 중 설명함:
- 오른쪽 급성 중이염으로 보여요.
- 귀를 살펴 고막 염증을 확인했어요.
- 해열진통제로 통증을 줄이고 지켜볼 수 있어요.
- 귀 뒤 붓기·처짐·목 뻣뻣함·열 지속이면 바로 오세요.
- 2~3일 뒤 귀 상태를 다시 볼게요.
- 귀 뒤 붓기·처짐·목 뻣뻣함도 생기면 바로 오세요.
다음 방문 시 교육 예정 : 고막 진찰로 중이염을 확인했으며 현재 추가 검사는 보통 필요하지 않습니다.; 콧물과 기침이 함께 있어 감기 뒤 중이에 염증이 생겼을 가능성이 있습니다.
```

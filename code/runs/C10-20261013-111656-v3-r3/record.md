## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 평소 약 56kg에서 석 달간 약 7kg 감소해 현재 약 49kg이며 감량 노력은 없다고 호소함 → 의미 있는 비의도적 체중 감소임. (시작 정보)
- 근거 : 두근거림, 손떨림, 더위 민감, 식욕 증가와 묽은 변을 호소함 → 갑상샘기능항진에 부합하는 전신 증상 조합임. (턴 4, 5, 6, 7, 9)
- 근거 : 진찰상 규칙적이고 강한 맥박 102회/분, 양측 자세성 떨림, 따뜻하고 습한 손바닥이 확인됨 → 갑상샘중독 상태를 뒷받침함. (턴 25, 26, 27)
- 근거 : 진찰상 양측 안구 돌출·안검 지연·안검 후퇴와 대칭성 미만성 갑상샘 비대 및 갑상샘 잡음이 확인됨 → 그레이브스병을 강하게 시사함. (턴 24, 28, 35)
- 근거 : 복용약과 영양제가 없다고 답함 → 외인성 갑상샘호르몬 또는 보충제 복용에 의한 증상 가능성을 낮춤. (턴 12)
```

## [A] 감별진단

```
r/o 독성 다결절성 갑상샘종 : 체중 감소와 두근거림 등 갑상샘기능항진 양상은 고려 근거이나, 진찰상 결절 없이 양측 대칭성 미만성 비대이고 안구 돌출 징후가 있어 그레이브스병에 더 부합함 (시작 정보; 턴 4, 24, 35). 감별 검사 : 갑상샘 초음파 및 갑상샘 스캔
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 두근거림은 가능하지만, 진찰상 갑상샘 압통이 없고 잡음과 안구 징후가 있어 그레이브스병이 더 가능함 (시작 정보; 턴 4, 24, 28, 35). 감별 검사 : TSH·유리 T4 및 갑상샘 섭취율 검사
r/o 당뇨병 : 비의도적 체중 감소와 식욕 증가가 있어 감별에 포함되나, 수분 섭취는 이전과 비슷하고 소변 횟수도 비슷하거나 약간 증가한 정도이며 갑상샘 안징후와 미만성 비대가 확인됨 (시작 정보; 턴 6, 10, 21, 24, 35). 감별 검사 : 공복 혈당 및 당화혈색소
```

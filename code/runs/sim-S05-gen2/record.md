## [A] 근거

```
#1. 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 (Left S1 radiculopathy due to lumbar disc herniation)
- 근거 : 열흘 전 이삿짐을 옮기다 허리를 삐끗한 뒤 통증이 시작됐고, 사흘째부터 왼쪽 엉덩이에서 발 바깥쪽까지 전기 오듯 찌릿한 방사통을 호소함 → 급성 요추 신경근 자극 양상으로 추간판 탈출증이 가장 의심됨. (시작 정보; 턴 2, 10)
- 근거 : 오래 앉기와 기침·재채기 시 통증이 악화된다고 호소함 → 디스크성 신경근 자극과 부합함. (턴 4)
- 근거 : 진찰상 좌측 발 외측과 새끼발가락의 감각 저하가 있고, 아킬레스건 반사는 우측 2+에 비해 좌측 1+임 → 좌측 S1 신경근 침범을 뒷받침함. (턴 23, 24)
- 근거 : 진찰상 좌측 하지직거상 검사에서 40도에 방사통이 재현되고, 족저굴곡 근력은 Gr.5/Gr.4로 좌우 차이가 관찰됨 → 신경근병증을 지지함. (턴 22, 25)
- 근거 : 왼쪽 다리에 힘이 덜한 듯하다고 호소하며 진찰상 왼쪽 체중부하를 피하는 보행이 관찰됨 → 증상의 기능적 영향을 뒷받침함. (턴 8, 26)
- 근거 : 대소변 문제, 요폐·실금, 회음부 감각저하, 발열·오한을 호소하지 않고 극돌기 타진 압통도 없음 → 마미증후군이나 전신 감염을 시사하는 소견은 현재 확인되지 않음. (턴 6, 7, 9, 27)
```

## [A] 감별진단

```
r/o 요추 염좌 및 근육 긴장 : 이삿짐을 옮기다 허리를 삐끗한 뒤 허리 통증이 시작된 점은 염좌와 맞지만, 왼쪽 엉덩이부터 발 바깥쪽까지의 방사통과 S1 분포 감각·반사 이상은 단순 염좌만으로 설명하기 어려움 (시작 정보; 턴 2, 23, 24). 감별 검사 : 증상 경과에 따른 임상 재평가; 지속 또는 악화 시 요추 MRI
r/o 요추 신경공 협착증에 의한 좌측 신경근병증 : 방사통과 좌측 S1 분포 감각·반사 이상은 신경근병증에 부합하나, 이번 증상이 허리를 삐끗한 뒤 급격히 시작된 점은 급성 추간판 병변을 더 지지함 (시작 정보; 턴 2, 10, 23, 24). 감별 검사 : 요추 MRI
r/o 천장관절 기능장애 : 허리를 삐끗한 뒤 통증이 시작된 점은 고려할 수 있으나, 발 바깥쪽까지의 방사통과 진찰상 감각 저하·아킬레스건 반사 저하는 신경근 병변을 더 시사함 (시작 정보; 턴 2, 23, 24). 감별 검사 : FABER, thigh thrust 등 천장관절 유발 검사
```

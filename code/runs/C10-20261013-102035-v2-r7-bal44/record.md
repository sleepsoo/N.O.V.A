## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 의도적인 감량 없이 3개월간 약 56kg에서 49kg으로 7kg 감소 → 유의한 비의도적 체중 감소로, 대사 항진 상태를 시사함 (시작 정보)
- 근거 : 식욕 증가와 더위 민감, 안정 시 심계항진, 손떨림 및 야간 발한 호소 → 갑상샘항진증에 합당한 증상군 (턴 1, 2, 3, 4, 10)
- 근거 : 진찰상 대칭성 미만성 갑상샘 비대와 안검 징후를 동반한 양측 안구 돌출, 갑상샘 잡음 → 그레이브스병을 강하게 지지함 (턴 24, 25, 29)
- 근거 : 진찰상 빈맥과 강한 맥박, 온난하고 습한 피부, 자세성 떨림 및 하지 근위부 근력 저하·항진된 슬개건반사 → 갑상샘호르몬 과다에 의한 전신 소견으로 해석됨 (턴 26, 27, 28, 30, 31)
- 근거 : 목에서 혹이 만져지지 않았고 진찰상 갑상샘은 결절 없이 매끈하고 미만성으로 비대했으며 압통도 없음 → 결절성 질환이나 압통성 갑상샘염보다 그레이브스병에 더 부합함 (턴 12, 24)
- 근거 : 수분 섭취 증가는 없고 소변 횟수는 조금 늘어난 정도라고 호소함 → 체중 감소와 식욕 증가가 당뇨병을 시사할 수는 있으나, 두드러진 갑상샘 특이 증상·진찰 소견이 더 설득력 있음 (턴 6, 11, 24, 25, 29)
```

## [A] 감별진단

```
r/o 독성 다결절성 갑상샘종 : 체중 감소와 갑상샘항진증 양상은 고려 근거이나, 젊은 연령이며 진찰상 결절 없이 대칭성 미만성 비대이고 안구 징후와 갑상샘 잡음이 있어 덜 가능함 (시작 정보; 턴 24, 25, 29). 감별 검사 : 갑상샘 초음파, 갑상샘 기능검사
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 심계항진 등은 맞을 수 있으나, 진찰상 갑상샘 압통이 없고 잡음 및 양측 안구 징후가 있어 그레이브스병을 더 지지함 (시작 정보; 턴 3, 24, 25, 29). 감별 검사 : TSH·유리 T4, 갑상샘 섭취율 검사
r/o 당뇨병 : 비의도적 체중 감소, 식욕 증가와 소변 횟수의 약간 증가가 고려 근거이나, 수분 섭취 증가는 없고 미만성 갑상샘 비대 및 안구 징후가 확인되어 덜 가능함 (시작 정보; 턴 1, 6, 11, 24, 25). 감별 검사 : 공복 혈당, 당화혈색소
r/o 악성 종양 : 비의도적 체중 감소 자체는 고려 근거이나, 식욕 증가와 갑상샘항진증에 특징적인 병력 및 진찰 소견이 체중 감소를 더 잘 설명함 (시작 정보; 턴 1, 24, 25, 29). 감별 검사 : CBC·대사 패널 및 병력·진찰에 따른 표적 평가
```

## [A] 근거

```
#1. 가족성 성장장애 (Familial short stature)
- 근거 : 신장 105cm(3백분위수 미만) & 체중 16.5kg(3~10백분위수) → 성장곡선이 타이핑 별로 매우 낮음(턴 36, 39)
- 근거 : 성장 속도 5cm/년(정상 하한) & 최근 1년간 키 증가 5cm → 성장 속도의 취약성이 명백하지만 급성 감소는 아님(턴 39, 40)
- 근거 : 가족력(아빠·부모·조부모의 키가 평균 이하, 아빠는 어릴 때 키가 작았음) → 유전적 성장 장벽이 존재함(턴 22, 28)
- 근거 : 갑상선 촉진 결과 비대·결절·압통 없음, 중증 구조적 이상 부재 → 구조적 갑상선 질환 예외(턴 37)
- 근거 : 식욕 양호, 비만이 아님, 기초 대사 및 영양소 섭취 정상으로 추정 → 결핍성 성장 억제 가능성 낮음(턴 25, 26)
```

## [A] 감별진단

```
r/o 성장호르몬결핍 : 성장 속도 5cm/년이 정상 하한에 근접해 있으나 HGH 수치나 IGF‑1 검사를 통해 확인 예정, GH 자극 시험 필요
r/o 갑상선기능저하 : 갑상선 촉진 비대・결절 없음, TSH/Free‑T4 검사로 제외 가능성
r/o 영양소 결핍 : 식욕 양호하고 체중은 비만이 아니므로 영양 불충분 가능성 낮음, 혈액 영양소 검사를 통해 확인
```

## [P] 추가 검사

```
- 혈당 및 인슐린 검사 (성장 호르몬 체계와 대사 조절 연관성 확인)
- 성장호르몬 및 IGF‑1, IGFBP‑3 검사 (성장 호르몬 결핍 배제)
- 갑상선 기능 검사 (TSH, FT4, FT3, 갑상선저하 및 과다 배제)
- 영양소 검사(철분, 비타민 D, 칼슘, 단백질 수치) (영양 결핍 여부 확인)
- 골밀도 초음파 혹은 방사선 검사 (골 이상 여부 확인)
- 가족 성장 차이 유전학 상담(필요 시)
```

## [P] 치료

```
- 성장호르몬 치료 시작 전 검사 결과 확인 후 시작 고려
- 식이·문질 개선을 위한 영양 관리(고단백, 칼슘, 비타민 D 충분섭취)
- 꾸준한 중간 정도 근력 및 유연성 운동(주 3회, 안전 검토 후 진행)
- 골격 발달 촉진을 위해 정기적으로 성장량 기록 및 모니터링
- 성장 장해가 보이는 경우 약물 부작용 및 금기 항목 사전 확인
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 100/60 mmHg, PR 90회/분, RR 20회/분, BT 36.7°C
- 외래 추적 관찰 결정(운동·영양 관리 후 재검사)
- 필요 시 전문과(성장 호르몬 전문 클리닉) 의뢰 예정
```

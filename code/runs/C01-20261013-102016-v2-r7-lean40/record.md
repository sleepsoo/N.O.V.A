## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 7년 전부터 졸피뎀을 복용했고 한 알이 10mg이라고 호소함 → 장기간 진정수면제 사용 (턴 2, 3)
- 근거 : 현재 밤에 6알을 복용하고 가끔 낮에도 1알을 복용하며, 복용량이 반 알에서 6알로 늘었다고 호소함 → 용량 증량과 고용량 사용은 내성·조절 상실을 시사 (턴 4, 6)
- 근거 : 감량·중단을 여러 번 시도했으나 다시 복용했다고 호소함 → 사용을 줄이려는 시도가 반복적으로 실패함 (턴 9)
- 근거 : 복용 후 기억이 나지 않는 경우가 있다고 호소하며, 진찰상 졸림과 반응 지연이 관찰됨 → 사용과 관련된 기억 및 주간 기능 영향이 있음 (턴 14, 23)
- 근거 : 남편과 딸이 약 복용을 걱정하고 환자도 약 없이는 잠들지 못할까 걱정하며 감량 가능성을 묻는다고 호소함 → 약물 사용으로 인한 우려와 감량 동기가 확인됨 (턴 8, 15, 20)
- 근거 : 경련 병력은 없고 진찰상 급성 중독 징후가 없으며 의식이 명료하고 지남력이 유지됨 → 현재 경련이나 뚜렷한 급성 중독 상태를 뒷받침하는 소견은 없음 (턴 13, 22, 23)
```

## [P] 치료

```
- 급중단 금지 — 당일 처방 내역(DUR)·실제 총량 확인 후 첫 처방은 확인된 평소 1일 사용량을 넘지 않는 고정 일정(취침 전 정해진 시각)으로 1~2주분만(처방 일원화, 보호자 보관·복용 확인, 주간·추가 복용과 조기 재처방 없음), 이후 1~2주마다 10~25%씩 감량
- 음주·약국 수면유도제 등 다른 진정성 물질 병용 금지
- 급격한 중단 금지 — 실제 총량 확인 후 1~2주마다 10~25%씩 점진 감량(금단에 따라 조절)
- 처방 일원화(본원 한 곳), 추가·주간 복용 금지, 약국 수면유도제 중단
- 수면위생·수면일지·CBT-I, 정신건강의학과(중독·수면)와 협진
- 기존 복용약(예: 혈압약)은 유지
- 수면위생 교육, 수면일지와 불면 인지행동치료를 권하고 정신건강의학과 수면·중독 진료를 연계합니다.
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 급성 위험 징후 없어 입원 불필요, 외래 추적

- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

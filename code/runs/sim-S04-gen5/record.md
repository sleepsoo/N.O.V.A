## [A] 근거

```
#1. 만성폐쇄성폐질환의 급성 악화 (Acute exacerbation of chronic obstructive pulmonary disease)
- 근거 : 사흘 전부터 숨참·기침·가래가 악화되고, 수년간의 만성 숨참과 가벼운 활동에도 숨찬 호소가 있음 → 만성 기류 제한의 급성 악화에 부합 (시작 정보)
- 근거 : 진찰상 호흡음 감소, 호기 연장, 양측 미만성 호기성 천명음 → 폐쇄성 기류 제한을 지지 (턴 22)
- 근거 : 진찰상 술통형 흉곽과 양측 과공명음, 입술 오므린 호흡 및 경도 보조호흡근 사용 → 만성 폐쇄성 폐질환에 부합하는 소견 (턴 23, 28, 30)
- 근거 : 실내 공기에서 SpO2 89% → 급성 악화에 동반된 저산소혈증 (턴 21)
- 근거 : 하루 종일 많은 누렇고 끈적한 가래와 오한 호소 → 감염이 악화의 유발 요인일 가능성을 높임 (턴 2, 4)
- 근거 : 진찰상 수포음·경정맥 팽창·S3·함요부종이 없음 → 급성 심부전을 뒷받침하는 소견이 적음 (턴 22, 24, 25, 26)
```

## [A] 감별진단

```
r/o 폐렴 : 기침과 다량의 누런 가래, 오한 및 열이 조금 나는 것 같다는 호소가 있어 고려하나, 진찰상 수포음이 없고 촉각 진탕이 확인되지 않음 (시작 정보; 턴 2, 4, 22, 29). 감별 검사 : 흉부 X선, 혈액검사
r/o 급성 심부전 : 만성 숨참과 누울 때 숨참, 고혈압 병력은 고려 근거이나, 진찰상 경정맥 팽창·S3·수포음·함요부종이 없음 (시작 정보; 턴 6, 9, 22, 24, 25, 26). 감별 검사 : BNP 또는 NT-proBNP, 심초음파
r/o 폐색전증 : 숨참 악화와 저산소혈증, 빈맥은 고려 근거이나, 진찰상 종아리 압통이나 둘레 차이가 없고 폐쇄성 호흡기 소견이 두드러짐 (시작 정보; 턴 21, 22, 25, 27). 감별 검사 : 임상 위험도 평가 후 D-dimer 또는 CT 폐혈관조영술
```

## [A] 근거

```
#1. 우측 급성 중이염 (Right acute otitis media)
- 근거 : 어제 낮부터 발열을 호소했고, 진찰상 체온은 38.6°C → 급성 감염성 질환에 부합한다. (시작 정보; 턴 9, 29)
- 근거 : 오른쪽 귀 통증을 호소하고 귀를 잡아당기며 울었다고 함 → 국소 귀 증상이 있다. (시작 정보; 턴 2)
- 근거 : 진찰상 우측 고막 발적·팽윤 및 광반사 소실이 있고 이루는 없음 → 급성 중이염을 뒷받침하는 핵심 소견이다. (턴 20)
- 근거 : 맑은 콧물과 가벼운 기침을 호소하고 비점막 부종이 진찰됨 → 동반 상기도 감염이 중이염에 선행하거나 함께 있을 수 있다. (턴 11, 26)
- 근거 : 진찰상 의식은 명료하고 연령에 맞게 반응하며 경부강직·케르니그·브루진스키 징후와 발진이 없음 → 현재 수막염을 시사하는 소견은 확인되지 않는다. (턴 22, 23, 24)
```

## [A] 감별진단

```
r/o 바이러스성 상기도 감염 (viral upper respiratory infection) : 맑은 콧물과 가벼운 기침을 호소하고 비점막 부종이 진찰되어 동반 가능하지만, 우측 귀 통증과 고막 팽윤·발적은 단순 상기도 감염만으로 설명하기 어렵다 (시작 정보; 턴 11, 20, 26). 감별 검사 : 임상 경과 관찰; 필요 시 호흡기 바이러스 검사
r/o 외이도염 (otitis externa) : 귀 통증과 귀를 잡아당기는 행동은 있지만, 진찰상 우측 고막 팽윤·발적이 확인되어 급성 중이염이 더 잘 부합한다 (시작 정보; 턴 2, 20). 감별 검사 : 외이도 시진 및 이주 압통 확인
r/o 수막염 (meningitis) : 발열은 있으나 의식이 명료하고 경부강직·케르니그·브루진스키 징후, 발진이 진찰상 확인되지 않아 가능성이 낮다 (시작 정보; 턴 22, 23, 24). 감별 검사 : 임상적으로 의심 소견이 새로 나타나면 뇌척수액 검사 고려
```

## [P] 추가 검사

```
- 고막 진찰 : 우측 고막의 팽윤과 발적을 확인해 급성 중이염을 평가했습니다.
- 신경학적·경부 진찰 : 의식 변화와 목 경직 등 수막염을 시사하는 소견이 있는지 확인했습니다.
- 활력징후와 산소포화도 : 발열과 함께 호흡·순환 상태가 안정적인지 확인했습니다.
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C
- 외래 : 의식이 명료하고 처짐·탈수·목 경직·호흡곤란이 없으며, 산소포화도와 호흡 상태가 안정적입니다. 현재 응급 입원 소견이 없어 외래에서 경과를 볼 수 있습니다.
```

## [P] 추적

```
- 48~72시간 후 외래에서 열과 귀 통증, 고막 상태를 재평가합니다.
- 그전이라도 악화하거나 경고 증상이 나타나면 바로 진료받습니다.
```

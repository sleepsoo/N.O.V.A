## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth)
- 근거 : 보호자 호소상 1년간 키가 100cm에서 105cm로 약 5cm 증가했고, 성장도표상 성장속도는 연 5cm로 정상 하한이다 → 심한 성장속도 저하보다는 정상 하한의 성장 양상이다. (시작 정보; 턴 25)
- 근거 : 진찰상 신장 105cm는 3백분위수 미만이고 체중 16.5kg은 3~10백분위수이다 → 저신장이 확인되나 체중도 낮은 백분위수에 있다. (턴 24, 25)
- 근거 : 아버지는 고등학교 때 많이 컸다고 하며, 부모 키는 각각 178cm와 165cm이고 기록된 중간부모키는 178cm이다 → 부모의 작은 체격에 따른 가족성 저신장보다는 늦은 성장의 가족력이 고려된다. (턴 4, 5, 25)
- 근거 : 보호자 호소상 식사를 하루 세 끼 잘하고 활발히 놀며, 피로를 잘 느끼지 않고 급격한 체중 변화도 없다 → 영양 부족이나 만성 전신질환을 뒷받침하는 병력은 확인되지 않는다. (턴 10, 15, 16)
- 근거 : 진찰상 상·하절 비율은 정상이고 양팔 간격 불균형과 안면 기형은 없으며, 갑상선 비대도 없다 → 골격 비율 이상이나 명백한 신체 진찰 이상은 확인되지 않는다. (턴 26, 28, 29)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 : 신장이 3백분위수 미만이고 성장속도가 정상 하한이어서 고려한다. 다만 성장속도는 연 5cm로 기록되어 있고, 성장호르몬 결핍을 확정할 검사 결과는 없다 (시작 정보; 턴 25). 감별 검사 : IGF-1 및 IGFBP-3, 필요 시 성장호르몬 자극검사
r/o 가족성 저신장 : 저신장은 가족성일 수 있으나 부모 키는 178cm와 165cm이고 기록된 중간부모키는 178cm여서 가족성 저신장을 지지하지 않는다 (턴 4, 25). 감별 검사 : 부모 키와 성장기록을 이용한 목표키 비교
r/o 갑상선기능저하증 : 저신장과 성장속도 저하의 감별에 포함되지만, 피로 호소는 없고 진찰상 갑상선 비대도 없다 (턴 10, 25, 29). 감별 검사 : 혈청 TSH 및 유리 T4
r/o 영양 부족 또는 만성 전신질환에 따른 성장장애 : 체중이 3~10백분위수여서 고려할 수 있으나, 보호자는 식사를 잘한다고 하고 활발하며 급격한 체중 변화나 알려진 장·콩팥 질환이 없다 (턴 7, 10, 15, 16, 25). 감별 검사 : 식이 및 성장기록 검토, 임상 소견에 따른 CBC·대사검사 및 염증·셀리악 선별검사
```

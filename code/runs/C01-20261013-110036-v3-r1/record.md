## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 호소상 7년 전부터 졸피뎀을 복용했고, 10mg 정제를 밤에 5~6알(50~60mg) 복용하며 낮에도 가끔 1알 복용함 → 장기간 고용량·반복 사용을 시사함. (턴 9, 15, 16)
- 근거 : 호소상 감량을 여러 번 시도했으나 실패했고, 약을 먹지 않으면 잠을 전혀 못 자며 손 떨림과 가슴 두근거림이 생김 → 조절 실패와 금단 관련 증상을 동반한 사용장애를 강하게 시사함. (턴 2, 6, 8, 10)
- 근거 : 호소상 낮 졸림, 집안일 중 깜빡 잠듦, 복용 후 기억 단절이 있고 진찰상 반응 지연·졸림이 관찰됨 → 졸피뎀 사용에 따른 기능 저하 및 부작용 가능성이 있음. (턴 4, 7, 14, 28)
- 근거 : 진찰상 급성 중독 징후는 없고 의식은 명료하며 지남력 3/3점, MMSE-K 28/30점임 → 현재 급성 중독이나 뚜렷한 지남력 장애를 주된 설명으로 보기 어려움. (턴 28, 29, 36)
- 근거 : 호소상 감량 실패와 과다 복용에 대해 남편과 딸도 걱정함; 모친의 치매 병력이 있어 기억력 저하에 대한 평가도 고려할 필요가 있음. (턴 5, 19, 21)
```

## [A] 감별진단

```
r/o 졸피뎀 부작용 : 주간 졸림·집안일 중 잠듦·복용 후 기억 단절을 호소하고 진찰상 졸림과 반응 지연이 있어 부작용이 동반될 수 있으나, 감량 실패와 복용 중단 시 증상은 사용장애를 더 지지함 (턴 4, 7, 10, 14, 28). 감별 검사 : 복용 약물·실제 복용량 및 복용 시각 확인
r/o 불면장애 : 잠을 잘 못 자고 약 없이는 잠을 못 잔다고 호소하나, 장기간 고용량 복용과 감량 실패 및 미복용 시 떨림·두근거림이 있어 일차 불면장애만으로 설명하기 어려움 (시작 정보; 턴 2, 6, 8, 10, 16). 감별 검사 : 수면력 및 수면일지 평가
r/o 폐쇄성 수면무호흡증 : 주간 졸림과 집안일 중 잠듦을 호소해 고려할 수 있으나, 현재 기록에서는 졸피뎀 복용이라는 더 직접적인 설명이 있음 (턴 4, 7, 16). 감별 검사 : 수면다원검사
r/o 우울장애 관련 불면 : 수면 곤란은 호소하지만 많이 가라앉지는 않는다고 답해 우울 증상에 의한 불면을 뒷받침하는 근거가 제한적임 (시작 정보; 턴 26). 감별 검사 : 우울 증상 선별 및 임상 면담
```

## [P] 추가 검사

```
- 처방 내역 조회(DUR) : 여러 기관에서 받은 진정수면제의 종류와 총량을 확인합니다.
- 소변 약물 선별검사 : 다른 진정제 병용 여부를 확인합니다. 졸피뎀은 검사에서 검출되지 않을 수 있습니다.
- 혈액검사(CBC, 간·신기능, 전해질, 혈당) : 기저 건강 상태와 감량 중 안전을 확인합니다.
- 갑상샘 기능검사(TFT) : 두근거림과 떨림의 다른 원인을 살펴봅니다.
- 심전도 : 두근거림과 약 조정 전 심장 상태를 확인합니다.
```

## [P] 치료

```
- 현재 복용 중인 수면제를 오늘 갑자기 중단하지 않음(금단·경련 위험) — 처방 내역 확인 후 정신건강의학과 전문의 감독 아래 점진 감량 계획 수립
- 처방 기관 일원화, 임의 증량·추가 복용 금지, 술·약국 수면유도제 등 다른 진정성 물질 병용 금지
- 비약물 치료: 불면 인지행동치료(CBT-I), 수면위생 교육, 수면일지
- 기존 복용약은 유지하며 금기·약물 상호작용 확인, 금단 증상과 부작용 모니터링
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 현재 외래 추적이 적절하며, 증상 악화나 경고 증상이 생기면 응급 평가·입원 고려
- 의식 명료, 급성 중독·심한 금단 징후 없어 외래 감량 — 단, 금단 경련·섬망 병력이 있거나 보호자 감독이 어려우면 입원 해독 고려
- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

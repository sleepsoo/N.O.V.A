## [A] 근거

```
#1. 급성 우측 중이염 (Acute right otitis media)
- 근거 : 어제 낮부터 발열이 시작되어 어젯밤 최고 38.9°C였다는 호소는 급성 감염 경과에 부합한다. (턴 2, 5)
- 근거 : 오른쪽 귀를 잡아당기며 아파서 울고 귀 통증을 호소한다는 점은 우측 귀의 국소 증상을 뒷받침한다. (턴 6, 14)
- 근거 : 진찰상 우측 고막 발적과 팽윤, 광반사 소실이 있어 급성 중이염에 전형적으로 부합한다. (턴 26)
- 근거 : 맑은 콧물과 가벼운 기침이 먼저 있었고 진찰상 맑은 콧물과 경도의 비점막 부종이 있어 선행 상기도 감염이 동반된 것으로 해석된다. (턴 15, 27)
- 근거 : 귀 뒤 부종과 발적이 없다는 점은 유양돌기염의 임상적 뒷받침을 낮춘다. (턴 16)
- 근거 : 의식이 명료하고 연령에 맞게 반응하며 경부강직·케르니그 징후·브루진스키 징후와 발진이 없어 현재 진찰에서 수막염을 시사하는 소견은 확인되지 않는다. (턴 25, 29, 30)
```

## [A] 감별진단

```
r/o 바이러스성 상기도 감염 (Viral upper respiratory infection) : 맑은 콧물과 가벼운 기침은 지지하지만, 우측 고막의 발적·팽윤 및 광반사 소실은 단순 상기도 감염만으로 설명하기 어렵다 (턴 15, 26). 감별 검사 : 필요한 경우 호흡기 바이러스 PCR
r/o 외이도염 (Otitis externa) : 귀 통증은 고려 근거이나, 진찰상 우측 고막 팽윤과 발적은 외이도보다 중이 병변을 더 지지한다 (턴 6, 26). 감별 검사 : 외이도 시진 및 이주 압통·귓바퀴 당김 통증 확인
r/o 급성 유양돌기염 (Acute mastoiditis) : 발열과 귀 통증은 고려할 만하지만, 귀 뒤 부종과 발적이 없어 현재 이를 지지하는 소견은 부족하다 (시작 정보; 턴 16). 감별 검사 : 유양돌기 부위 재진찰; 의심 소견이 있으면 측두골 CT
```

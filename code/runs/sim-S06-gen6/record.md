## [S] 현병력

```
56세 여성으로, 2~3개월 전부터 피로하고 목이 자주 마른 증상이 있어 내원함.
물을 많이 마시고 소변을 자주 보며, 낮에 10회 넘게, 밤에 2~3회 배뇨한다고 함. 최근 체중이 3kg 정도 감소했다고 함.
눈이 침침하고 글씨가 흐릿하게 보일 때가 있으며, 질 주변 가려움과 분비물 증가를 호소함.

혈당이 조금 높다고 들어 운동을 권유받았으나 이후 재검하지 않았다고 함. 고혈압 및 당뇨 진단을 받은 적은 없다고 함.
아버지가 당뇨로 투석 중이며 본인도 아버지처럼 투석하게 될까 봐 걱정된다고 함.
```

## [A] 근거

```
#1. 제2형 당뇨병 (Type 2 diabetes mellitus)
- 근거 : 두세 달 전부터 심한 피로와 갈증을 호소하고 물을 많이 마시며 소변을 자주 본다고 함 → 증상성 고혈당에 부합함 (시작 정보)
- 근거 : 이전에 혈당이 조금 높다고 들었으나 재검하지 않았다고 함 → 확인되지 않은 고혈당 병력이 있음 (턴 2)
- 근거 : 약 3kg 체중 감소를 호소함 → 다뇨·다갈과 함께 고혈당에서 나타날 수 있는 증상임 (시작 정보; 턴 6)
- 근거 : 비만 체형과 후경부·액와 흑색극세포증이 진찰상 확인됨 → 인슐린 저항성 및 제2형 당뇨병 가능성을 뒷받침함 (턴 20, 22)
- 근거 : 부친이 당뇨병으로 투석을 받았다고 함 → 당뇨병 가족력이 있음 (턴 3)
- 근거 : 배뇨통·혈뇨·옆구리 통증·발열을 호소하지 않음 → 요로감염을 다뇨의 주원인으로 볼 근거는 상대적으로 약함 (턴 11, 12)
```

## [A] 감별진단

```
r/o 만성 신장질환 : 부친이 당뇨병으로 투석을 받았고 잦은 배뇨를 호소해 고려할 수 있으나, 거품뇨와 부종은 호소하지 않았고 진찰상 함요부종도 없음 (시작 정보; 턴 3, 15, 25). 감별 검사 : 혈청 크레아티닌/eGFR, 소변 알부민-크레아티닌비
r/o 요로감염 : 잦은 배뇨를 호소하지만 배뇨통·혈뇨·옆구리 통증·발열은 호소하지 않아 전형적 요로감염 소견은 부족함 (시작 정보; 턴 11, 12). 감별 검사 : 요검사, 소변배양검사
r/o 요붕증 : 갈증과 수분 섭취 증가, 잦은 배뇨를 호소해 고려할 수 있으나 혈당이 조금 높았다는 병력과 인슐린 저항성을 시사하는 진찰 소견이 있음 (시작 정보; 턴 2, 22). 감별 검사 : 혈청 나트륨·삼투압, 소변 삼투압
r/o 고칼슘혈증 : 피로와 갈증, 잦은 배뇨는 고칼슘혈증에서도 나타날 수 있으나 이 환자에서는 이를 확인할 혈액검사 결과가 없음 (시작 정보). 감별 검사 : 혈청 총칼슘과 알부민
```

```

- 혈액검사: 크레아티닌, 사구체여과율, 간기능, 칼슘 : 신장·간 기능과 칼슘 수치를 확인해 갈증·잦은 배뇨의 원인 및 치료 안전성을 평가합니다.
- 소변검사: 당, 케톤, 단백, 알부민, 염증 소견 : 당뇨와 신장 손상 여부를 살피고 요로감염·케톤 동반 여부를 확인합니다.
- 소변 배양검사 : 소변검사에서 감염이 의심되면 요로감염 여부와 원인균을 확인합니다.
- 지질검사 : 당뇨와 함께 심혈관 위험을 평가하고 치료 전 기준을 확인합니다.
- 갑상샘 기능검사 : 피로와 체중 감소에 갑상샘 질환이 관여하는지 살핍니다.
```

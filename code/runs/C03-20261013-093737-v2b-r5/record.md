## [A] 근거

```
#1. 체질성 성장지연 (Constitutional growth delay)
- 근거 : 현재 신장 105cm로 신장 백분위수 3 미만이고, 성장속도는 연 5cm로 정상 하한에 해당함 → 저신장은 확인되나 성장속도는 현저히 저하된 양상은 아님 (턴 25, 26)
- 근거 : 보호자 호소상 1년간 키가 100cm에서 105cm로 약 5cm 증가함 → 진찰에서 확인된 정상 하한 성장속도와 부합함 (시작 정보; 턴 26)
- 근거 : 아버지 키 178cm, 어머니 키 165cm이며 중간부모키는 178cm이고 가족 중 키가 작은 사람은 없음 → 가족성 저신장을 뒷받침하지 않음 (턴 4, 6, 26)
- 근거 : 아버지가 고등학교 때 많이 성장했다고 함 → 가족 내 늦은 성장 시기의 병력이 체질성 성장지연을 지지함 (턴 5)
- 근거 : 만성 천식·장·콩팥 질환 및 스테로이드 복용력이 없고, 식사를 하루 세 끼 잘하며 체중이 1년간 15kg에서 16.5kg으로 증가함 → 만성질환·영양 부족 가능성을 낮춤 (시작 정보; 턴 7, 8, 15, 18)
- 근거 : 진찰상 상·하절 비율이 정상이고 양팔간격 불균형 및 갑상선 비대가 없으며, 복부 진찰에서 종괴와 간·비장 촉지가 없음 → 뚜렷한 골격 비율 이상이나 해당 진찰 소견은 확인되지 않음 (턴 27, 30, 31)
```

r/o 갑상선기능저하증 : 저신장으로 감별이 필요하지만 변비가 자주 없고 진찰상 갑상선 비대가 없음. 이 소견만으로 갑상선 기능 이상을 배제할 수는 없음 (턴 10, 24, 26, 30). 감별 검사 : TSH 및 유리 T4 검사

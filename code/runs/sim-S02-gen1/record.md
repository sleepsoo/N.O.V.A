## [A] 근거

```
#1. 무조짐 편두통 (Migraine without aura)
- 근거 : 두통이 수년간 간헐적으로 있었고 최근 3개월 더 잦아져 업무에 지장을 줌 → 반복되며 기능 저하를 일으키는 두통 양상 (시작 정보)
- 근거 : 두통은 하루, 길면 이틀 지속되고 주로 왼쪽 관자놀이·눈 뒤에 발생하며 가끔 오른쪽도 아픔 → 편두통에 부합하는 지속시간과 주된 편측성 (턴 2, 5)
- 근거 : 두통과 함께 메스꺼움과 구토를 호소함 → 편두통을 지지하는 동반 증상 (턴 11)
- 근거 : 모친이 젊을 때부터 편두통을 앓았고, 환자는 두통 전 번쩍임을 호소하지 않음 → 가족력이 있으며 시각 전조가 보고되지 않은 양상 (턴 15, 17)
- 근거 : 갑작스러운 최악의 두통, 팔다리 힘 빠짐, 말 어눌함, 발열 및 목 뻣뻣함을 호소하지 않음; 진찰상 유두부종·국소 신경학적 이상·경부강직이 확인되지 않음 → 현재 급성 출혈, 국소 병변 또는 수막 자극을 시사하는 소견이 뚜렷하지 않음 (턴 7, 8, 9, 20, 21, 26, 27, 30)
```

## [A] 감별진단

```
r/o 긴장형 두통 : 수년간 반복되는 두통은 고려할 수 있으나, 주로 편측 두통을 호소하고 메스꺼움과 구토가 동반되어 전형적인 긴장형 두통보다는 편두통을 더 지지함 (시작 정보; 턴 5, 11). 감별 검사 : 두통 일지와 임상 양상 평가
r/o 군발두통 : 관자놀이·눈 뒤의 편측 통증은 고려 근거이나, 한 번의 두통이 하루에서 이틀 지속된다고 호소해 전형적인 군발두통의 발작 지속시간과 맞지 않음 (턴 2, 5). 감별 검사 : 두통 발작 양상 및 동반 자율신경 증상에 대한 상세 문진; 비전형적이거나 지속되는 경우 뇌 MRI
r/o 이차성 두통 : 최근 3개월간 두통 빈도가 증가한 점은 고려할 필요가 있으나, 갑작스러운 최악의 두통이나 국소 신경 증상을 호소하지 않고 진찰에서도 유두부종, 국소 신경학적 이상, 경부강직이 확인되지 않음 (시작 정보; 턴 7, 8, 20, 21, 30). 감별 검사 : 뇌 MRI
```

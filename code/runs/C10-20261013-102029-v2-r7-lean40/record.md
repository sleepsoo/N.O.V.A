## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 다이어트나 운동 없이 최근 3개월간 약 56kg에서 49kg으로 7kg 감소한 호소는 임상적으로 의미 있는 비의도적 체중 감소이다. (시작 정보)
- 근거 : 식욕 증가, 더위 민감, 안정 시 심계항진과 손떨림을 호소하고 배변 횟수가 늘고 묽어졌다는 호소가 있어 갑상샘항진 증상군에 부합한다. (턴 1, 2, 3, 4, 5)
- 근거 : 진찰상 갑상샘이 양측 대칭으로 미만성 비대하고 잡음이 있으며, 안구 돌출·안검 지연·안검 후퇴가 확인되어 그레이브스병을 강하게 지지한다. (턴 22, 23, 27)
- 근거 : 진찰상 빈맥, 따뜻하고 발한이 있는 피부, 양측 자세성 떨림 및 항진된 슬개건 반사가 확인되어 갑상샘항진의 임상 소견에 부합한다. (턴 24, 25, 26, 29)
- 근거 : 모친의 갑상샘저하증 가족력은 갑상샘 질환 가족력이 있음을 보여 주지만, 그 자체로 그레이브스병을 특정하지는 않는다. (턴 19)
- 근거 : 갑상샘 결절과 압통이 없고 물 섭취 증가를 호소하지 않으며 복용 약·영양제가 없어, 결절성 원인·갑상샘염·당뇨병 또는 외인성 갑상샘호르몬 사용보다 그레이브스병이 더 잘 부합한다. (턴 6, 13, 22)
```

## [A] 감별진단

```
r/o 독성 갑상샘선종 : 체중 감소와 갑상샘항진 증상은 고려 근거이나, 진찰상 갑상샘이 결절 없이 대칭적으로 미만성 비대하고 안구 징후가 있어 독성 선종보다 그레이브스병에 더 부합한다 (시작 정보; 턴 2, 3, 22, 23). 감별 검사 : 갑상샘 초음파 및 방사성요오드 섭취율 검사
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 더위 민감·심계항진·손떨림은 갑상샘중독증의 감별 근거이나, 진찰상 압통이 없고 잡음과 안구 징후가 있어 갑상샘염보다는 그레이브스병을 지지한다 (시작 정보; 턴 2, 3, 4, 22, 23, 27). 감별 검사 : TSH·유리 T4 및 방사성요오드 섭취율 검사
r/o 당뇨병 : 비의도적 체중 감소와 식욕 증가는 고려 근거이나, 물 섭취 증가를 호소하지 않고 갑상샘 미만성 비대·안구 징후·잡음이 확인되어 당뇨병 단독보다 갑상샘항진증이 더 잘 설명한다 (시작 정보; 턴 1, 6, 22, 23, 27). 감별 검사 : 공복 혈당 및 당화혈색소
```

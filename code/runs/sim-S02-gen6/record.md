## [A] 근거

```
#1. 무조짐 편두통 (Migraine without aura)
- 근거 : 왼쪽 관자·눈 뒤가 주로 아프고 가끔 반대쪽도 아프며, 욱신거리는 양상이라고 호소함 → 편두통에 부합하는 편측성 박동성 두통 (턴 9, 10)
- 근거 : 두통 때 메스꺼움이 있고 심하면 구토한다고 호소함 → 편두통의 동반 증상에 부합 (턴 5)
- 근거 : 밝은 빛과 시끄러운 소리에 민감하고, 한 번 시작하면 하루에서 길게는 이틀 지속한다고 호소함 → 편두통의 감각 과민 및 지속 양상에 부합 (턴 11, 19, 20)
- 근거 : 한 달에 네다섯 번 발생하고 업무에 지장을 준다고 호소함 → 반복되는 임상적으로 유의한 두통 (시작 정보; 턴 11)
- 근거 : 두통 전 눈앞 번쩍임은 없다고 호소함 → 조짐 증상 없이 발생하는 편두통에 부합 (턴 21)
- 근거 : 모친이 젊을 때부터 편두통이 있었다고 함; 진찰상 유두부종·출혈이 없고 의식, 근력, 감각, 협조운동 및 보행이 정상이며 경부강직도 없음 → 편두통을 뒷받침하고 뚜렷한 신경학적 이상이나 수막자극 징후는 확인되지 않음 (턴 16, 23, 24, 28, 29, 30, 31, 32)
```

## [A] 감별진단

```
r/o 긴장형 두통 : 수년간 반복되는 두통이라는 점은 고려할 수 있으나, 편측성 욱신거림과 메스꺼움·구토, 빛·소리 민감은 긴장형 두통보다 편두통에 더 부합함 (시작 정보; 턴 5, 9, 10, 19, 20). 감별 검사 : 두통 일지 및 임상 양상의 ICHD-3 기준 평가
r/o 약물과용 두통 : 두통이 반복되고 이부프로펜을 복용하지만, 복용은 한 달에 다섯~여섯 번이라고 하여 약물과용 두통을 뒷받침하기에는 부족함 (턴 11, 14). 감별 검사 : 두통·진통제 복용 일지로 월별 복용 일수와 기간 확인
r/o 두개내 구조적 병변에 의한 이차성 두통 : 최근 석 달 동안 두통이 더 잦아졌다고 호소하여 고려할 필요는 있으나, 수년 전부터 반복된 경과와 정상 신경학적 진찰, 유두부종 및 경부강직 부재는 가능성을 낮춤 (시작 정보; 턴 8, 23, 24, 28, 29, 30, 31, 32). 감별 검사 : 뇌 MRI
```

## [P] 추가 검사

```
- 두통 양상과 동반 증상 확인 : 편두통과 긴장형 두통을 구분하고 두통 빈도와 일상 지장 정도를 파악합니다.
- 진통제 복용력 확인 : 진통제 사용이 잦아 약물과용 두통이 생겼는지 확인합니다.
- 혈압 측정 : 두통 평가와 급성기 약물 선택에 참고합니다.
- 두통일기 작성 : 두통 날짜, 지속 시간, 증상, 복용 약과 효과를 기록해 치료 계획을 세웁니다.
- 뇌 영상 검사 : 현재 신경학적 진찰은 정상이므로 우선 시행하지 않습니다. 벼락두통이나 신경학적 이상 등 경고 징후가 생기면 뇌 MRI 등을 고려합니다.
```

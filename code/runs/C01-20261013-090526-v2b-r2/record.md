## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative, Hypnotic, or Anxiolytic Use Disorder)
- 근거 : 호소상 10mg 정을 하루 5–6알(약 50–60mg) 복용하고 때때로 낮에도 추가 복용함 → 장기간 빈번한 고용량 복용 양상. (턴 2, 4, 5)
- 근거 : 호소상 반 알에서 5–6알로 복용량이 늘었고 감량·중단을 여러 번 시도했으나 다시 복용함 → 내성 및 조절 실패를 뒷받침함. (턴 6, 8)
- 근거 : 호소상 약을 먹지 않으면 불면과 온몸의 불안이 나타남 → 진정수면제 금단 또는 반동 증상 가능성을 뒷받침함. (턴 7)
- 근거 : 호소상 복용 후 기억이 나지 않을 때가 있고 낮에 졸리고 멍함; 진찰상 반응 지연과 졸림이 관찰됨 → 복용 관련 부작용 및 주간 기능 저하가 동반됨. (턴 11, 18, 26)
- 근거 : 호소상 약국 수면유도제를 가끔 함께 복용하고 가족도 약 복용을 걱정함; 진찰상 의식은 명료하고 지남력은 3/3점이며 급성 중독 징후는 관찰되지 않음 → 병용 위험은 있으나 진찰 당시 급성 중독 소견은 없음. (턴 9, 12, 25, 26)
```

## [A] 감별진단

```
r/o 만성 불면장애 (Chronic Insomnia Disorder) : 7년간 불면을 호소하고 잠들기 어렵고 자주 깬다고 함(F6, F18). 다만 하루 5–6알 복용, 복용량 증가 및 미복용 시 증상도 있어 독립적인 불면장애인지 약물 관련 증상인지 구분이 필요함(F9, F11, F12) (턴 1, 4, 6, 7, 13). 감별 검사 : 수면일지 및 불면 증상에 대한 구조화 평가
r/o 약물·물질 유발 수면장애 (Substance/Medication-Induced Sleep Disorder) : 고용량 졸피뎀 복용 중에도 수면 문제가 호소되고(F9, F18), 미복용 시 불면과 불안이 나타남(F12). 불면과 졸피뎀 복용 모두 약 7년 전부터라고 보고되어 시간적 선후관계는 분명하지 않음(F6, F8) (턴 1, 3, 4, 7, 13). 감별 검사 : 복용·수면 경과의 상세 문진과 의료진 감독하 감량 과정의 수면일지
r/o 불안 또는 우울 관련 수면장애 (Anxiety- or Depression-Related Sleep Disorder) : 약을 복용하지 않을 때 전신 불안을 호소하고 진찰상 초조가 관찰됨(F12, E2, E4). 다만 기분이 많이 가라앉지는 않는다고 호소하며, 불안은 약 미복용과 연동되어 독립적인 불안·우울 문제인지는 불확실함(F25, F12) (턴 7, 19, 24, 26). 감별 검사 : 정신건강 면담 및 PHQ-9/GAD-7 선별검사
```

## [P] 치료

```
- 정확한 하루 복용량과 다른 약·술 복용을 확인한 뒤, 금단 증상에 따라 1~2주마다 10~25%씩 점진 감량을 고려합니다. 급격히 중단하지 않습니다.
- 처방은 한 의료기관으로 일원화하고, 가족이 복용량과 감량 과정을 함께 확인하도록 권합니다. 주간 추가 복용과 약국 수면유도제는 중단합니다.
- 수면일지, 수면위생 교육과 불면 인지행동치료를 권합니다. 복용 중인 혈압약은 유지합니다.
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

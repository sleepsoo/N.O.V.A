## [A] 근거

```
#1. 제2형 당뇨병 (Type 2 diabetes mellitus)
- 근거 : 두세 달간 심한 피로와 갈증을 호소하고 물을 많이 마시며, 낮에 열 번 넘게 소변을 보고 밤에도 두세 번 깬다고 함 → 고혈당에 따른 다뇨·다갈 양상에 부합함. (시작 정보; 턴 12)
- 근거 : 3kg 체중 감소와 한 달간 글씨가 흐릿해지는 증상을 호소함 → 증상성 고혈당에서 나타날 수 있는 소견임. (턴 11, 15)
- 근거 : 혈당이 조금 높다는 말을 들었다고 함 → 고혈당 가능성을 뒷받침하나, 수치가 제시되지 않아 진단 기준 충족 여부는 확인되지 않음. (턴 2)
- 근거 : 진찰상 후경부와 액와에 흑색가시세포증이 있음 → 인슐린 저항성과 제2형 당뇨병 가능성을 뒷받침함. (턴 24)
- 근거 : 부친이 당뇨병으로 투석을 받았다고 함 → 제2형 당뇨병 가족력이 있음. (턴 3)
- 근거 : 배뇨통·혈뇨·옆구리 통증·발열을 부인함 → 요로감염은 현재 증상을 설명하는 원인으로 덜 지지됨. (턴 8, 9, 16)
```

## [A] 감별진단

```
r/o 요붕증 : 갈증, 많은 수분 섭취와 잦은 소변은 부합하지만, 혈당이 높다는 말을 들었고 흑색가시세포증·체중 감소·시야 흐림도 있어 당뇨병성 다뇨가 더 가능함 (시작 정보; 턴 2, 11, 15, 24). 감별 검사 : 혈청 나트륨 및 혈청·요 삼투압; 필요 시 수분 제한 검사
r/o 원발성 다음증 : 물을 많이 마시고 소변을 자주 보는 점은 부합하나, 혈당 상승을 들은 병력과 흑색가시세포증 및 체중 감소는 다른 대사 원인에 더 부합함 (시작 정보; 턴 2, 11, 24). 감별 검사 : 혈청 나트륨 및 혈청·요 삼투압
r/o 고칼슘혈증 : 갈증과 잦은 소변은 가능하지만, 현재 고칼슘혈증을 뒷받침하는 검사 결과나 별도의 관련 소견은 제시되지 않음 (시작 정보; 턴 12). 감별 검사 : 혈청 칼슘 및 알부민
r/o 요로감염 : 잦은 소변은 부합하지만 배뇨통, 혈뇨, 옆구리 통증과 발열을 부인하여 지지 근거가 약함 (시작 정보; 턴 8, 9, 12, 16). 감별 검사 : 요검사; 필요 시 소변 배양검사
```

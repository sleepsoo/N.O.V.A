## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 어제 저녁 배꼽 주변에서 시작한 통증이 밤 12시 이후 우하복부로 이동하고 그 부위에서 더 심해졌다는 호소는 충수염에 전형적인 통증 경과를 시사한다. (시작 정보; 턴 21)
- 근거 : 걷거나 기침할 때 통증이 악화되고 오심 및 구토를 호소해 복막 자극을 동반한 급성 복부 질환 가능성을 뒷받침한다. (턴 6, 8)
- 근거 : 맥버니점 압통, 우하복부 반발압통, 우측 요근 징후와 우하복부에 국한된 근성방어가 진찰상 확인되어 급성 충수염을 강하게 지지한다. (턴 24, 25, 26, 32)
- 근거 : 체온 37.9°C이며 열과 오한을 호소해 염증성 질환 가능성을 뒷받침한다. (턴 4, 37)
- 근거 : 배뇨통과 혈뇨가 없고 통증이 등·사타구니·고환으로 뻗치지 않으며 늑척추각 압통도 진찰상 없어 요관 결석 가능성은 낮아진다. (턴 14, 22, 27)
```

## [A] 감별진단

```
r/o 감염성 장염 : 오심·구토와 열·오한 호소는 장염에서도 가능하지만, 통증이 우하복부로 이동했고 해당 부위의 반발압통과 국한된 근성방어가 진찰상 확인되어 급성 충수염 쪽에 더 부합한다 (턴 4, 8, 21, 25, 32). 감별 검사 : 복부 CT, 혈액검사(CBC 및 CRP)
r/o 말단 회장염 : 우하복부 통증과 발열·오심 호소는 고려할 근거이나, 배꼽 주위에서 우하복부로 이동한 통증과 맥버니점 압통 및 반발압통이 진찰상 확인되어 충수염이 더 우선이다 (시작 정보; 턴 4, 8, 21, 24, 25). 감별 검사 : 복부 CT, 필요 시 대변 염증·감염 검사
r/o 요관 결석 : 우하복부 통증은 고려할 수 있으나 배뇨통·혈뇨 및 등·사타구니·고환으로 뻗치는 통증을 호소하지 않고, 늑척추각 압통도 진찰상 없다 (턴 14, 22, 27). 감별 검사 : 요검사, 복부·골반 CT
```

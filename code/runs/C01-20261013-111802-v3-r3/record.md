## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 7년 전부터 복용했고 반 알에서 서너 알로 늘었으며, 현재 졸피뎀 10mg을 밤에 5~6알(50~60mg), 낮에도 가끔 1알 복용한다고 호소함 → 장기간 복용과 용량 증가는 내성 및 사용 조절 문제를 시사함. (턴 6, 7, 13, 14)
- 근거 : 약 없이는 전혀 못 자고 약을 안 먹으면 손이 떨린다고 호소함 → 약물 의존 및 금단 관련 증상에 부합함. (턴 2, 8)
- 근거 : 감량·중단을 여러 차례 시도했으나 다시 복용했고 여러 진료기관에서 처방받았다고 함 → 감량 시도 실패와 반복적인 약물 추구를 뒷받침함. (턴 9, 10)
- 근거 : 낮 졸림·멍함과 복용 후 기억 공백을 호소하고, 진찰상 졸림과 반응 지연이 관찰됨 → 고용량 복용과 관련된 주간 진정 및 인지 부작용이 의심됨. (턴 4, 17, 24)
- 근거 : 기억력 저하를 호소하고 모친의 치매 병력이 있으나, MMSE-K는 28/30점이고 지남력은 3/3점임 → 기억 문제는 평가가 필요하나 현재 소견만으로 치매를 주진단으로 보기 어려움. (턴 5, 20, 25, 33)
- 근거 : 진찰상 급성 중독 징후, 보행 불균형, 구음장애는 관찰되지 않음 → 급성 중독이나 뚜렷한 신경학적 이상 소견은 없으나 사용장애 가능성을 배제하지 않음. (턴 24, 26, 27)
```

## [A] 감별진단

```
r/o 불면장애 : 수면 곤란과 약 없이는 잠들기 어렵다는 호소가 있으나, 장기간의 고용량 복용과 금단 유사 증상 및 감량 실패가 있어 약물 관련 수면 문제가 우선 고려됨 (시작 정보; 턴 2, 8, 9, 14). 감별 검사 : 약물 감량 과정 중 수면일지
r/o 불안 관련 불면 : 감량 시 잠을 못 잘까 걱정하고 진찰상 불안·초조가 관찰되나, 용량 증가와 복용 중단 시 손떨림 등 약물 관련 소견이 더 두드러짐 (턴 3, 7, 8, 9, 24). 감별 검사 : GAD-7 및 PHQ-9
r/o 폐쇄성 수면무호흡증 : 낮 졸림을 호소하여 감별 대상이나, 현재 제공된 병력만으로 수면무호흡 여부를 판단하기 어려움 (턴 4). 감별 검사 : 수면다원검사
```

## [P] 치료

```
- 현재 복용 중인 수면제를 오늘 갑자기 중단하지 않음(금단·경련 위험) — 처방 내역 확인 후 정신건강의학과 전문의 감독 아래 점진 감량 계획 수립
- 처방 기관 일원화, 임의 증량·추가 복용 금지, 술·약국 수면유도제 등 다른 진정성 물질 병용 금지
- 비약물 치료: 불면 인지행동치료(CBT-I), 수면위생 교육, 수면일지
- 기존 복용약은 유지하며 금기·약물 상호작용 확인, 금단 증상과 부작용 모니터링
- 다음 평가 전까지 현재 복용량을 넘기지 않도록 보호자가 약을 보관하고 복용을 확인(보유량·마지막 복용 시각 확인)
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 현재 외래 추적이 적절하며, 증상 악화나 경고 증상이 생기면 응급 평가·입원 고려
- 의식 명료, 급성 중독·심한 금단 징후 없어 외래 감량 — 단, 금단 경련·섬망 병력이 있거나 보호자 감독이 어려우면 입원 해독 고려
- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

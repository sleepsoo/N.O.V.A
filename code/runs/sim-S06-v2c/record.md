## [A] 근거

```
#1. 제2형 당뇨병 (Type 2 diabetes mellitus)
- 근거 : 두세 달간 피로와 갈증을 호소하고, 낮에 열 번 넘게 소변을 보고 밤에도 두세 번 깬다고 함 → 당뇨병의 전형적인 고혈당 증상 조합을 시사함. (시작 정보; 턴 1)
- 근거 : 물을 하루 2리터 넘게 마시고 최근 단 음료를 자주 마신다고 호소함 → 갈증이 지속되고 음료 섭취가 늘어난 양상임. (턴 2, 21)
- 근거 : 약 3kg 체중 감소를 호소함 → 다뇨·다갈과 함께 나타난 체중 감소는 증상성 고혈당 가능성을 높임. (시작 정보; 턴 3)
- 근거 : 2년 전 혈당이 조금 높다는 말을 들었고, 부모 모두 당뇨병 병력이 있음 → 기존 혈당 상승 병력과 강한 가족력이 위험인자임. (턴 4, 5)
- 근거 : 비만 체형이며, 안저 검사에서 미세동맥류·출혈·삼출물은 관찰되지 않음 → 비만은 제2형 당뇨병 위험을 뒷받침하며, 진찰상 당뇨망막병증 소견은 확인되지 않음. (턴 23, 24)
```

## [A] 감별진단

```
r/o 요붕증 : 다갈과 잦은 소변을 호소해 고려할 수 있으나, 과거 혈당 상승 및 부모의 당뇨병 병력이 있어 당뇨병에 의한 고혈당성 다뇨가 더 가능함 (시작 정보; 턴 4, 5). 감별 검사 : 혈당 및 HbA1c, 혈청·소변 삼투압
r/o 갑상샘기능항진증 : 피로와 체중 감소는 호소하지만, 손떨림과 심계항진은 부인하고 갑상샘 비대·결절·압통은 진찰상 없음 (시작 정보; 턴 3, 14, 28). 감별 검사 : TSH, 유리 T4
r/o 요로감염 : 잦은 소변을 호소하지만 배뇨통·발열·오한·혈뇨·옆구리 통증은 부인하고, 방광염 과거력도 없음 (시작 정보; 턴 12, 13, 18, 19, 20). 감별 검사 : 소변검사, 필요 시 소변배양
```

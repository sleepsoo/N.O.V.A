## [A] 근거

```
#1. 무조짐 편두통 (Migraine without aura)
- 근거 : 왼쪽 관자놀이와 눈 뒤의 욱신거리는 두통을 호소하고, 심할 때 강도는 8/10임 → 편두통에 합당한 편측성·박동성·중증 통증 양상임 (턴 6, 7)
- 근거 : 두통이 하루, 길면 이틀 지속되고 심할 때 메스꺼움과 구토를 호소함 → 편두통에서 흔한 지속시간 및 동반 위장 증상임 (턴 13, 18)
- 근거 : 밝은 빛에 눈부시고 통증이 심해지며 소리가 거슬린다고 호소함 → 빛·소리 과민이 동반됨 (턴 19)
- 근거 : 두통 전 번쩍임이나 시야 가림을 호소하지 않음 → 조짐 증상은 보고되지 않아 무조짐 편두통에 부합함 (턴 14)
- 근거 : 모친이 젊을 때부터 편두통이 있었음 → 편두통 가족력이 있음 (턴 17)
- 근거 : 진찰상 의식·지남력이 명료하고 근력·감각·구음·소뇌 기능 및 보행에 이상이 없으며, 유두부종과 경부강직도 없음 → 진찰에서 뚜렷한 국소 신경학적 이상이나 수막자극 징후가 확인되지 않음 (턴 24, 28, 29, 30, 31, 32, 33, 34)
```

## [A] 감별진단

```
r/o 월경 관련 편두통 : 생리 시작 하루 이틀 전에 두통이 온다고 호소하여 월경과 연관된 편두통 가능성이 있음. 다만 주진단은 편두통 양상에 근거하며, 반복 주기별 발생 양상은 추가 확인이 필요함 (턴 5, 6, 7, 13, 19). 감별 검사 : 월경 주기와 두통 발생일을 두통 일지에 기록
r/o 긴장형 두통 : 수년 전부터 간헐적으로 두통이 있었다고 호소하지만, 편측성 박동통과 심한 통증, 메스꺼움·구토 및 빛·소리 과민은 긴장형 두통보다 편두통을 더 지지함 (시작 정보; 턴 6, 7, 13, 19). 감별 검사 : 두통 양상과 동반 증상을 포함한 두통 일지
r/o 약물과용 두통 : 최근 두통 빈도가 늘었으나 한 달 4~5회 두통과 한 달 5~6회 이부프로펜 복용을 호소하여, 현재 확인된 빈도는 약물과용 두통을 뒷받침하지 않음 (턴 2, 11, 16). 감별 검사 : 두통 일수와 진통제 복용일을 월별로 기록
r/o 이차성 두통 : 최근 석 달간 두통 빈도 증가를 호소해 고려할 수 있으나, 수년간 간헐적 두통 경과와 진찰상 유두부종·국소 신경학적 이상·경부강직이 확인되지 않은 점은 가능성을 낮춤 (시작 정보; 턴 2, 24, 29, 30, 31, 33). 감별 검사 : 두통 양상이 지속적으로 진행하거나 경고 소견이 확인되면 뇌 MRI 고려
```

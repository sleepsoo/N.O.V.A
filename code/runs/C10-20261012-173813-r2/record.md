```

- 종합 혈액 검사 (CBC, 전해질, 간 기능) : 부작용 감시(항염소제)
```

```
- 항갑상선제 (메티마졸) :을 시작해 서서히 토양적으로 증상 완화 후 방사성 요오드/수술 전 2~4주간 유지, 약용시 혈청 항체 확인

- 부작용 관찰: 간 기능 검사, 혈소판 감소 모니터링, 급격한 중단 금지
- 갑상선 수술·핵분열치료 전 요오드(보충제) 금지
```

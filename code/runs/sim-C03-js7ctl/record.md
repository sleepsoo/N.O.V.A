## [A] 근거

```
#1. 가족성 저신장 (Familial short stature)
- 근거 : 신장 105cm, 체중 16.5kg, 성장도표에서 신장 3백분위수 이하, 체중 3~10백분위수, 성장속도 5cm/년(정상 하한) → 가족성 저신장 가능성 높음 (턴 19)
- 근거 : 부모 성장 지연 보고(아빠) → 가족성 성장 패턴에 부합함 (턴 4)
- 근거 : 1년 전 100cm → 현재 105cm, 5cm 성장 → 정상 성장속도 적절함, 성장호르몬 결핍 가능성 낮음 (시작 정보)
- 근거 : 안면 기형 및 귀 위치 이상 없음, 갑상선 촉진 결과 비대/결절/압통 없음 → 선천적 기형 및 갑상선 비대 배제함 (턴 22, 23)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍 : 신장이 3백분위수 이하이지만 성장속도 5cm/년(정상 하한)으로 GH 결핍의 확증적 증거는 부족함; 그러나 단기 성장 지연 가능성 존재 (시작 정보; 턴 19). 감별 검사 : GH 절단 자극 검사 (Oral Glucose, Insulin Tolerance Test) 및 TSH, FT4 검사
r/o 무증상 갑상선 기능저하증 : 갑상선 기능 이상 증상 부재하지만 정상 성장 달성에도 불구하고 TSH 상승 가능성 존재, 무증상 시 LH 시 진단 필요 (턴 23). 감별 검사 : TSH, 자유형 T4
```

- 좌측 손 X‑ray(골연령) : 골연령이 실제 성장량과 일치하는지 확인하여 성장지연 여부를 판단

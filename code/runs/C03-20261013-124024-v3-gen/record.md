## [A] 근거

```
#1. 체질성 성장지연 (Constitutional delay of growth and puberty)
- 근거 : 현재 신장은 105cm로 3백분위수 미만이며, 최근 1년간 약 5cm 자랐고 성장속도는 정상 하한으로 확인됨 → 저신장이지만 성장속도는 보존되어 있음. (시작 정보; 턴 24)
- 근거 : 부모 신장은 아버지 178cm, 어머니 165cm이고 중간부모키는 178cm로 확인됨 → 가족성 저신장을 뒷받침하지 않음. (턴 4, 24)
- 근거 : 아버지가 고등학교 때 많이 자랐다고 함 → 가족 내 늦은 성장 시기가 체질성 성장지연 가능성을 뒷받침함. (턴 5)
- 근거 : 상·하절 비율 정상, 양팔간격 불균형 및 안면 기형 소견 없음 → 비례 이상이나 뚜렷한 기형 소견은 확인되지 않음. (턴 25, 26)
- 근거 : 세 끼와 간식을 잘 먹고, 변비·추위 민감·구토가 없으며 갑상선 비대·결절과 피부 건조도 없음 → 영양 부족이나 갑상선기능저하증을 시사하는 병력·진찰 소견은 뚜렷하지 않음. (턴 10, 12, 21, 27, 28)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍 : 신장이 3백분위수 미만이고 보호자는 최근 성장이 더딘 것 같다고 호소함. 다만 성장속도는 정상 하한인 5cm/년으로 확인됨 (시작 정보; 턴 24). 감별 검사 : IGF-1 및 IGFBP-3 측정, 필요 시 성장호르몬 자극검사
r/o 가족성 저신장 : 신장은 3백분위수 미만이나 부모 신장은 각각 178cm와 165cm이며 중간부모키는 178cm임 (턴 4, 24). 감별 검사 : 골연령 X선 검사
r/o 갑상선기능저하증 : 저신장의 감별 진단이나 변비와 추위 민감이 없고 갑상선 비대·결절 및 피부 건조도 진찰상 없음 (턴 12, 27, 28). 감별 검사 : TSH 및 유리 T4 측정
r/o 영양 부족 : 체중은 3~10백분위수이고 최근 1년간 1.5kg 증가했으나, 세 끼와 간식을 잘 먹는다고 함 (시작 정보; 턴 10, 24). 감별 검사 : 식이 섭취 평가 및 CBC·혈청 화학검사
```

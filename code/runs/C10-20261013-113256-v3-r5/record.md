## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 다이어트나 운동 없이 3개월간 7kg 감소했고, 식욕은 오히려 증가했다고 호소함 → 갑상샘기능항진증에 합당한 비의도적 체중 감소 양상 (시작 정보; 턴 8)
- 근거 : 두근거림, 더위 민감, 발한, 손떨림을 호소하며 진찰상 규칙적 빈맥, 온난하고 습한 손바닥, 자세성 떨림이 있음 → 갑상샘호르몬 과다 상태를 뒷받침함 (턴 4, 5, 9, 24, 25, 26)
- 근거 : 진찰상 양측 대칭성 미만성 갑상샘 비대와 갑상샘 잡음이 있음 → 혈류가 증가한 미만성 갑상샘 질환으로 그레이브스병을 지지함 (턴 27, 35)
- 근거 : 진찰상 양측 안구 돌출, 안검 지연, 안검 후퇴가 있음 → 그레이브스병에 특이적으로 동반될 수 있는 갑상샘 안병증 소견 (턴 28)
- 근거 : 모친이 갑상샘저하증 약을 복용한다고 함 → 가족 내 갑상샘 질환 병력이 있으나 그 자체로 그레이브스병을 확진하지는 않음 (턴 17)
- 근거 : 갈증은 늘지 않았고 소변 횟수도 평소와 같다고 호소함; 발열이 없고 갑상샘 압통도 없음 → 당뇨병 및 발열·압통을 동반하는 갑상샘염을 상대적으로 덜 지지함 (턴 12, 20, 22, 35)
```

## [A] 감별진단

```
r/o 독성 결절성 갑상샘종 : 체중 감소와 빈맥 등 갑상샘기능항진 양상은 고려 근거이나, 진찰상 결절 없이 양측 대칭성 미만성 비대가 확인되어 덜 지지됨 (시작 정보; 턴 24, 35). 감별 검사 : 갑상샘 초음파 또는 갑상샘 스캔
r/o 갑상샘염에 의한 갑상샘중독증 : 체중 감소와 빈맥은 고려 근거이나, 발열과 갑상샘 압통이 없고 갑상샘 잡음 및 안병증 소견이 있어 그레이브스병보다 덜 지지됨 (시작 정보; 턴 22, 24, 27, 28, 35). 감별 검사 : TSH, 유리 T4 및 갑상샘 섭취율 검사
r/o 당뇨병 : 비의도적 체중 감소는 고려 근거이나, 갈증과 소변 횟수가 늘지 않았고 갑상샘기능항진을 시사하는 증상 및 진찰 소견이 뚜렷함 (시작 정보; 턴 4, 12, 20, 27, 28). 감별 검사 : 공복 혈당 또는 당화혈색소
```

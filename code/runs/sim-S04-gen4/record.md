## [A] 근거

```
#1. 만성폐쇄성폐질환의 급성 악화 (Acute exacerbation of chronic obstructive pulmonary disease)
- 근거 : 수년간 이어진 숨참이 최근 3일간 악화되고, 기침·가래 및 가벼운 활동에도 숨찬 증상이 동반되어 만성 기도질환의 급성 악화를 시사함. (시작 정보; 턴 2)
- 근거 : 하루 한 갑씩 거의 50년간 흡연한 병력은 만성폐쇄성폐질환의 중요한 위험인자임. (턴 16)
- 근거 : 진찰상 호흡음 감소, 호기 연장과 미만성 호기성 천명음, 술통형 흉곽 및 양측 과공명음이 있어 폐쇄성 기류 제한 및 폐기종성 변화에 부합함. (턴 21, 22, 23)
- 근거 : 실내 공기에서 SpO2 89%이고 진찰상 입술 오므린 호흡과 경도의 보조호흡근 사용이 확인되어 현재 호흡 악화가 임상적으로 유의함. (턴 19, 20, 22)
- 근거 : 누렇고 끈적한 가래, 주관적인 열감과 오한은 감염이 급성 악화를 촉발했을 가능성을 뒷받침함. (턴 4, 5)
- 근거 : 진찰상 수포음·S3·경정맥 팽창·하지 함요부종이 없고, 환자도 다리 부종을 호소하지 않아 급성 심부전 가능성은 상대적으로 낮음. (턴 7, 21, 25, 26, 27)
```

## [A] 감별진단

```
r/o 폐렴 : 기침과 가래 악화, 누런 가래, 열감 및 오한은 폐렴에서도 가능하지만, 진찰상 수포음은 없음 (시작 정보; 턴 4, 5, 21). 감별 검사 : 흉부 X선, 혈액검사
r/o 급성 심부전 : 누우면 숨이 더 찬 증상은 고려 요인이지만, 진찰상 수포음·S3·경정맥 팽창·하지 부종이 없고 환자도 다리 부종을 호소하지 않음 (턴 6, 7, 21, 25, 26, 27). 감별 검사 : BNP 또는 NT-proBNP, 심초음파
r/o 폐색전증 : 급격한 숨참과 낮은 산소포화도, 빈맥은 고려 요인이지만, 진찰상 종아리 압통이나 좌우 둘레 차이가 없음 (시작 정보; 턴 19, 25, 28). 감별 검사 : 임상 위험도 평가 후 D-dimer 또는 폐동맥 CT 혈관조영술
r/o 급성 기관지염 : 최근 시작된 기침과 가래, 열감은 급성 기관지염과 맞을 수 있으나, 수년간의 숨참과 흡연력 및 폐쇄성 진찰 소견은 기저 만성폐쇄성폐질환의 급성 악화를 더 지지함 (시작 정보; 턴 16, 21, 22, 23). 감별 검사 : 흉부 X선으로 폐렴 배제, 안정 후 폐활량측정
```

## [A] 근거

```
#1. 졸피뎀 의존성 및 내성 불면증 (Zolpidem dependence with tolerance insomnia)
- 근거 : 17번에서 현재 Zolpidem과 암로디핀을 복용 중임을 확인(턴 17)
- 5번에서 7년간 복용 시작을 명시하며, 과거 의존의 길이를 보여줌(턴 5)
- 6~8번에서 매일 5~6알을 복용하고 가끔 7알까지 늘려 사용 중인 사실(턴 6,8,7)
- 24번에서 약을 끊을 때 가슴 두근거림, 27번에서 약이 떨어질까 두려워 불안해 함(턴 24,27)
- 31번에서 수면제 처방을 요청하며 불면증 증상이 약 물질 의존으로 인해 발생함을 시사(턴 31)
```

## [A] 감별진단

```
r/o 일반성 불안장애 : 현재 불면증이 Zolpidem 의존/내성으로 심화되고 있으므로 불안이 주원인으로 보이지 않음. 항불안제 적절 사용과 CBT 검토.
r/o 원발성 불면증 : 약물에 의존적인 불면증이므로 단독 원인으로 보기는 어려움. 수면관련 행동요인 평가.
r/o 수면 무호흡증 : 코막힘, 호흡곤란, 폐소음 부정으로 수면 무호흡 가능성 낮음. 수면다원검사로 검사.
r/o 우울증 : 인지검사 결과 정상, 기분 징후 없음; 불면증이 약물 의존으로 설명될 가능성 높음. Beck Depression Inventory 등으로 간단 평가.
```

## [A] 근거

```
#1. 요추 추간판 탈출증에 의한 좌측 S1 신경근병증 (Left S1 radiculopathy due to lumbar disc herniation)
- 근거 : 열흘 전 이삿짐을 옮기다 허리를 삔 뒤 허리 통증이 생겼고, 처음에는 허리만 뻐근하다가 사흘째부터 다리 통증이 시작됨 → 추간판성 신경근 자극을 유발할 수 있는 급성 발병 경과. (시작 정보; 턴 10)
- 근거 : 좌측 둔부에서 후대퇴·종아리·외측발까지 전기 오듯 찌릿하게 뻗치는 통증을 호소함 → 좌측 요천추 신경근 분포의 방사통에 합당함. (턴 2)
- 근거 : 진찰상 좌측 하지직거상 검사에서 40도에 방사통이 유발되고 우측은 80도에서 음성임 → 좌측 신경근 자극 소견을 지지함. (턴 24)
- 근거 : 진찰상 좌측 발 외측·새끼발가락의 감각이 저하되고, 아킬레스건 반사는 우측 2+에 비해 좌측 1+임 → S1 신경근 침범을 뒷받침함. (턴 26, 27)
- 근거 : 이삿짐 운반 중 허리를 삔 뒤 증상이 시작되었고 부친의 허리 디스크 수술력이 있음 → 추간판 질환을 고려할 임상적 맥락이나, 가족력만으로 진단을 확정할 수는 없음. (시작 정보; 턴 11)
- 근거 : 소변·대변 문제와 회음부 감각저하를 호소하지 않고, 발열·오한·체중 감소도 호소하지 않으며 진찰상 극돌기 타진 압통이 없음 → 마미증후군, 감염성·종양성 질환 및 압박골절 가능성을 낮추는 소견. (턴 6, 7, 8, 28)
```

## [A] 감별진단

```
r/o 급성 요추 염좌·근육 손상 : 이삿짐 운반 중 허리를 삔 뒤 허리 통증이 먼저 시작된 점은 고려할 만하지만, 좌측 하지직거상 검사 양성 및 S1 감각·반사 이상은 단순 염좌만으로 설명하기 어려움 (시작 정보; 턴 10, 24, 26, 27). 감별 검사 : 요추 MRI
r/o 요추 퇴행성 질환 : 요추 퇴행성 변화에 의한 신경근 증상도 고려할 수 있으나, 증상이 열흘 전 급성으로 시작했고 다리 통증은 사흘째부터 나타났음 (시작 정보; 턴 10). 감별 검사 : 요추 MRI
r/o 이상근 증후군 : 둔부에서 다리로 뻗치는 통증은 고려 근거이나, 요통이 먼저 시작되었고 진찰상 좌측 S1 피부분절 감각저하와 아킬레스건 반사 저하가 있어 척추 신경근 병변이 더 잘 맞음 (턴 2, 10, 26, 27). 감별 검사 : 요추 MRI 및 이상근 유발 검사
r/o 척추 압박골절 : 무거운 짐을 옮긴 뒤 통증이 시작된 점은 고려할 수 있으나, 진찰상 극돌기 타진 압통이 없고 S1 분포의 방사통·신경학적 소견이 있어 가능성이 낮음 (시작 정보; 턴 2, 26, 28). 감별 검사 : 요추 단순 X선 또는 CT
```

## [P] 추가 검사

```
- 요추 자기공명영상(MRI) : 디스크 탈출 위치와 신경 압박 정도를 확인하고 치료 방향을 정합니다.
- 요추 단순 방사선촬영 : 척추 정렬과 뼈의 이상 여부를 확인합니다.
- 혈액검사(신장기능) : 소염진통제를 계속 복용할 때 신장기능을 확인합니다.
- 단순 방사선(X-ray) : 진료 중 설명한 검사
```

## [P] 치료

```
- MRI 결과와 증상을 보고 약물치료와 활동 조절을 우선 고려합니다.
- 통증이 지속되면 재활치료나 신경 주사 치료를 검토하고, 심한 근력 저하가 진행하면 수술 평가를 합니다.
```

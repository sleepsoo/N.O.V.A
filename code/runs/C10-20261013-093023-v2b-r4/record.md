## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves disease causing hyperthyroidism)
- 근거 : 최근 3개월간 비의도적으로 약 7kg 감소(약 56kg에서 49kg, 약 12.5% 감소)했고 BMI는 18.2 → 임상적으로 의미 있는 체중 감소이다. (시작 정보)
- 근거 : 체중 감소에도 식욕은 증가했고, 더위를 더 타며 가만히 있을 때 심계항진과 손떨림을 호소한다 → 갑상샘호르몬 과다 상태를 시사한다. (턴 1, 2, 3, 4)
- 근거 : 진찰상 갑상샘이 양측 대칭으로 미만성 비대하고 표면이 매끈하며 결절과 압통은 없고, 양측 안검 징후와 안구 돌출이 관찰된다 → 그레이브스병을 강하게 지지한다. (턴 25, 26)
- 근거 : 진찰상 갑상샘 잡음, 빠르고 강한 맥박, 온난하고 습윤한 손바닥, 자세성 떨림이 있다 → 갑상샘 기능항진에 합당하다. (턴 27, 28, 29, 30)
- 근거 : 갈증 증가는 호소하지 않고 복부 압통이나 종괴, 간·비장 비대는 진찰상 확인되지 않는다 → 당뇨병이나 복부 질환을 뒷받침하는 소견은 제한적이나, 이들 질환을 배제하지는 않는다. (턴 6, 33)
```

## [A] 감별진단

```
r/o 독성 결절성 갑상샘종 : 체중 감소, 식욕 증가와 심계항진은 갑상샘중독증에 합당하지만, 진찰상 결절 없는 대칭성 미만성 비대와 안구 돌출은 덜 부합한다 (시작 정보; 턴 1, 3, 25, 26). 감별 검사 : 갑상샘 초음파 및 방사성요오드 섭취율 검사
r/o 갑상샘염에 의한 일과성 갑상샘중독증 : 체중 감소와 심계항진은 고려 근거이나, 갑상샘 압통이 없고 갑상샘 잡음과 안구 징후가 관찰되어 그레이브스병보다 덜 가능하다 (시작 정보; 턴 3, 25, 26, 30). 감별 검사 : TSH·유리 T4와 적혈구침강속도 또는 C-반응단백
r/o 당뇨병 : 비의도적 체중 감소와 식욕 증가는 고려할 근거지만, 갈증 증가는 호소하지 않고 진찰상 갑상샘항진을 시사하는 소견이 뚜렷하다 (시작 정보; 턴 1, 6, 25, 27, 30). 감별 검사 : 공복혈당 및 당화혈색소
r/o 악성 종양 : 비의도적 체중 감소는 고려할 근거이나, 미만성 갑상샘 비대와 안구 징후 등 갑상샘항진에 부합하는 소견이 더 두드러진다. 진찰상 복부 종괴는 촉지되지 않았다 (시작 정보; 턴 25, 26, 33). 감별 검사 : 전혈구검사와 종합대사검사, 병력·진찰에 따른 표적 검사
```

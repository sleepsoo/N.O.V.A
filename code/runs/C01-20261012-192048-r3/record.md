## [A] 근거

```
#1. 졸피뎀 사용장애 (Zolpidem use disorder)
- 근거 : 7년 전부터 수면장애 지속, 차츰 악화하며 지속적 졸피뎀 복용, 일주일 섭취량 5-6 알로 증가 (턴 2, 5, 7) → 약물 의존성의 발전을 시사
- 근거 : 약물 중단 시 불안·손 떨림, 잠 못 자는 증상 발생 (턴 8, 27) → 불이행 시 신경학적 반응과 수면 무산을 동시에 동반하는 사용장애 특징
- 근거 : 하루 5-6 알 복용 중 ‘제법’ 가짐, 복용량이 점진적으로 증가 (턴 5, 6, 7) → 졸피뎀 사용량과 의존성 악화 관계 명시
- 근거 : 진찰 결과 심음·폐음 정상, 혈압, 맥박, 호흡, 체온 정상, 방울떨림 없음 (턴 32-40) → 물리적 약물 영향 최소화 확인
- 근거 : 고혈압 병력 있음에도 불구하고 수면 문제는 약물에 의존적임이 확인 (턴 13, 14) → 원인 규정에 부합
```

## [A] 감별진단

```
r/o Chronic primary insomnia : 수면이 약물 복용에 의존적이며 지속적 졸피뎀 사용이 가장 우선인 원인으로 보이므로 가능성 낮음 + 수면 다이어리 및 PSG 검토
r/o Generalized anxiety disorder : 불안 증상은 약물 중단 시에만 나타나고 전반적 불안이 부족히 검출되어 가능성 낮음 + GAD 검증 스케일(HAM-A, GAD-7) 점검
r/o Other sedative-hypnotic dependence : 졸피뎀 외 다른 수면제는 없으나 의존성은 여전히 가능하므로, 의존성 평가 기록 필요 + DSM-5 의존성 스케일 적용
```

## [P] 추가 검사

```
- 혈액검사(CBC, CMP, 혈당, 콜레스테롤, TSH, 간기능) : 기초 대사 이상·갑상선 기능 검사의 필요성
- 정맥성 맥박검사·EKG : 심혈관 합병증 추적방지(고혈압 외)
- 수면다원수면검사(PSG) : 수면 무호흡·수면양상 파악을 통한 감별진단
- 정신건강평가(예: GAD‑7, PHQ‑9) : 불안·우울증 징후의 존재 여부 확인
- 심정지 및 신경학적 검진(경도 신경염/두통 평가) : 추가 원인 배제
```

## [P] 치료

```
- 졸피뎀 의존형 천천히 전량 감량(Tapering) 계획 수립(전문의 감독 아래)
- 비약물 치료: 인지행동치료(CBT‑I), 수면 위생·규칙적 생활 패턴 장려
- 필요 시 항우울제(SSRIs 등) 고려(불안·우울 증상 완화) ± 메탈로핀 · 벤조디아제핀 반대
- 안전주의: 급격한 중단 금지, 금기사항 확인(뇌하수체 질환 등) 및 부작용 모니터링
```

## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 수면곤란과 졸피뎀 복용이 각각 7년 전부터 이어졌고, 현재 밤에 5~6알 및 가끔 낮에도 복용한다고 호소하며 복용량이 반 알에서 서너 알로 증가했다고 함 → 지속적이고 증량된 사용 양상. (턴 1, 3, 4, 6)
- 근거 : 복용하지 않으면 잠이 오지 않고 불안하며, 감량·중단을 여러 번 시도했으나 실패했다고 호소함 → 미복용 증상과 조절 시도 실패가 사용장애를 지지. (턴 7, 9)
- 근거 : 여러 내과·신경과·정신과에서 처방받고 약국 수면유도제를 가끔 병용하며, 복용 후 기억이 나지 않을 때가 있고 가족도 걱정한다고 함 → 처방 중복·병용 및 사용 관련 위해 우려. (턴 10, 11, 12, 13)
- 근거 : 진찰상 졸림과 반응 지연, 불안·초조가 관찰되나 급성 중독 징후는 없음 → 주간 약물 관련 영향 가능성이 있으나 진찰 당시 급성 중독 소견은 확인되지 않음. (턴 25)
- 근거 : 많이 가라앉은 기분, 자살 사고, 흥미 저하를 부인함 → 우울 증상에 따른 불면을 주원인으로 보는 근거는 상대적으로 약함. (턴 14, 15, 21)
```

## [A] 감별진단

```
r/o 만성 불면장애 : 7년간 수면곤란을 호소해 고려할 수 있으나, 현재의 증량 사용·미복용 불안 및 반복된 감량 실패는 졸피뎀 사용장애가 임상상을 더 잘 설명함 (시작 정보; 턴 1, 4, 7, 9). 감별 검사 : 수면일지 및 불면 심각도 평가
r/o 불안 관련 불면 : 진찰상 불안한 기분과 초조가 있으나, 미복용 시 불안하다는 호소도 있어 약물 관련 증상일 가능성이 있으며 우울감·자살 사고·흥미 저하는 부인함 (턴 7, 14, 15, 21, 30). 감별 검사 : 불안 증상에 대한 구조화 면담 또는 GAD-7
r/o 폐쇄성 수면무호흡증 : 수면곤란 호소로 감별에 포함할 수 있으나 코골이·목격된 무호흡 등 관련 병력은 제시되지 않아 현재 지지 근거가 제한적임 (시작 정보). 감별 검사 : 수면무호흡 병력 확인 및 필요 시 수면다원검사
```

## [P] 추가 검사

```
- 처방 내역 조회(DUR) : 여러 기관에서 받은 수면제의 종류와 총 복용량을 확인합니다.
- 소변 약물 선별검사 : 다른 진정제 병용 여부를 확인합니다. 졸피뎀은 검사에 잡히지 않을 수 있습니다.
- 혈액검사(CBC, 간·신장기능, 전해질, 혈당, 갑상선기능) : 기저 건강 상태와 불면·불안의 다른 원인, 감량 계획을 확인합니다.
- 불안·우울 증상 평가 : 약물과 별개로 지속되는 불안이나 우울이 있는지 확인합니다.
```

## [P] 치료

```
- 급중단 금지 — 당일 처방 내역(DUR)·실제 총량 확인 후 금단을 막는 최소 용량으로 1~2주분만 단기 처방(처방 일원화, 보호자 보관·복용 확인, 증량·추가·조기 재처방 없음), 이후 1~2주마다 10~25%씩 감량
- 급격한 중단 금지 — 실제 총량 확인 후 1~2주마다 10~25%씩 점진 감량(금단에 따라 조절)
- 처방 일원화(본원 한 곳), 추가·주간 복용 금지, 약국 수면유도제 중단
- 수면위생·수면일지·CBT-I, 정신건강의학과(중독·수면)와 협진
- 기존 복용약(예: 혈압약)은 유지
- 수면일지, 수면위생 교육 및 불면 인지행동치료를 권하고 정신건강의학과와 협진을 고려합니다.
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

## [P] 처치 결정

```
- 활력징후 대체로 안정 : BP 128/78 mmHg, PR 76 회/분, RR 18 회/분, BT 36.6°C → 급성 위험 징후 없어 입원 불필요, 외래 추적
- 의식 명료, 급성 중독·심한 금단 징후 없어 외래 감량 — 단, 금단 경련·섬망 병력이 있거나 보호자 감독이 어려우면 입원 해독 고려
- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

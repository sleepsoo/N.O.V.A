## [A] 근거

```
#1. 급성 충수염 (Acute appendicitis)
- 근거 : 환자는 24세 남성으로 배꼽 주변에 부풀음이 있었으나 오늘 아침부터 우하복부로 이동한 통증을 호소하며, 통증 강도는 7/10이다. 걷기와 기침 시 통증이 악화되고, 메스꺼움과 구토를 동반, 37.9°C 발열이 있다. (시작 정보; 턴 1, 2, 3, 5, 11)
- 근거 : 진찰에서 우하복부 압통, 근성방어, 맥버니지점 압통, 반발통이 일관되게 확인되었으며 소화기 소음이 감소하였다. (턴 25, 26, 27, 29)
```

## [A] 감별진단

```
r/o 소장 장폐색 : 구토와 복부 팽만이 부족하고 설사·변비가 없으며( F13), 진찰에서 우하복부 국한성 통증과 반발통이 임상적으로 장폐색과는 부합하지 않는다 (턴 5, 6, 26, 27). 감별 검사 : 복부 X‑ray or CT abdomen to rule out obstruction
r/o 크론병 : 크론은 보통 지속적인 설사, 체중 감소, 복부 팽만을 동반하지만, 본 환자는 설사·변비가 없고( F13), 복부 팽만이 없으며( F15) 염증성 장 질환의 전형적 징후가 없으므로 가능성이 낮다 (턴 6, 7, 26, 27). 감별 검사 : CRP, ESR, fecal calprotectin or intestinal MRI/CT for Crohn’s disease
```

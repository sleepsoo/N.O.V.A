## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 7년간 정기적 스틸녹스·졸피뎀 복용 및 금단 증상(뒤척임, 불안) → 의존성 징후 (시작 정보; 턴 2, 3, 4, 5, 6)
- 근거 : 정상 활력(128/78 mmHg, 76bpm) 및 정서적 증상 있음 → 수면 무호흡증 가능성 낮음 (턴 14, 23, 25)
- 근거 : 흉부 청진 정상, 폐음 무경과 → 중증 수면 무호흡증 배제 (턴 29)
- 근거 : 불안 및 초조 증상 관찰, 의식·지남력 명료 → 불안장애 가능성 존재 (턴 21, 27)
```

## [P] 치료

```
- 급격한 중단 금지 — 전문의 감독 아래 점진 감량 계획 수립(처방 내역·실제 복용 총량 확인 후 금단 증상에 맞춰 조절)
- 처방 일원화(한 기관), 임의 추가 복용·약국 수면유도제 병용 피하기, 보호자 복용 확인
- 비약물 치료: 불면 인지행동치료(CBT-I)·수면위생·수면일지
- 금기·약물 상호작용(음주·타 진정제 병용 포함) 확인 및 부작용(낮 졸림·기억 저하·낙상) 모니터링
- 정신건강의학과(중독·수면) 협진
- 기존 복용약(예: 혈압약)은 유지
- 전문의 평가 전까지 임의 증량·급감량 없이 정해진 시간에만 복용하고, 금단 증상(불안·떨림·발한·경련 전조)이 나타나면 재진 전이라도 조기 연락
```

## [P] 처치 결정

```
- 활력징후 대체로 안정
- 금단 경련·섬망 병력 없음, 마지막 복용 어젯밤에도 자기 전에 네 알을 먹고 새벽에 깨서 두 알을 더 먹었다 → 확인된 활력징후·진찰 소견상 의식 명료, 급성 중독·심한 금단 징후 없어 현재 외래 추적이 적절하며 금단 경련·섬망 병력, 금단 증상 악화, 보호자 감독이 어려운 경우 입원 해독 고려
- 졸림·반응 지연 있어 당일 운전·위험 작업 회피
- 가족이 감량 과정을 지지·복용 확인하도록 권유
```

## [A] 근거

```
#1. 급성 충수염 (Acute Appendicitis)
- 근거 : 우하복부 통증이 지속되며 7/10 강도와 앓는 편제증이 보고되었다 (턴 1, 3)
- 근거 : 걷기·기침 시 통증이 악화되고, 우하복부 반발통, McBurney점 압통이 양성이었다 (턴 2, 29, 30, 32)
- 근거 : 복부 촉진 시 근성방어가 일시적이지만 강직이 없었고, 장음이 감소했다가 고창음이 나타났다 (턴 28, 29, 33)
- 근거 : 정상 범위 혈압·맥박·체온이지만 경미한 발열(37.9℃)이 관찰되었다 (턴 23)
```

## [A] 감별진단

```
r/o 원장염 : 우하복부 통증과 통증 증강이 관찰되지만, 설사(F10)와 혈변(F11) 없음 → 가능성 ↓ (턴 1, 6, 7). 감별 검사 : CBC, CRP 기본
r/o 발장염 : 통증 위치가 우하복부지만, 설사(F10), 혈변(F11) 부재 → 가능성 낮음 (턴 1, 6, 7). 감별 검사 : 울트라소닉 혹은 CT 기본
r/o 박테리아성 복막염 : 통증이 급성·위치지정이 우하복부이며 McBurney점 압통이 양성 → 가능성 중간 (턴 1, 29, 30, 32). 감별 검사 : 복부 CT, 혈액검사
```

## [P] 추가 검사

```
- 혈액 : CBC, ESR/CRP, 전해질, AST/ALT, BUN/Cr, 공복혈당/HbA1c : 검사 목적

```


## [P] 추적

```
- 재진 : 응급 평가 후 결과에 따라 외래 추적
- 모니터링 : 8~12시간 – 체온, 통증
- 의뢰 기준 : 체온 38.5°이상, 통증 급격 상승, 삼킴 곤란
- 즉시 내원 : 고열·복통 악화·구토·두통·시야 흐림
```

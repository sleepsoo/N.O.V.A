## [A] 감별진단

```

r/o 불안장애/피로증후군 : 지지 E2, E4 / 반대 F6, F5 → 가능성 중간 (턴 24, 26). 감별 검사 : 심박수 기록
```

## [P] 추가 검사

```
- 혈액 : FT4, T3, TSH 진단 검사 : 갑상샘호르몬 과다 여부 확인
- LH/FSH, Testosterone : 다낭성 난소 증후군 감별
- 대장 조영술 : 만성 위장관 질환 감별
- 심박수 기록 : 불안장애/피로증후군 감별
```

## [P] 치료

```
- 금기(천식·서맥·심부전) 확인 후 베타차단제로 두근거림·떨림 조절
- TFT·TRAb 확인 후 항갑상샘제 시작 여부를 내분비내과 전문의와 상의해 결정, 무과립구증·간독성 교육
- 눈 건조·자극감이 있으면 인공눈물
- 재발·부작용 시 방사성요오드·수술을 내분비내과와 상의
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 102회/분), 확인된 진찰 소견상 갑상샘중독발증 징후 없어 현재 외래 추적이 적절하며 심한 빈맥·발열·의식 변화 시 입원 고려
- 천식·심장병 없음 확인(턴 37) → 베타차단제 금기 없음
- 내분비내과 외래 연계
```

## [P] 추적

```
- 재진 : 1~2주 뒤 - TFT·CBC·LFT·체중·증상 확인
- 모니터링 : 4~6주 간격 - 항갑상샘제 복용 시 TFT·CBC·LFT
- 의뢰 기준 : 안병증 악화(시력 저하·복시)는 안과, 확진·약물 부작용·조절 실패는 내분비내과
- 즉시 내원 : 두근거림·떨림 악화·호흡곤란·시력 저하·복시
```

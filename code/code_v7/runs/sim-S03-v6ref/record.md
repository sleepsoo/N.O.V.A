## [A] 근거

```
#1. 급성중이염 (Acute Otitis Media)
- 근거 : 정상 체온 38.6℃와 함께 오른쪽 귀 발적·팽윤·광반사 소실이 관찰되어 급성 중이염으로 진단됩니다. (턴 1, 25)
- 근거 : 열 최고 38°C 호소 (턴 1)
- 근거 : 열 시작 어제 낮 호소 (턴 2)
- 근거 : 해열제 반응 2시간 호소 (턴 3)
- 근거 : 진찰상 전반적 외관 시진 급성 병색 경도, 보챔(+), 처짐(-), 탈수 징후(-) (턴 23)
- 근거 : 진찰상 고막 시진 우측 고막 발적(+), 팽윤(+), 광반사 소실(+), 이루(-) / 좌 (턴 25)
```

## [A] 감별진단

```
r/o 수막염 : 환자의 고열과 견인된 보챔이 수막염을 의심하게 하지만 경부강직, 케르니그, 브루진스키 징후가 없으므로 가능성이 낮음 (턴 22, 33). 감별 검사 : Lumbar puncture with CSF analysis
r/o 상기도감염 : 경증 기침·콧물과 열이 상기도감염을 암시하지만, 고막 부종과 광반사 소실은 중이염과 더 관련이 깊음 (턴 7, 25). 감별 검사 : 기본 상기도 감염 관찰/보존적 관리를 권장
r/o 바이러스성 귀염 : 바이러스성 귀염은 대개 고막 부종이 없고 숨김이 적지만, 이번엔 고막 발적·팽윤이 있어 세균성 중이염 가능성이 높음 (턴 2, 25). 감별 검사 : Tympanocentesis 및 세균학적 검사
```

## [P] 추가 검사

```
- 중이염 진단을 위한 고막 시진 : 발진, 팽만, 광반사 손실 확인
- 중이 수액 저장 검사 (타입B/C) : 수액 여부와 중이염 심도 판단
- 폐소생산성 검사(전흔치사 검사) : 폐 질환 배제
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C → 현재 외래 추적이 적절하며 활력징후 불안정·증상 급격한 악화 시 입원 고려
```

## [P] 추적

```
- 즉시 내원 : 귀 뒤 붓기, 처짐, 목 뻣뻣함, 고열 지속
```

## [P] 환자 교육

```
진료 중 설명함:
- 급성 중이염 가능성이 높습니다
- 귀에 혈액이 모일 수 있어 통증이 납니다
- 약은 검사 결과 보고 상의해 조절해요.
- 통증 완화제와 해열제를 사용해요
- 발열, 통증, 귀 뒤 붓기가 있으면 바로 내원해요.
- 귀 뒤 붓기·처짐·목 뻣뻣함·고열 시 바로 오세요.
- 바로 오셔야 할 증상 하나를 말씀해 보세요.
- 2~3일 뒤 결과 보러 다시 오세요.
다음 방문 시 교육 예정 : 구강 위생 관리; 구강 협조 및 기침 가려움 주의
참고 지침 : Korean Clinical Practice Guidelines: Otitis Media in Children (KR_EuropePMC, 2012)
```

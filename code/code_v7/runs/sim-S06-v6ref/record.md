## [A] 근거

```
#1. 제2형 당뇨병 (Type 2 Diabetes Mellitus)
- 근거 : 피로와 체중 감소가 2~3개월 지속되었으며, 비만 체형과 고혈압이 함께 나타나는 것을 보면 대사 증후군이 의심된다. 다수의 빈뇨(낮 10회)와 다량의 물 섭취(2L/일)이 관찰돼다. 가족력(아버지·어머니) 역시 당뇨병 유병률을 높인다. (시작 정보; 턴 1, 5, 7, 8, 9, 16, 23)
- 근거 : 비만 체형(E1)과 고혈압(고혈압제 복용, F6) 등은 인슐린 저항성 및 타입2 당뇨의 위험 요소로 인식된다. (턴 5, 23)
```

## [A] 감별진단

```
r/o 제1형 당뇨병 / Type 1 Diabetes Mellitus : 유전적 관여와 가족당뇨의 존재는 형식적인 가능성을 유지하나, 케토산증 증상(제외) 및 인슐린 결핍 증거가 없으므로 단순 수가 낮음 (턴 7, 9). 감별 검사 : HbA1c, fasting plasma glucose, C‑peptide
r/o 갑상선 기능저하증 / Hypothyroidism : 호소한 피로와 체중 감소가 일부 증상일지 모르나, 갑상선 촉진 검사(E3)에서 비대/결절/압통이 없고, 결막·공막 시진(E2)에서 충혈이 없으므로 기능 저하 의심률이 낮다 (시작 정보; 턴 24, 25). 감별 검사 : TSH, free T4
```


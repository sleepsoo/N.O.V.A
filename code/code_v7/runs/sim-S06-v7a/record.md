## [A] 근거

```
#1. 2형 당뇨병 (Type 2 Diabetes Mellitus)
- 근거 : 피로, 목 건조, 자주 배뇨와 체중 감소가 3개월간 지속 (시작 정보; 턴 1, 13)
- 근거 : 비만 체형과 고혈압이 있기에 당뇨 위험 증가 (턴 2, 23, 24)
- 근거 : 가족 당뇨력(부모) 존재 (턴 15)
```

## [A] 감별진단

```
r/o 만성 무증상 갑상선기능저하증 (Silent Hypothyroidism) : 반대 → 환자 무증상, 목 건조 환자가 아닌, 제경절 양성 → 가능성 낮음 (시작 정보; 턴 2, 27). 감별 검사 : TSH, FT4
r/o 부신피로증후군 (Adrenal Fatigue Syndrome) : 반대 → 고혈압 존재, 증상 충분히 짧음 → 가능성 낮음 (턴 2, 13, 32). 감별 검사 : ACTH, cortisol 연속 (TRAb 음성·불명확 시)
r/o 위장관 질환(소화불량) : 지지 → 소화불량 비음성, 대체 증상 없음 → 배제 어려움 (턴 9). 감별 검사 : 대변 검사, 위장 내시경
r/o 정신과적 인과(지속적 스트레스) : 지지 → 피로 무증상, 가족력 없음 → 가능성 중간 (턴 16, 17). 감별 검사 : 심리평가
r/o 당뇨 [환자 우려] : 지지 → 몸이 피곤하고, 목 건조, 자주 배뇨, 체중 감소, 가족력 → 가장 가능성 (시작 정보; 턴 1, 13, 15). 감별 검사 : HbA1c, 공복혈당
```

## [P] 추가 검사

```
- 혈액 : CBC, 최종화, 공복혈당/HbA1c : 기본검사
- 혈액 : TFT, 단백/스코어(조건부) : 갑상선 기능
- TSH, FT4 : 만성 무증상 갑상선기능저하증 (Silent Hypothyroidism) 감별
- (조건부) ACTH, cortisol 연속 : TRAb 음성·불명확 시 — 부신피로증후군 (Adrenal Fatigue Syndrome) 감별
- 대변 검사, 위장 내시경 : 위장관 질환(소화불량) 감별
- 심리평가 : 정신과적 인과(지속적 스트레스) 감별
```

## [P] 치료

```
- 식사·운동 요법
- 결과 확인 후 경구 혈당강하제 시작 고려(eGFR 확인)
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(혈압 상승)
- 현재 외래 추적이 적절하며 활력징후 불안정·증상 급격한 악화 시 입원 고려
```

## [P] 추적

```
- 의뢰 기준 : 매우 높은 혈당·케톤·합병증 의심 시 내분비내과
- 즉시 내원 : 심한 갈증·구토·의식 저하(고혈당 응급)
```

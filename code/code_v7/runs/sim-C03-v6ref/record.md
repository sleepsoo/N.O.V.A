## [A] 근거

```
#1. 가족성 저신장 (Familial short stature)
- 근거 : 부모의 키가 평균보다 낮고 시아버지도 어린 시절 키가 작았던 사실이 유전적 요인을 시사한다 (턴 4, 5, 6)
- 근거 : 현재 신장은 105cm으로 3번째 백분위수 이하이며 성장 속도도 5cm/년이라는 정상 하한치에 근접해 있음을 확인하였다 (턴 24, 25)
- 근거 : 상·하절 비율이 정상이고, 팔길이대비 다리길이가 비정상적으로 짧지 않으며, 병력이 전반적으로 없으므로 골연골 이형성증 같은 구조적 이상을 배제한다 (턴 26, 28)
```

## [A] 감별진단

```
r/o 성장호르몬 결핍증 : 성장 속도가 정상 하한치로 보이더라도, 신체 비율이 정상 여부와 IGF-1 수치가 낮을 경우 진단 가능성이 있다 (턴 25, 26, 27). 감별 검사 : IGF‑1 검사 및 성장호르몬 자극검사
r/o 비후성 골연골 이형성증 : 들어온 소견에서 비대치, 머리둘레 비정상, 비정상적인 골격 비율 등 특징이 없고, 상·하절 비율도 정상으로 골연골이형성증 배제 가능 (턴 26, 28). 감별 검사 : 정형외과 X‑ray (전부기, 사지 길이 비율 확인)
```

## [P] 추가 검사

```
- 좌측 손 X‑ray : 골연령 확인으로 성장지연 여부 확인
- TSH 및 자유 T4 : 갑상선 기능 정상 여부 파악
- IGF‑1 : 성장호르몬 기능 평가
- 혈액 산화물질 검사 : 정상 성장과의 비교
- 좌측 손 X-ray(골연령) : 역연령과 일치 확인
```

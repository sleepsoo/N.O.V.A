```

## [A] 감별진단

```
r/o Growth hormone deficiency : 지지 성장차이·저성장속도·저체중 → 가능성 중간 / 반대 갑상선 검사음성 → 배제 어려움 (시작 정보; 턴 31, 32). 감별 검사 : IGF‑1 level, insulin‑like growth factor 1, or GH stimulation test
r/o Constitutional growth delay : 지지 저성장속도·상대적 정상 체중 → 가능성 낮음 / 반대 연령이 6세·성장지연 시기 다소 이른 시기 → 배제 어려움 (시작 정보). 감별 검사 : bone age radiograph (hand/wrist) (조건 ①)
r/o Subclinical hypothyroidism : 지지 저성장속도·저체중 → 가능성 낮음 / 반대 갑상선 촉진·압통 음성 타인 → 배제 어려움 (시작 정보; 턴 31, 32). 감별 검사 : TSH, free T4, TPO antibodies
r/o Skeletal dysplasia (achondroplasia) : 반대 목요골 비틀림·비대 체형 없음 → 배제 어려움 (턴 24, 30). 감별 검사 : 골형성 유전자 검사 (조건 ②)
```

## [P] 추가 검사

```
- 혈액 : TSH, free T4, IGF‑1 : 호르몬 상태 확인
- 좌측 손 X-ray(골연령) : 역연령과 일치 확인
- IGF‑1 level, insulin‑like growth factor 1, or GH stimulation test : Growth hormone deficiency 감별
- (조건부) bone age radiograph (hand/wrist) : 조건 ① — Constitutional growth delay 감별
- (조건부) 골형성 유전자 검사 : 조건 ② — Skeletal dysplasia (achondroplasia) 감별
```

```

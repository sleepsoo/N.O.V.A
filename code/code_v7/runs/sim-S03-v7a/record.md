## [A] 근거

```
#1. 급성 중이염 (Acute Otitis Media)
- 근거 : 고열, 귀통증 및 염증성 고막(빨강, 팽윤, 광반사 소실) 발견 (턴 1, 28)
- 근거 : 반응성 고막(광반사 소실)과 인두의 발적·편도 비대는 감염의 지표 (턴 28, 29)
- 근거 : 고름이나 맑은 귀분비물 없음은 급성 세균성 중이염의 특징 (턴 28, 30)
- 근거 : 여러 증상(열, 귀통증, 밤보채)과 가족력이 없는 경우 급성 중이염 확률 높음 (턴 1, 10)
- 근거 : 우측 상경부 1cm 림프절 비증식은 감염 반응을 의미 (턴 30)
```

## [A] 감별진단

```
r/o 뇌수막염 (환자 우려) : 고열, 밤보채, 귀통증이 뇌수막염과 겹침 → 배제 필요 (턴 1, 8, 28). 감별 검사 : 시상하부 보존 검사(뇌척수액 검침·배양)
r/o 외이도염 : 오른 귀 통증 국소화 및 전통적 증상 부족 (턴 28, 30). 감별 검사 : 외이도 세균 검사 (반응에 따라)
r/o 항상성 중이염 : 짧은 증상기간(1일)과 급성 발열 완절 부적합 (턴 1, 28). 감별 검사 : 경부 초음파 (반응에 따라)
r/o 비특이 감염성 증후군(예: 백일해) : 경부 림프절 비증식 및 발열이 일관되지는 않음 (턴 1, 30). 감별 검사 : 혈청 IgA형 백일해 검사 (반응에 따라)
```

## [P] 추가 검사

```
- 고막 시진 : 교정 원인 확인
- 시상하부 보존 검사(뇌척수액 검침·배양) : 뇌수막염 감별
- (조건부) 외이도 세균 검사 : 반응에 따라 — 외이도염 감별
- (조건부) 경부 초음파 : 반응에 따라 — 항상성 중이염 감별
- (조건부) 혈청 IgA형 백일해 검사 : 반응에 따라 — 비특이 감염성 증후군(예: 백일해) 감별
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열)
- 현재 외래 추적이 적절하며 활력징후 불안정·증상 급격한 악화 시 입원 고려
```

## [P] 추적

```
- 재진 : 48시간 뒤 중이염 호전 여부 확인
- 모니터링 : 48h 이후 체온, 귀통증 상태 체크
- 의뢰 기준 : 잦은 재발·삼출액 지속·청력 저하·합병증 의심 시 이비인후과
- 즉시 내원 : 귀 뒤 붓기, 처짐, 목 뻣뻣함, 고열 지속
```

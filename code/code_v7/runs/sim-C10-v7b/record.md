## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 3개월간 7kg 체중 감소(비가역, 급성) → 호르몬 이상 가능성 높음 (시작 정보)
- 근거 : 식사량 증가, 열감↑, 두근거림, 손떨림, 발한, 야간 발한 → 재정맥계 과민성, 갑상선 과다분비 (시작 정보; 턴 1, 2, 3, 4)
- 근거 : 목소리 특징: 진환상(안검후퇴, 눈부전, 눈저림) + 둔휘성 갑상선비대(양측 ST, 결절 없음) → Graves 특성 (턴 28, 30)
- 근거 : 요심혈관계 HR 102, BP 138/72, 손바닥 습윤, 기립성 혈압 정상 → 심박동수 상승, 수분 대사 증가 (턴 25, 26, 27)
- 근거 : 환자가 ‘큰 병 우려’ 표현 및 이미 치료기존 약물복용(갑상샘 기능저하증) 기록 있음 → 부작용·영향가능성 존재 (턴 18)
```

## [A] 감별진단

```
r/o 주근육경련성 스트레스/정신과적 원인 : 지지: 불면, 소화불량, 두근거림/반대: 체중감소 과다, 항진증 소견 배제→낮음 (턴 21). 감별 검사 : 골반단백질 검사(소변소변 검사)
r/o 확진성 감염·염증성 질환(급성 감염 등) : 지지: 체중감소 ; 반대: 정열감정 25°C 이하, 급성 고열 없음→심화가능성 낮음 (턴 10). 감별 검사 : CBC, CRP
r/o 대사성 질환(당뇨/인슐린 저항성) : 지지: 소변량 증가 ; 반대: 혈당 이상 없고 DM병력 없음→차감 가능성 낮음 (턴 11, 12). 감별 검사 : 공복혈당 및 HbA1c
```

## [P] 추가 검사

```
- 혈액 : TSH, 자유형 T4, T3 : 갑상샘 기능 확인
- 혈액 : TSH 수용체 항체(TRAb) : 그레이브스병 확진
- 혈액 : CBC, AST/ALT, BUN/Cr, HbA1c : 기준치·당뇨 감별
- 갑상샘 초음파(필요 시) : 결절·기타 감별
- 골반단백질 검사(소변소변 검사) : 주근육경련성 스트레스/정신과적 원인 감별
- CBC, CRP : 확진성 감염·염증성 질환(급성 감염 등) 감별
- 공복혈당 및 HbA1c : 대사성 질환(당뇨/인슐린 저항성) 감별
```

## [P] 치료

```
- 금기(천식·서맥·심부전) 확인 후 베타차단제로 두근거림·떨림 조절
- TFT·TRAb 확인 후 항갑상샘제 시작 여부를 내분비내과 전문의와 상의해 결정, 무과립구증·간독성 교육
- 눈 건조·자극감이 있으면 인공눈물
- 재발·부작용 시 방사성요오드·수술을 내분비내과와 상의
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 102회/분), 확인된 진찰 소견상 갑상샘중독발증 징후 없어 현재 외래 추적이 적절하며 심한 빈맥·발열·의식 변화 시 입원 고려
- 내분비내과 외래 연계
```

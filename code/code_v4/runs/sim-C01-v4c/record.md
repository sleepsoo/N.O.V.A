## [A] 감별진단

```
r/o 일반불안장애 (Generalized Anxiety Disorder, Anxiety) : 이 환자는 식은 땀(F5), 가슴 두근거림(F6), 머리 아픔(F7), 손 떨림(F8) 등의 불안 증상을 보이며, 수면제 사용에 대한 두려움(식물F19)이 존재한다 (턴 3, 15). 감별 검사 : GAD‑7
r/o 무증상 갑상선기능저하증 (Subclinical Hypothyroidism) : 악심의 증상인 식은 땀(Chills)과 손 떨림이 가벼운 증상의 미묘한 포인트이지만, 신체검사에서 갑상선 비대(검사E7)가 없고 체온이 정상으로 매우 미미한 증상이므로 추가 실험이 필요하다 (턴 3, 20, 22). 감별 검사 : TSH
```

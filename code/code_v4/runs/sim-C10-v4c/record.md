## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 7kg 체중 감소는 급격한 체중 감소이며, 다이어트·운동 기록이 없으므로 호르몬 이상 가능성이 높음 (시작 정보; 턴 2)
- 근거 : 자주 느끼는 두근거림과 혈액 맥박 102bpm, 호흡 19bpm은 부정맥 위험을 시사 (턴 3, 4, 18)
- 근거 : 다발성 땀, 피로감, 안검 후퇴 및 안검 지연은 갑상선 기능 항진의 특징적인 증상 (턴 6, 10, 22)
- 근거 : 갑상선 촉진 결과 양측 비대(2배 정상)는 갑상선 기능 항진의 잠재적 징후 (턴 23)
```

## [A] 감별진단

```
r/o 자기파괴적 섭식장애 (Anorexia nervosa) : 체중 급격 감소와 피로감이 일치하지만, 객관적으로 안증, 검진에서 안검 지연·후퇴, 심박수 상승·다발성 땀과 같은 갑상선 기능 항진 징후가 존재 (시작 정보; 턴 2, 6, 18, 22). 감별 검사 : TSH, free T4, T3 및 영양사 상담과 심리 평가
r/o 감염성 질환 (Infectious disease) : 체중 감소와 피로감이 존재하나, 열이 없고, 혈액학적 염증 지표가 부정적이며 요로감염 증상을 거부 (턴 8, 11, 20). 감별 검사 : CBC, CRP, ESR, urine culture
```

## [P] 추가 검사

```
- TSH, free T4, T3 : 갑상샘중독증 확인
- TRAb : 그레이브스병 확진
- CBC, LFT : 항갑상샘제 시작 전 기준치
- ECG : 빈맥·심방세동 여부
- 심전도 : 빈맥·심방세동 확인
- 갑상샘 초음파(필요 시 스캔·섭취율) : 결절 유무와 원인 감별
```

## [P] 치료

```
- 금기(천식·서맥·심부전) 확인 후 베타차단제로 두근거림·떨림 조절
- TFT·TRAb 확인 후 항갑상샘제 시작 여부를 내분비내과 전문의와 상의해 결정, 무과립구증·간독성 교육
- 눈 건조·자극감이 있으면 인공눈물, 흡연자는 금연 권고(안병증 악화 인자)
- 재발·부작용 시 방사성요오드·수술을 내분비내과와 상의
```

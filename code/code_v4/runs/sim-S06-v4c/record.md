## [A] 근거

```
#1. 당뇨병 (Diabetes Mellitus)
- 근거 : 증상으로 나타난 지속성 피로, 심한 목마름, 다량 수분 섭취 및 빈번한 소변, 그리고 시야 흐림은 모두 고혈당으로 인한 신경계 및 눈의 기능 이상을 시사하며, 이는 2형 당뇨병의 대표적 전형적 증상이다. (시작 정보; 턴 3, 11)
- 근거 : 가족력에 부모의 당뇨병 및 당뇨 합병증이 존재하며, 고혈압과 비만이 동시에 존재함으로써 당뇨병 위험이 높아진다. (턴 8, 10, 17)
```

## [A] 감별진단

```
r/o 수면무호흡증 (Obstructive Sleep Apnea) : 비만체형과 고혈압, 과령이 OSA 발생 위험을 높임. 그러나 수면 무호흡 소음이나 과다한 낮잠 등의 단순 증상이 보고되지 않아 우선 제외 (턴 8, 17). 감별 검사 : 수면다중검사(Polysomnography)
r/o 갑상선기능항진증 (Hyperthyroidism) : 갑상선 비대 및 소음이 없고, 객관적 객단절효과가 없으므로 가능성이 낮음. 하지만 갑상선 기능검사가 필요 (턴 21, 22). 감별 검사 : TSH, 프리T4
```

## [P] 추가 검사

```
- 공복혈당 : 당뇨 확진 및 혈당 상한점 확인
- HbA1c : 최근 3개월 평균 혈당 평가
- 지질검사 : 합병증 위험 평가
- 크레아티닌·eGFR : 신장 기능 확인 후 약제 선정
- 간기능검사 : 약제 선택 시 안전성 평가
- 기초 시각검사 : 시야 흐림 원인 확인
- Sleep study(PSG) : 수면무호흡증 감별
```

## [P] 치료

```
- 식사·운동 요법
- 결과 확인 후 경구 혈당강하제 시작 고려(eGFR 확인)
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

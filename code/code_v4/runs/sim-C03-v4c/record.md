## [A] 감별진단

```
r/o 체질성 성장지연 (Constitutional Growth Delay) : 성장 속도가 정상 하한선이었고, 신체 비율 및 외부 기형이 없으며, 부모 키가 정상 범위이므로 성장 지연은 체질성 가능성이 높다. 골연령이 늦어질 수 있다 (턴 5, 6, 19). 감별 검사 : 골연령 X‑ray
r/o 유전형 성장지연 (Familial Short Stature) : 부모 평균 키 178 cm로 정상, 따라서 가족성 저신장은 가능성이 매우 낮다 (턴 19). 감별 검사 : 부모 측정 기록 확인
r/o 성장호르몬 저하 (Growth Hormone Deficiency) : 키가 3rd 퍼센타일 미만이지만, 성장 속도가 정상 하한선이므로 겸양이 가능하나, 현재 신체 검사에서 성장샘 부정상 징후가 없고 비타민·요오드 섭취가 정상적이라 가능성이 낮음 (턴 18, 19, 22). 감별 검사 : 생장호르몬 자극(IGF‑1, GH stimulation test)
r/o 골연골 이형성증 (Hypochondroplasia) : 신체 비율 정상, 관절 및 부속 관절 길이의 비대칭이 없으며, 머리 두께는 평균이다. 골연골 이형성증 특징적 징후가 없으므로 배제 가능성 높음 (턴 17, 18, 21). 감별 검사 : FGFR3 유전자 검사
```

## [A] 근거

```
#1. 급성 중이염 (Acute Otitis Media)
- 근거 : 환자 3세가 열(38.6°C)과 오른쪽 귀 통증을 호소하고, 현미경 상 고막이 붉고 팽창, 광반사가 사라져 급성 중이염을 시사한다. (시작 정보; 턴 20)
- 근거 : 복부·심문에서 비뇨기 및 심각질환 소견이 없으며 전반적 외관은 급성 병색이 가라앉아 보악음이 보이고 탈수 징후가 없다. (턴 17)
```

## [A] 감별진단

```
r/o 감기성 상기도감염 (Common Cold) : 열이 있으나 귀 통증이 꼭 중이염을 의미하지 않는다. 감기 증상으로는 발열, 기침, 혼성 기분등이 흔하지만 고막 충혈·팽창은 드물다 (시작 정보; 턴 11). 감별 검사 : 상부기관 두께 부피검사 또는 비강 내시경으로 상기도염 증거 확인
r/o 귀지 축적 (Earwax Impaction) : 귀 통증이 있을 수 있으나, 고막에 충혈·팽창이 없고 광반사 소실이 없었음 (시작 정보; 턴 20). 감별 검사 : 음성 또는 농담의 옵션을 활용한 귀지 제거 및 고막 시진
```

## [P] 추가 검사

```
- 고막 진찰 : 진단 확정과 감별 성분 확인
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C
- 외래 : 열·귀통증·고막 발적 확인
```

## [P] 추적

```
- 재진 : 48h 후, 귀통증·열 여부 확인
- 모니터링 : 체온·귀통증, 12시간 간격 체크
- 즉시 내원 : 고열·귀뒤 부기·목 뻣뻣함
```

## [P] 환자 교육

```
진료 중 설명함:
- 급성 중이염 가능성이 높아 보여요.
- 개선되는 지 관찰·48h 후 재진이 적절해요
- 말씀하신 증상들이 이 병과 잘 맞아요.
- 뇌수막염은 귀통증이 아니라 두통·경련이 주요 신호예요
- 고막 진찰은 귀를 확인해요
- 해열진통제는 과다 복용 시 간에 부담을 줄 수 있어요
- 2~3일 뒤 귀 상태를 다시 볼게요.
- 고열·귀통증·귀뒤 부위 붓기·목 뻣뻣함면 바로 오세요.
참고 지침 : Korean Clinical Practice Guidelines: Otitis Media in Children (KR_EuropePMC, 2012); 중이염 (KR_HealthInfo, 2026)
```

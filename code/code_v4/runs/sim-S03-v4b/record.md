## [A] 근거

```
#1. 급성 전이성 중이염 (Acute Otitis Media)
- 근거 : 고막이 발적·팽윤 및 광반사 소실이 나타나며, 이는 급성 전이성 중이염을 시사한다. (턴 18)
- 근거 : 이하은이 어제부터 귀를 자꾸 만지며 보채는 증상이 있으며, 이는 귀통증의 증거다. (턴 2)
- 근거 : 체온 38.6℃와 심박수 128회/분 등 급성 질환의 임상적 징후가 확인된다. (턴 13)
```

## [A] 감별진단

```
r/o Upper Respiratory Tract Infection (비인두염) : 비인두염은 일반적으로 인두(경도) 발적이 있으며 귀통증이 드물다. 환자는 인두 경도 발적이 있으나, 고막 발적·팽윤이 명확히 관찰된 반면 간단한 URI와 차별화된다 (턴 17, 18, 19). 감별 검사 : 인두 swab 또는 혈액 검사(CRP)로 바이러스 여부 확인
r/o Acute Otitis Externa (외이염) : 외이염은 외이도 붉고 부어 있으며 귀를 잡으려는 행동이 흔하지만, 고막의 발적과 광반사 소실은 외이염이 아닌 중이염을 암시한다 (턴 17, 18). 감별 검사 : 외이도 촬영(필요 시)
```

## [P] 추가 검사

```
- 고막 시진 : 중이염 확인
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C
- 외래 : 현 활력징후 정상, 고열 38.6°C, 고막 산증 발견
```

## [P] 추적

```
- 재진: 48~72시간 후, 점막 회복 여부 확인
- 즉시 내원 : 귀 뒤 붓기, 처짐, 목 뻣뻣함, 고열 지속
```

## [P] 환자 교육

```
진료 중 설명함:
- 급성 중이염이 귀 안쪽 염증이예요
- 열과 통증은 해열진통제로 조절해요.
- 귀 안쪽 돔이 부풀어서 아프게 만들어요
- 고막 시진이 진단에 가장 사용돼요
- 항생제 복용 시 약물 복용을 주의하세요
- 집에 담배 피우지 마세요
- 2~3일 뒤 귀 상태를 다시 볼게요.
- 귀 뒤 붓기·고열 지속·구토면 바로 오세요.
참고 지침 : Korean Clinical Practice Guidelines: Otitis Media in Children (KR_EuropePMC, 2012)
```

## [A] 근거

```
#1. 범불안장애 (Generalized Anxiety Disorder)
- 근거 : 이환자와 같이 밤에 잠을 못 자며 휴대성을 느끼는 경우 불안감과 신체 증상(가슴 두근거림, 식은땀, 두통, 손떨림)이 동반될 때 범불안장애가 흔히 토지엉니다. (턴 2, 3)
- 근거 : 불면증과 함께 낮에 피로, 집중력 저하, 짜증이 나타나며, 이는 불안 장애가 수면문제의 큰 원인 중 하나임을 시사한다. (턴 5)
- 근거 : 수면제(스틸녹스) 4일 이상 자가 처방 복용과 학습(“새벽 두 알 추가”)는 수면제 의존 위험을 증가시킨다. (턴 7, 8)
```

## [A] 감별진단

```
r/o 우울증 (Major Depressive Disorder) : 낮에 피로, 집중력 저하, 짜증 같은 증상은 우울증의 일부지만, 현재는 기분저하·관심감 상실·산증설명 재제곱이 없으며, 두통·어지러움 등 신체적 증상이 두드러진다. 따라서 우울증 상호 배제 가능성은 낮다 (시작 정보; 턴 3, 5). 감별 검사 : PHQ‑9 설문
r/o 수면제 남용 가능성 (Sedative‑hypnotic dependence) : 스틸녹스 같은 베타디아제핀 수면제의 과다/확장 복용은 종말적 의존 위험이 존재한다. 현재 복용량과 빈도가 4일 이상이므로 유의 강화가 필요하다 (턴 7, 8). 감별 검사 : 아정체성 평가(탈출/중단반응관찰)
```

## [A] 근거

```
#1. 중이염 (Acute Otitis Media)
- 근거 : 발열(38.6°C)과 동반된 오른쪽 귀 통증은 급성 중이염에서 흔히 관찰되는 감염 증상이다. (시작 정보; 턴 2)
- 근거 : 명시된 고막 발적·팽윤, 광반사 소실은 AOM 진단 기준에 부합한다. (턴 20)
- 근거 : 세(3세) 연령과 급성 병색(급성 염증 기전)으로 위험군에 속한다. (시작 정보; 턴 17)
```

## [A] 감별진단

```
r/o 수막염 (Meningitis) : 고열과 잠재적 전신 감염은 수막염 가능성을 배제할 수 없으나, 경부강직 부재, 케르니그·브루진스키 음성, 고막 증상은 수막염을 배제한다 (시작 정보; 턴 29). 감별 검사 : 정맥 혈액검사(전혈구수, CRP) 및 수액 바쁜 사람에서 신속한 두개내 주사(혈액 및 뇌척수액)
r/o 급성 비염 (Acute Rhinitis) : 발열 및 귀 통증이 비염의 증상과 1:1로 일치하지 않으며, 고막 증상은 비염과는 무관하다 (시작 정보; 턴 20). 감별 검사 : 필요 없음, 주로 임상 평가
r/o 폐렴 (Pneumonia) : 호흡곤란, 기침, 흉부 경음증 증상 부재로 폐렴 가능성이 낮음 (턴 3, 23). 감별 검사 : 흉부 X‑선 촬영
```

## [P] 추가 검사

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C
- 외래 : 고막 소견이 급성 중이염에 부합하며 별도의 응급 처치 필요 없으며 성인 내부 부종비상 상황이 아니라는 진찰 소견
```

## [P] 추적

```
- 재진 : 48~72시간 후 중이통 증상 및 열 감지 여부 확인
- 모니터링 : 일주일에 한 번 귀 감각 및 열 변화 관찰
- 즉시 내원 : 열 39℃ 초과, 두통, 목 뻣뻣함, 광반사 소실 등 신체적 악화 시
```

## [P] 환자 교육

```
진료 중 설명함:
- 중이염 가능성이 높아 보여요.
- 열과 통증은 해열진통제로 조절해요.
- 말씀하신 증상들이 이 병과 잘 맞아요.
- 진찰 소견은 큰 병보다 지금 진단 쪽에 맞아요.
- 정확히 확인하려고 피검사를 할게요.
- 2~3일 뒤 귀 상태를 다시 볼게요.
- 귀 뒤 붓기·처짐·목 뻣뻣함·고열 시 바로 오세요.
```

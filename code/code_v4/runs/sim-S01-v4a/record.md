## [A] 감별진단

```
r/o 장염 (Enteritis) : 통증 시작은 배근각후 1시간, 가벼운 발열, 전반적인 복통, 식후 1시간 후 통증이 있음 (시작 정보; 턴 5, 13). 감별 검사 : CBC 및 CRP 확인 및 복부 초음파
r/o 복막염 (Peritonitis) : 반발압통과 국소근성방어, 가벼운 발열이 우하복부 급성통과 일치 (턴 5, 27, 28). 감별 검사 : 복부 CT, 혈액소염지표(CRP, WBC)
r/o 급성신장결석 (Kidney stone) : 배뇨통증 없음, 소변색 정상, 고전적인 통증 부근 증상 부재 (턴 6, 14). 감별 검사 : 신장 초음파 또는 CT 스캔
```

## [P] 추가 검사

```
- CBC : 백혈구 수와 장염 여부 확인
- CRP : 염증 정도 평가
- Abdominal CT : 충수염 확인 및 감별질환 배제
- Urinalysis : 신장결석 부재 확인
```

## [P] 치료

```

- 항생제 처방 승인 대기
- 새 약 시작 전 금기·약물 알레르기·상호작용 확인
```

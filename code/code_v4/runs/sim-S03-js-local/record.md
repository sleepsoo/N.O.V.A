## [A] 근거

```
#1. 급성중이염 (Acute Otitis Media)
- 근거 : 3세 아동이 오른쪽 귀 통증과 38.6°C의 열이 동반되고, 청진에서 우측 고막이 발적·팽창하며 광반사가 소실된 상태(고막부종)로 나타남. 이는 급성 중이염의 전형적 징후이다. (시작 정보; 턴 1, 25, 33)
- 근거 : 비가역적 고막 발적과 팽창이 일반적인 상기도 바이러스산증과는 구별되며, 고막시지(80%)는 급성 중이염에서 자주 보이는 양증 (턴 25)
```

## [A] 감별진단

```
r/o 상기도 바이러스감염 : 고열은 2-3시간 후 해열제 사용으로 일시적으로 완화되었으며, 맑은 콧물·가벼운 기침이 나타남. 고막 부종은 없었으나, 상기도 증상이 동반될 수 있다 (턴 7, 10). 감별 검사 : 상기도 바이러스 PCR검사 (필요시)
r/o 알레르기 비염 : 마취전 또는 비염의 특징인 마른 콧물 및 재채기보다는 맑은 콧물 및 기침이 주로 나타나며, 눈 가려움증이나 충혈과 같은 동반 증상 없음 (턴 7). 감별 검사 : 피부 단자 시험 또는 혈청 IgE 검사
```

## [P] 치료

```
- 해열진통제
- 2세 미만·중증·양측이면 항생제, 그 외 48~72시간 관찰 가능
```

## [P] 처치 결정

```
- 활력징후 대체로 안정(빈맥 128회/분, 빈호흡, 발열) : BP 96/58 mmHg, PR 128 회/분, RR 26 회/분, BT 38.6°C → 현재 외래 추적이 적절하며 활력징후 불안정·증상 급격한 악화 시 입원 고려
```

## [P] 추적

```
- 48~72시간 후 재진, 증상 호전 여부 확인
- 즉시 내원 : 귀 뒤 붓기, 처짐, 목 뻣뻣함, 고열 지속
```

## [P] 환자 교육

```
진료 중 설명함:
- 급성중이염 가능성이 높아 보여요.
- 감염이 귀 안에서 생긴 거예요
- 귀가 아프고 열이 나는 이유는 염증이 때문이예요
- 항생제 처방했다 48시간 후 확인해요
- 복용 시 변비나 구토가 있을 수 있으니 조심해요
- 처음 2일 안에 통증이 가라앉다면 기분이 나아질 거예요
- 정확히 확인하려고 피검사를 할게요.
- 귀 뒤 붓기·처짐·목 뻣뻣함·고열 시 바로 오세요.
다음 방문 시 교육 예정 : 간접흡연은 피해주세요; 약 복용 중 부작용이 있으면 알려주세요
참고 지침 : Korean Clinical Practice Guidelines: Otitis Media in Children (KR_EuropePMC, 2012)
```

## [S] 현병력

```
24세 남자 정민수 씨는 배가 아픈 증상으로 내원하였다.
어제 저녁부터 배꼽 주변이 부풀면서 고통이 있었으며, 오늘 아침부터는 오른쪽 하복부 통증이 더 심해졌다.
밤새 잠을 거의 못 자며, 방금 뒤키는 듯한 메스껍증과 함께 구토를 한 번 했다.
소화제 한 알만 복용하였다.
현재 항복증이나 기타 의학적 질환 이력은 없으며, 통증이 등, 사타구니, 고환 쪽으로 뻗치지는 않다.
이러한 증상으로 내원하였다.
```

## [A] 감별진단

```
r/o 위궤양 (Peptic Ulcer) : 메스꺼움과 구토가 있는 반면, 상복부 통증이 없고 우하복부 반발통·압통이 주요 특징 (턴 5, 26). 감별 검사 : 상부 위 내시경 및 H. pylori 검사
r/o 크론병 (Crohn's Disease) : 지속적 소화불량·복통이 짧은 기간에 급성격으로 나타나며, 복부 CT에서 장벽 두꺼워짐이 특징 (턴 5, 24). 감별 검사 : 복부 CT 또는 장내 MRI
r/o 복벽 감염 (Peritonitis) : 반발통이 국소적이며, 전신증상(발열, 상승된 심박수)과 함께 있는 경우 급성 복막염을 의심 (턴 2, 26, 27). 감별 검사 : 복부 초음파 또는 CT
```

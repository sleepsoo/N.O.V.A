## 가상 환자 대본 (가상 환자만 봄)

이름은 이하은이고, 세 살 여자아이이다. 엄마 박수진, 서른네 살이 보호자로 함께 왔다. 엄마는 하은이가 어제부터 열이 나고 오른쪽 귀를 자꾸 만지며 아파한다고 말했다. 밤새 보채고 잠을 잘 못 자서 데려왔다고 한다.

의사 선생님의 질문에는 엄마 박수진이 대신 대답한다. 하은이는 세 살이라 직접 물어보면 '아파', '싫어' 정도로만 짧게 대답한다.

닷새 전부터 맑은 콧물과 가벼운 기침이 있었다. 어린이집에서 감기가 돌고 있었다. 어제 낮부터 열이 나기 시작했고, 어젯밤에는 삼십팔 점 구 도까지 올랐다. 해열제(아세트아미노펜 시럽)를 먹이면 두세 시간 정도 열이 내렸다가 다시 오른다. 마지막으로 해열제를 먹인 건 오늘 새벽 다섯 시이다. 열이 나면서 오른쪽 귀를 손으로 잡아당기고 '귀 아파'라고 하며 울었다. 누우면 더 보채고, 안아 주면 조금 나아진다. 귀에서 고름이나 진물이 나온 적은 없다. 엄마가 보기에 소리를 잘 못 듣는 것 같지는 않다.

밥은 평소의 반 정도만 먹고, 우유는 잘 마신다. 물도 잘 마신다. 오줌은 평소처럼 기저귀가 젖고, 마지막으로 오줌 싼 건 두 시간 전이다. 토하지는 않았고, 설사도 없다. 숨이 차거나 쌕쌕거리는 소리는 없다. 목이 뻣뻣하거나 고개를 숙이기 싫어하는 모습은 없다. 몸에 발진은 없다. 경련을 한 적도 없다. 축 처지지는 않고, 열이 내리면 평소처럼 장난감을 가지고 논다. 눈곱이 끼거나 눈이 충혈되지는 않았다.

하은이는 만삭에 자연분만으로 태어났고, 태어날 때 특별한 문제는 없었다. 예방접종은 폐렴구균 백신까지 모두 제때 맞았다. 돌 무렵에 중이염으로 한 번 항생제를 먹은 적이 있고, 그 뒤로는 귀가 아팠던 적은 없다. 입원하거나 수술을 받은 적은 없다. 최근 한 달 안에 항생제를 먹은 적은 없다. 평소 먹는 약은 없다. 약 알레르기는 없고, 아목시실린도 전에 먹고 문제가 없었다. 음식 알레르기도 없다. 발달은 또래와 비슷하고, 말도 잘한다.

아빠는 비염이 있다. 엄마는 건강하다. 가족 중에 귀 수술을 받거나 난청이 있는 사람은 없다. 하은이는 엄마, 아빠, 다섯 살 오빠와 함께 산다. 오빠도 지난주에 감기를 앓았다. 집 안에서 담배를 피우는 사람은 없다. 아빠가 담배를 피우지만 밖에서만 피운다. 하은이는 평일에 어린이집에 다닌다. 젖병을 물고 자는 습관은 없다.

여기 적히지 않은 내용을 물어보면 잘 모르겠다거나 그런 건 없다고 답한다.

엄마는 열이 계속 나서 혹시 뇌수막염 같은 큰 병이 아닌지 걱정이 된다. 항생제를 꼭 먹어야 하는지, 귀가 나빠지거나 청력에 문제가 생기지 않는지 궁금해한다. 어린이집에 언제부터 다시 보내도 되는지도 알고 싶어 한다.

## 정답 진단·참고 기록 (채점용)

- 주진단: 우측 급성 중이염 (Acute otitis media, right)
- 인정 표현(accepted_diagnoses): 우측 급성 중이염 (Acute otitis media, right) / 급성 중이염 / Acute otitis media

### 근거

```
상기도 감염(콧물·기침 5일) 뒤 급성 발열(최고 38.9°C)과 우측 귀 통증(귀 잡아당김, 누우면 악화).
이경: 우측 고막 발적·팽윤·광반사 소실, 좌측 정상. 경부강직·발진·처짐·탈수(-)로 수막염·중증 감염 징후 없음, 유양돌기 압통(-)로 합병증 없음.
```

### 감별진단

```
외이도염(이주 압통·외이도 부종 없음), 삼출성 중이염(급성 염증 징후 있음), 바이러스 상기도 감염 단독, 급성 유양돌기염(유양돌기 소견 음성), 세균성 뇌수막염(경부강직·의식변화 없음)
```

### 필요 검사

```
임상 진단으로 추가 검사 불필요. 중증·치료 실패 시 CBC/CRP, 이루 시 배양, 반복 시 청력검사·고막운동성검사.
```

### 처치·추적·교육

```
2세 이상 편측·중등도 발열(<39°C)·이루 없음 → 즉시 아목시실린 고용량(80~90 mg/kg/일, 분2) 또는 48~72시간 관찰 후 미호전 시 투여(보호자와 공동 결정). 아세트아미노펜·이부프로펜으로 통증·열 조절. 48~72시간 내 미호전·고열 39°C 이상·이루·귀 뒤 붓기·처짐·경부강직·경련 시 재진/응급. 2~3주 후 고막 재확인, 삼출 지속 시 청력 평가. 해열 24시간 후 어린이집 등원 가능, 간접흡연 피하기·젖병 물고 자기 금지.
```

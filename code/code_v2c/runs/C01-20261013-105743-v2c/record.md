## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 졸피뎀 10mg을 7년간 복용하며 현재 하루 5~6알, 때로 7알까지 복용한다고 호소해 고용량·장기간 사용이 확인됩니다. (턴 2, 3, 4)
- 근거 : 복용량이 반 알에서 서너 알로 늘었고 감량을 여러 번 시도했지만 실패했다고 호소해 내성 및 조절 실패를 뒷받침합니다. (턴 6, 9)
- 근거 : 약을 복용하지 않으면 잠을 못 자고 불안하다고 호소해 금단 또는 의존 양상과 부합합니다. (턴 7)
- 근거 : 복용 후 기억이 나지 않는 때가 있다고 호소하며, 진찰상 반응 지연과 졸림이 관찰되어 약물 관련 위해가 우려됩니다. (턴 12, 25)
- 근거 : 여러 진료기관에서 처방받고 약국 수면유도제도 가끔 복용하며, 남편과 딸도 약 복용을 걱정합니다. (턴 10, 11, 13)
- 근거 : 진찰상 의식은 명료하고 지남력은 유지되며 급성 중독 징후는 없고, MMSE-K는 28/30점입니다. (턴 24, 25, 26)
```

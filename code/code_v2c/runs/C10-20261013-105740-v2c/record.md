## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 최근 3개월간 의도하지 않게 7 kg 감소했고, 체중은 약 56 kg에서 49 kg으로 줄었으며 계속 감소 중임 → 임상적으로 의미 있는 진행성 체중 감소 (시작 정보; 턴 18)
- 근거 : 체중 감소에도 식욕이 증가했고 더위를 더 타며, 가만히 있어도 두근거리고 손떨림을 호소함 → 갑상샘항진증에 합당한 과대사 증상 (턴 1, 2, 3, 4)
- 근거 : 진찰상 양측 대칭성 미만성 갑상샘 비대와 갑상샘 잡음이 있고, 안구돌출·안검 지연·안검 후퇴가 확인됨 → 그레이브스병을 강하게 시사 (턴 24, 25, 29)
- 근거 : 진찰상 맥박 102회/분, 따뜻하고 땀이 나는 피부, 자세성 떨림 및 양측 하지 근위부 근력 저하가 확인됨 → 갑상샘항진증의 신체 소견과 부합 (턴 26, 27, 28, 30)
- 근거 : 갑상샘 결절과 압통은 없고, 갑상샘 약을 포함한 복용약도 없다고 함 → 결절성 원인이나 외인성 갑상샘호르몬 복용 가능성을 낮춤 (턴 12, 15, 24)
```

## [A] 감별진단

```
r/o 무통성 갑상샘염 (Painless thyroiditis) : 체중 감소와 과대사 증상은 설명할 수 있으나, 진찰상 안구돌출 등 안징후와 갑상샘 잡음은 그레이브스병 쪽을 더 지지함 (시작 정보; 턴 1, 25, 29). 감별 검사 : TSH, 유리 T4 및 갑상샘 섭취율 검사
r/o 독성 갑상샘결절 (Toxic thyroid nodule) : 체중 감소와 두근거림은 갑상샘항진증에 부합하지만, 결절이 없고 갑상샘이 양측 대칭성으로 미만성 비대함 (시작 정보; 턴 3, 12, 24). 감별 검사 : 갑상샘 초음파 및 갑상샘 섭취율 검사
r/o 당뇨병 (Diabetes mellitus) : 체중 감소와 식욕 증가는 고려할 근거이나, 미만성 갑상샘 비대·안징후·갑상샘 잡음은 당뇨병보다 그레이브스병을 더 시사함 (시작 정보; 턴 1, 24, 25, 29). 감별 검사 : 공복 혈당 및 당화혈색소
r/o 위장관 흡수장애 (Gastrointestinal malabsorption) : 체중 감소와 전보다 묽은 변은 고려할 근거이나, 식욕 증가와 갑상샘 안징후 및 잡음은 갑상샘항진증을 더 지지함 (시작 정보; 턴 1, 5, 25, 29). 감별 검사 : 혈청 총 IgA 및 조직트랜스글루타미나제 IgA 항체
```

## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 환자는 7년 전부터 스틸녹스(진정수면제)를 사용해왔으며, 복용량을 점진적으로 10mg에서 4알+1~2알까지 늘려 왔음 (F4, F5, F6, F8). (턴 1, 2, 4)
- 근거 : 수면제 중단 시 불안·뒤척임이 발생하고, 복용량을 줄이려 했으나 불안으로 재복용했다는 증거 (F10, F12) 가 존재함. (턴 6, 8)
- 근거 : 정상적인 의식·지남력(E2)과 인지기능 선별검사(E4) 결과가 정상으로, 다른 신경학적 원인 배제됨. (턴 24, 26)
```

## [A] 감별진단

```
r/o 불안장애 (Generalized Anxiety Disorder) : 환자는 수면제 중단 시 불안 증상을 보이며, 불안이 장기간(7년) 지속된 것으로 추정됨. 실제 불안 스케일을 평가해 진단을 확정할 수 있음 (턴 1, 6). 감별 검사 : STAI (State‑Trait Anxiety Inventory) 또는 HADS‑A
r/o 우울증 (Major Depressive Disorder) : 기억상실이 가끔 보고되었으며, 두통 및 기분 변동이 잠재적 우울 증상일 수 있음. 우울 스케일 평가가 필요함 (턴 16). 감별 검사 : PHQ‑9 또는 Beck Depression Inventory
r/o 수면 무호흡증 (Obstructive Sleep Apnea) : 흡족, 저소변, 밤 호흡 이상이 없지만 수면 중 무호흡이 은폐될 가능성을 배제할 수 없으며, 수면다양성 검사로 최종판단. 감별 검사 : 폴리소몽검사 (Polysomnography)
```

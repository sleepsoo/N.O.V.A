## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 7kg 체중 감량(3개월)와 심박수 102회/분, 솜털이 난 손‑발, 두근거림, 발한 등은 갑상샘 항진증의 특징적 징후이다. (시작 정보; 턴 3, 4, 26, 27)
- 근거 : 갑상선 양쪽 대칭성 비대(약 2배)와 안검 지연, 안검 후퇴, 돌출은 그레이브스병에서 흔히 나타나는 안쪽 눈 증세이다. (턴 24, 25)
- 근거 : 체온 36.9°C, 혈압 138/72 mmHg, 다이어트/운동 기록이 없으면서 식욕 증가가 보고된 점은 비정상적인 대사 증후군을 시사한다. (턴 1, 12)

```

```
r/o 암 (복부/위부·메트로바이럴) : 갑작스러운 체중 감소와 복부 빈약, 부정된 변비(소화불량·설사·변비)과 같은 비특이적 증상은 소화기계 악성 종양을 달리 볼 수 있으므로, 초음파 또는 CT 검사를 권장한다 (시작 정보; 턴 6). 감별 검사 : 복부 초음파 또는 CT 스캔
```

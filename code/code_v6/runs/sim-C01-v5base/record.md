## [A] 근거

```
#1. 수면제(진정수면제) 사용장애 (Sedative-Hypnotic Use Disorder)
- 근거 : 박선희는 7년간 지속적인 불면증을 겪었으며, 스틸녹스 10mg(진정수면제)를 11시와 2~3시에 매번 4~5알씩 복용해 왔다. (시작 정보; 턴 2, 4)
- 근거 : 수면제 복용을 줄이려는 시도(여러 번)에도 성공하지 못했고, 약 복용 시 기억상실을 경험했다. 이는 의존성의 흔한 징후이다. (턴 8, 12)
- 근거 : 신경정신과적 평가에서 불안·초조가 관찰되었지만, MDB(모근단 심박수) 정상이었으며 혈압도 정상 범위였다. 수면 장애가 주된 원인인 것으로 판단된다. (턴 25, 26)
- 근거 : MMSE‑K 점수가 28/30으로 정상으로, 인지 기능에 별다른 결함이 없으며 혈압은 128/78 mmHg로 정상학적 범위 내에 있다. (턴 26)
```

## [A] 감별진단

```
r/o 우울 불안성 불면증 : 불안·초조, 멍·가라앉음, 가족 갈등 등이 정서적 고충을 유발하며, 이러한 심리적 요인으로 인한 수면장애가 우려된다 (턴 6, 7, 13, 17). 감별 검사 : PHQ‑9·GAD‑7 심리상태 평가 및 정신과 상담
r/o 원인불명성 불면증 : 기존 검사 결과에는 뇌신경계 질환, 심장, 내과적 합병증이 배제되었으나 명확한 구조적 원인 부재 (시작 정보; 턴 14). 감별 검사 : 수면다리기식이(Polysomnography) 검사를 통한 수면 단계 분석
```

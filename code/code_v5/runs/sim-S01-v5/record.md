## [A] 근거

```
#1. 급성 충수염 (Acute Appendicitis)
- 근거 : 환자의 복통이 좌심소엽 → 오른쪽 하복부로 이동하며, 해당 부위가 압통 및 반발압통을 보임 (턴 1, 26, 27)
- 근거 : 마시멜로부위(McBurney) 해당 부위가 통증을 일으켜 (+) 토픽이 확인됨 (턴 29)
- 근거 : 우측 요근 부위가 징후를 보이며 급성 급진성 통증이 자주 진행됨 (턴 32)
- 근거 : 복부 통증이 7/10 정도 역사와 함께 매일 밤 수면장애가 발생함 (시작 정보; 턴 3)
- 근거 : 메스꺼움과 구토가 동반된 경증 열(37.9°C)과 함께 대변이 없음(무삭제) 및 설사 없음 (턴 5, 6, 10)
```

## [A] 감별진단

```
r/o 장폐색 : 메스꺼움·구토와 초기 복통이 있지만, 복부 팽만과 설사는 없음. 가능성은 낮으나 배경에 엉덩이부 통증이 있을 수 있으므로 검증 필요 (턴 5, 26). 감별 검사 : 복부 X‑ray 및 CT 스캔 (폐색 여부 확인)
r/o 연질 대장염 : 구토·메스꺼움은 있을 수 있으나, 대장염은 주로 변비, 노랗거나 혈변, 설사와 연결되며, 환자에게는 그러한 징후가 전혀 보이지 않음 (턴 1, 5, 24). 감별 검사 : 대장 내시경 검사 및 염증 정밀검사(CRP, ESR)로 판단
```

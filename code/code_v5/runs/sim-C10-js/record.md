## [A] 근거

```
#1. 그레이브스병에 의한 갑상샘항진증 (Graves' disease)
- 근거 : 증상(식욕증가, 더위감, 두근거림, 손떨림, 고온, 발한) 및 눈 증상(안검 지연)과 진찰에서 비대, 브루트, 혈액 급박한 심박수 102를 보아 갑상샘 항진증이 강하게 의심됨 (턴 1, 2, 3, 4, 24, 25, 27, 29, 30)
- 근거 : 진찰에서 양측 갑상샘 2배 대칭 비대 및 청진시 브루트, 혈압 정상이면서 기분적 고온이 전형적 맥락임 (턴 24, 29)
- 근거 : 연속 3개월간 7kg 체중 감소와 연속 증상으로 급성 대사증상에 걸린 경향이 확연히 보임 (시작 정보)
```

## [A] 감별진단

```
r/o 그레이브스병에 의한 갑상샘 항진증 : 임상적 증상과 진찰 소견이 과다 갑상호르몬 수치와 정합하여 가장 가능성이 높음 (턴 1, 2, 3, 4, 24, 25, 29). 감별 검사 : TSH, FT4, FT3, TSI, Radioactive iodine uptake scan
r/o 피에오크로미오사이트 : 심박수 증가, 두근거림, 발한이 갑상항진증과 유사하지만 혈압 상승과 호전 가능성 있음 (턴 3, 4, 30). 감별 검사 : 24h urine metanephrines
```

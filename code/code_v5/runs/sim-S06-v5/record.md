## [S] 현병력

```
오미경, 여성, 두세 달 전부터 피로와 지속적인 목말라가 시작되어 급격한 체중 감소(3kg)와 자주 요량증가를 동반함.
2리터 이상의 물을 일부러 섭취하며 일상에 지장이 있다고 함.
고혈압 약 1일 1알을 복용 중이며, 과거 혈당 상승 병력이 있어 당뇨 우려와 투석 위험을 걱정해 내원함.
```

```
r/o 요로 감염(신우신염 등) : 소변 분비 증상 없음, 요통 없음, 무증상일 경우 발생 가능 (시작 정보; 턴 6, 20, 21). 감별 검사 : 소변 배양 및 감염 마커 (CRP) 검사

```
